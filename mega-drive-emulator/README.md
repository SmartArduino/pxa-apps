# MD模拟器

独立 PXA App，包 ID 为 `pxa-mega-drive`。内核为 PicoDrive，便携 FAME 68000 + CZ80，公共前端位于 [`common/emulator`](../common/emulator/README.md)。

## ROM 与存档

- 文件格式：.md / .gen / .bin / .smd，文件名扩展名不区分大小写；当前直接读取未压缩文件。
- SD 卡通常使用 `/sdcard/PXA/media/lucinhu/pxa-mega-drive/`；空游戏库的 SD 提示中显示系统返回的实际目录。
- Flash 使用本 App 私有目录中的 `roms/`。在游戏库中用左右方向键切换来源，Y 刷新目录。
- 电池存档按平台与 ROM CRC32 分开保存；切换游戏、暂停和退出时写入临时文件并原子替换。
- 范围：16 MiB（另允许 512 字节 SMD 头）；较大 ROM 使用有界缓存，包含 SSF2 换银行及 DMA 路径。支持 MD/Genesis 卡带，SMD 自动去头及反交错。当前不提供 Mega CD / 32X。ROM 文件大小与 Wasm 内存预算分离，无需为了装下整 ROM 扩大线性内存。

## 操作与画面

MD 的 A/B/C 对应手柄 A/B/Y；X/Y/Z 对应 X/L/R；Mode 对应 Select。 支持两个独立手柄输入。Start+Select 打开/关闭游戏菜单，松开组合键后再接收游戏按键。手柄有按键操作后自动隐藏悬浮键；触摸屏空白区域继续游戏，触摸 MENU 打开菜单，支持多指同时按方向和动作键。

默认按平台显示比例放大到屏幕安全区内的最大尺寸并保留黑边，菜单可切换原始尺寸。界面通过 PXA i18n 跟随系统语言，中英文翻译位于 `i18n/`。菜单使用系统字体，游戏中的透明按键使用预计算遮罩与 RGB565 混色表。

声音默认开启，并自动申请播放权限；在游戏菜单切换后按应用保存，下次启动恢复。CPU、图像和声音按同一模拟帧推进；自动跳过部分绘制以减少负载，不通过丢失 CPU 时间来伪造满速。性能与实际支持范围需要结合目标硬件和 ROM 判断。

PCM 使用两块固定缓冲在 PicoDrive 的混音回调中交接：核心清理下一块输出，前端借用已完成的一块，不复制整段 PCM。即时存档同时保存混音滤波器历史；旧开发格式仍能加载游戏进度，缺少的滤波历史从零开始。电池存档格式保持不变。

## 构建与测试

在 PXA 固件工作区根目录执行：

```sh
tools/app.sh build mega-drive-emulator --board doit-gamekit-1 --target simulator,esp32s31 --aot-only \
  --output local/artifacts/console-build/$(date +%Y%m%d-%H%M%S)
```

可运行的原生测试与测量方法见公共前端说明。内核来源、固定版本和本地修改列在 `vendor/` 的 `*upstream.json`；原许可证保留在对应源码中。使用和分发必须同时遵守这些许可证。

`-DEMU_MD_PROFILE=ON` 启用帧、68000、Z80、绘图和声音阶段采样；原生测量加 `EMU_BENCH_LOG=1` 输出日志。CPU/绘图采用抽样估计，阶段包含内部调用（例如 CPU 的 MMIO 可能触发声音或绘图），不能把这些值相加。诊断构建影响耗时，不能用于 FPS 验收；发布构建默认完全关闭采样。

68000 的常用主总线回调通过直接调用执行，保留自定义回调和回调前的实时 PC 同步。逐扫描线的调色板转换合并相邻像素访问，保留阴影/高光索引以及扫描线间的调色板变化；未对齐或不足完整像素组时使用原有转换路径。
