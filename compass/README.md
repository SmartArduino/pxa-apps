# 北辰指南针 / Northstar Compass

`pxa-compass` 是面向 PXA SDK 2.1 的独立指南针工具。默认中文，右上菜单切换 English。深色表盘、珊瑚红北针、屏幕上沿基准和大字方位读数适配方屏、横屏和竖屏；也支持上下、确认三键操作。

## 使用

需要三轴 `magnetic-field.0` 或 `magnetic-field.1`（nT）和三轴 `motion.acceleration`（µm/s²），采样最小周期不超过 100 ms。ESP-Mosaico 的固件公开了两颗 BMM150 和 BMI270 加速度计，设置中可分别选择磁力计 1、2，每颗传感器独立保存校准。当磁场和重力组合不可用时，也支持单值 `orientation.heading`（微度，单位 8）的系统绝对方位服务。无上述服务时不显示虚构方位。

原始磁场模式：

1. 允许传感器访问，进入「校准」，在远离金属、磁铁和大电流导线的位置开始采样。
2. 缓慢转动设备，让上、下、左、右、正面、背面依次朝上；每个朝向稍作停留，同时覆盖不同旋转方向。只有覆盖和拟合检查均通过，才出现「保存」。
3. 保存后以屏幕上沿作为前进方向。红针始终指向磁北，顶部金色标记对应当前朝向。倾角过大、快速移动、异常磁场或失去信号会显示相应状态。
4. 「锁定」保留历史读数并明确标识；解锁恢复实时。设置可选择磁力计、填写已知的当地磁偏角（东偏正、西偏负），或经确认后清除当前传感器校准。

浏览器使用 Host 0.7.6 或更新版本。在没有原始磁场接口的 Android Chrome 上，新版会自动选择「系统方位」，不依赖实验开关。方位来自绝对朝向事件或 AbsoluteOrientationSensor；操作系统负责校准，此模式不显示磁场强度、不采集六面校准，也不改写原有磁力计校准。界面中的「说明」和设置会标明数据来源。普通相对旋转不能指北；平放手机、远离磁铁，并允许站点传感器权限。接口可用不保证硬件实际提供数据，支持与精度需要在具体手机上验证。

默认读数以磁北为基准，不自动假定当地磁偏角，也不获取位置。填写磁偏角后，读数旁明确显示修正值。整度显示是界面分辨率，不是精度保证；误差取决于传感器安装、校准、周围磁场和运动状态。改变附件、磁铁位置或使用环境后应重新校准。

触摸按下后取消、移出按钮松开均不执行动作。未连接或未授权时可点「重试」。取消校准保留旧值，只有明确保存后替换；清除校准需要确认。暂停或进入后台释放传感器资源，返回后重新订阅。

## 算法和资源

- 加速度使用 Host 的设备坐标：+X 指向屏幕顶部、+Y 指向屏幕左侧、+Z 指向屏幕外。磁力计原始坐标通过校准推断对应的 24 种正交安装旋转之一；不会直接把不同坐标系的向量用于倾斜补偿。
- 校准使用最多 256 对样本的有界环形缓冲，数据区为 6 KiB。只配对时间差不超过 50 ms 的磁场与重力样本，缓冲填满后继续滚动拟合。
- 球拟合估计硬铁偏置，重力与磁场夹角的一致性确定安装旋转。要求至少 96 对样本、8 秒、六面覆盖、15–85 µT 的拟合场强、充分跨度、残差与旋转置信度。该方法不等同于完整软铁椭球标定；失真的采样可能无法通过。
- 运行时将屏幕上沿与磁场投影到重力的垂直平面，计算 0–359° 方位。角度采用 240 ms 时间常数的环形平滑，针的动画采用 100 ms 时间常数；跨越北向时不会绕远路。
- 超过 1.5 秒无有效磁场或重力数据时隐藏实时方位。锁定保留的是明确标注的历史读数。磁场幅值异常检测不能识别所有外部干扰。
- 设置存档键 `pxa-compass.save.v1`，有效负载 80 字节：`CMP1`、选择通道、磁偏角、两组校准参数及 FNV-1a 校验。瞬时方位、锁定和采样缓冲不持久化。
- 采样请求为 10 Hz，绘图请求约 20 Hz。包内只有小图标、许可证和程序，不需要网络、音频或外部依赖。安装包使用当前默认 Container 0.2 / DEFLATE / 4 KiB。
- 线性内存上限为 2 MiB，其中包含共享绘图运行时的双帧缓冲；宿主的显示缓冲和 AOT 代码另外占用内存。上面的 6 KiB 数字仅表示校准样本区。

## 构建和测试

从固件工作区根目录运行，产物仅写入忽略的 `local/artifacts/`：

```sh
compass_artifacts="$PWD/local/artifacts/compass/$(date +%Y%m%d-%H%M%S)"
sh local/pxa-apps/compass/tests/run-native.sh "$compass_artifacts/native" "$PWD/deps/pxa-system"
tools/app.sh build compass --board esp-mosaico --target simulator \
  --source-root local/pxa-apps --output "$compass_artifacts/packages/simulator" --aot-only
python3 local/pxa-apps/compass/tests/build_sensor_simulator.py \
  --workspace "$PWD" --output "$compass_artifacts/sensor-simulator"
python3 local/pxa-apps/compass/tests/simulator_test.py \
  --workspace "$PWD" --output "$compass_artifacts/full"
```

原生测试涵盖 24 种安装旋转、噪声、退化采样、环形缓冲继续拟合、方位、跨北平滑、异常状态、存储损坏、双语布局和输入。服务测试覆盖授权、撤销、取消、晚到响应、句柄释放与背压。模拟器测试以公共传感器接口注入明确的合成磁场和重力向量，运行真正签名的 PXA 包，并验证校准、真实输入、持久化及重启。

合成向量回归不能代替实机验收：实际硬件需验证两颗传感器、完整转动校准、平放四方向、倾斜补偿、远离干扰后的稳定读数、后台恢复和重启保留校准。商城截图必须来自实际模拟器运行，关闭性能浮层和底部导航后直接保存，不能裁剪修饰。
