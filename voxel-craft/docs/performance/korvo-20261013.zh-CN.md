# Korvo-1：Voxel Craft 真机验证（2026-10-13）

ESP32-S31-Korvo-1，800×480 RGB565、CPU 320 MHz、16 MB PSRAM，
`/dev/ttyUSB0`、2,000,000 baud。应用采用现有 C++ SDK/O3，未降低画质。
本轮测量面板完成事件，而非应用提交 FPS。完整 Host/音频/跨板报告位于 workspace
`docs/performance/esp32s31-korvo-1-20261013.zh-CN.md`。

## 固定负载结果

相同签名 AOT 包，种子 `0x5ae1`、相机 `(32.5,12.0469,32.5)`、视距 24、
相同透视纹理与 R16 深度路径；物理冻结，每场景重启、预热 20 秒、测量 4 秒、重复两轮。

| 固件 | 固定画面 FPS | 转向 FPS | 固定画面 / 转向光栅 ms |
|---|---:|---:|---:|
| 本轮当前代码基线，O2 | 8.88 | 8.27 | 85.69 / 90.69 |
| 独立光栅优化阶段，O3 加专用内核 | 9.34 | 8.91 | 80.66 / 84.53 |
| **最终完整固件，含音频/菜单修正、小内核 IRAM** | **9.04** | **8.51** | **82.86 / 88.27** |

最终固定画面和转向分别提升约 1.7%/2.9%。仅改 O3、专用内核配 O2，
以及整合固件中的重复 Surface 检查均出现回退；不把阶段最佳数字冒充最终收益。
314 B 内循环通过 Host 的 IDF linker fragment 放入 IRAM，其他板默认关闭。
固定截图 SHA256 前后相同：
`d078a53084f80377241454528ff9c822c4928640de2af1494c59e3dd20b7b994`。
叶片孔洞、深度遮挡、视距和渲染分辨率不变。

## 正常游戏与操作

最终 0.12.3 正常游戏包实际进入新游戏、行走和转向，最后一轮显示 FPS：
静止 9.31、转向 7.76、行走 7.76。各次启动生成地图并使用默认自动视距，
因此这些数字不用于严格前后或语言性能比较。

转向/行走的注入采样到 Guest 回调均值 9.43/11.52 ms；到关联显示完成均值
150.71/148.72 ms，P95 167.02/163.34 ms。仍有可感知延迟，主要耗时为
约 100 ms 的全分辨率 Host 光栅化；不是把 ABI 分发当作主要瓶颈。
不含物理触控控制器扫描或 LCD 光学响应。

此前 pai-touch 正常游戏约 10–12 FPS，但其原生分辨率只有 296×240；Korvo 的 800×480
像素量约为它的 5.4 倍，CPU 主频只有 320/240 倍。两边默认自动视距、地图和朝向也不同，
不能把差距当作相同工作量下 S31 更慢。Korvo 已使用两核光栅；PPA 当前用于合成/复制。
整屏合成/复制约 9 ms，主要瓶颈仍是 CPU 的带深度纹理像素循环。
PSRAM 带宽竞争和 AOT/指令效率差异尚未独立测量，不列为实测结论。
跨板严格比较需固定地图、相机、画质及内部 3D 分辨率；本轮保持原生画质，没有为提高数字改用低分辨率 3D。

Host 在手势条隐藏时仍有透明输入区，旧底部背包按钮会被系统接走。
本轮补齐区域报告，游戏控件避让，3D 仍全屏；真机截图确认标题、新游戏、
暂停、继续、背包网格和返回。长按攻击已注入，具体材质挖掘时间和物品事务由原生测试覆盖。
单帧菜单的最后一次显示完成也会被收集，避免截图长期停留在旧页面。

## 内存

相同固定包、各固件重启后的首个测量窗口：

| 项目 | 基线 | 最终完整固件 |
|---|---:|---:|
| SRAM heap 稳态 | 580,452 B | 572,324 B |
| SRAM heap 本次启动峰值 | 584,612 B | 576,244 B |
| SRAM heap 稳态窗口峰值 | 580,692 B | 572,324 B |
| 可用 SRAM heap 总量 | 663,539 B | 662,995 B |
| PSRAM 稳态 | 8,031,256 B | 6,492,276 B |
| PSRAM 本次启动峰值 | 10,419,816 B | 10,419,568 B |
| PSRAM 稳态窗口峰值 | 8,032,348 B | 6,492,332 B |

SRAM heap 总量减少的 544 B 包含新增静态字段、IRAM 和对齐，计入后整机稳定占用
和启动峰值仍下降约 7–8 KiB。PSRAM 稳态下降约 1.46 MiB，启动峰值基本持平。
峰值用 `MEMORY START/STOP` 的本窗口 minima，而非历史累计值。
稀疏游戏无需预分配可选整屏 ARGB 缓冲；密集透明系统 UI 使用时才分配原容量。

固定包 Guest 线性内存 393,216 B、命令缓冲 49,152 B、AOT 文件 666,156 B、
Surface 双 RGB565 1,536,000 B、R16 深度 768,000 B、Host mailbox 0 B，均不增长。
代码映射包含在整机 heap 中；AOT 文件大小不是运行时映射量，不将重叠统计直接相加。
诊断 probe 2,112 B 仅采样时分配，原三个 LCD 帧缓冲不增加。

最终功能检查整段（包括 JPEG 截图）SRAM/PSRAM heap 峰值为 621,212/8,933,236 B。
该窗口与纯游戏窗口不同，也没有同条件功能窗口基线，不能用它宣称峰值改善。
