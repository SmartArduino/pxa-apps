The grayscale coverage subsets in ../menu-font-{10,14,18}.a8 are derived from Sarasa Gothic SC (更纱黑体 SC; Sarasa-Regular.ttc, face 1), copyright 2015–2025 Renzhi Li and contributors, under SIL OFL 1.1. See Sarasa-OFL.txt. The SC face explicitly uses mainland Chinese glyph forms and sans-serif strokes; the generator asserts the face name so a collection default or Japanese locale cannot silently replace it. Regenerate with ../../tools/generate_menu_font.py. Only the glyphs used by this UI are shipped. One atlas is loaded at startup according to viewport/density; no runtime font engine or glyph cache is linked. The 10-pixel atlas retains grayscale coverage; a Unifont bitmap alternative has not been shipped or verified on this screen.
