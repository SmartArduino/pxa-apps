# Core 2 全应用迁移中的 Voxel 回归

Voxel 生产包继续使用 C++26 / O3 和最新 Core 2 SDK。C 生产目录已移除；
冻结世界生成、UV 和渲染算法保留在 `common/cpp/tests/reference/c/voxel-craft`
供原生对照，不含可发布清单。

本轮修复文件写入、校验和加载完成后的 close 错误被忽略的问题。失败时
不再宣布存档/加载成功；原文件格式、存档槽位及渲染质量保持不变。
原生回归覆盖 close 错误，并在 ASan/UBSan 下通过。没有增加世界缓存、
请求池、帧临时容器或热路径分配。

- 32 种地图种子、3,062 棵有根树木、区块溢出回退通过。
- C/C++ 对照 98,304 个方块一致，FNV1a 为 `667de4b0`。
- 六个法线方向、不等长合并面的 UV、视锥边界和逐帧零分配通过。
- 保留深度遮挡和透明孔洞。UV 取样边界与旧路径仍有 20 个相邻纹素
  平局差异，属于既有约定，不宣称完全逐像素一致。
- 模拟器及 pai-touch：六种工具合成、错误工具、长按时长、耐久、消耗、
  背包、存档、音效触发与恢复通过。恢复后的背包 hash 与保存值同为
  `1024414608`。

验证工具效率关系，不用于游戏 FPS 结论。

真机检查使用隔离 ID `pxa-voxel-craft-cpp-ui2` 和固定游戏夹具。其本次
启动/游戏/截图窗口记录：SRAM 稳定 286,252 B、峰值 308,928 B；
PSRAM 稳定 2,937,740 B、峰值 3,386,132 B。恢复检查相应为
286,252 / 308,892 B、2,938,100 / 3,386,372 B。
这些数值包含调试截图开销，不能作为纯游戏峰值或与另一地图/构建直接
比较。原始日志另有历史累计 surface peak，不能当作这一次的真实峰值。
