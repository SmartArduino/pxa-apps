Chri-Bocchi Cat uses the exact official OBONO MIT sources at commit d4b1f041789dcd1d71907654e4025d613b4ab420. All title, cat, gift, snow, font and sound data is embedded in the original source and covered by its MIT license. The original Playtune 1.0.4 source and MIT copyright, and the licensed AVR rand reference, are retained. Frozen Arduboy2 provider copyright/license remains in ../arduboy-batch-20261010.

Owner changes are the existing Arduboy2 branch, software framebuffer clear, omitted physical startup recovery loops and LED writes, explicit AVR16-bit score/timer, uintptr_t EEPROM address transport, original byte260 narrowing to4, and defined zero for the original logo logical shift outside0..31. Logical-shift guard is an explicit interpretation of the source out-of-range AVR helper result; no AVR firmware execution was performed. All own hooks serialize/reset complete state including inactive128 BOX and64 SNOW records; observation is read only. PXA NEW reconstructs the original empty Playtune object in static aligned storage without repeated heap allocations, then resets original globals and reruns setup, while EEPROM and activity clock persist.

Original Playtune interpreter and register/16MHz timer transitions are simulated in software. Physical speaker is silent; physical OLED/LED/GPIO and a cycle-accurate AVR CPU are not validated. EEPROM is1024 byte session RAM, with no durable cross-process record. No firmware flash, deployment, security-setting change or credentials are used.
