# 钢铁黎明 / Iron Dawn

原创 PXA 即时战略游戏。等距工业战场、自动采矿、基地建设、电力调度、混合编队和三章连续剧情。所有战场图形均由应用实时绘制，没有依赖其他游戏的素材或运行时。

## 玩法

- 点选己方单位；双击同一单位选择全部同型部队。“全军”选择所有作战单位。
- 点地面下达移动指令，部队途中自动迎敌；点可见敌军集中攻击。拖动战场平移，小地图跳转，“回基地”归位，“缩放”切换三个视野。
- “部队”面板排队生产；“基地”面板选择建筑，再点己方基地周边已探索的空地施工。精炼厂完工附送一辆采矿车。
- 采矿车自动采集有限矿脉并返厂交付。补充电站，避免缺电造成生产与施工减速、己方炮塔停火。兵营生产步兵，工厂生产装甲和采矿车。
- 游骑兵适合对抗步兵，破甲兵适合反装甲；坦克承担正面交战，长弓火炮用远射与溅射压制密集目标。
- “维修”修复选中单位或建筑并扣除相应资金；“空袭”消耗 180 矿石，点可见目标施放，冷却 45 秒。“撤单”取消末项生产并全额退款。
- 战斗可暂停，约每 12 秒自动保存，并在暂停、切到后台、回指挥部时保存。重新打开后从“返回战场”恢复。大存档保存在应用私有文件中，使用两份带校验的快照及原子替换。
- 触屏是完整操作方式。方向键辅助平移，A 选择全军，Start 暂停，B 返回。菜单支持上下与 A。

## 战役

1. **灰烬里的电台**：建立赤砂前哨的经济与装甲生产线，摧毁东南敌方指挥中心。
2. **穿越静默之河**：利用渡口跨河，部队靠近中继站 8 秒完成占领，保护平民撤离 90 秒。把防线推进到电台前方，拦截敌军远射。
3. **黎明之前**：先击毁两座聚变电站，让灰塔炮塔停火，再摧毁中枢。利用火炮与空袭瓦解防御。

初次建议选择休闲难度。标准难度需要保护矿线、补充生产和掌握推进时机。战役胜利解锁下一章，可从档案重玩；保存最好用时和完成状态。

## 构建与运行

在 PXA 工作区根目录：

```sh
tools/app.sh build iron-dawn --target simulator,esp32s3,esp32s31,esp32p4 --source-root local/pxa-apps
tools/simulator.sh product --profile pai-touch \
  --package local/app-output/pai-touch/pxa-iron-dawn \
  --publisher-key local/pxa-apps/.dev-signing/publisher-public.der
```

可选 `--board doit-gamekit-2` 等目标板。设备需要触摸屏、约 4 MiB 应用线性内存预算和 PXA Core 2.1。使用现有 SDK 的 Surface 映射帧缓冲，界面按屏幕尺寸缩放，原生像素输出。实体设备帧率取决于芯片、屏幕及 PSRAM，需在目标硬件上实测。

`tools/generate_assets.py` 从工作区 OFL 字体生成应用所需的字形子集并重建原创图标；需要 Pillow、CairoSVG。字体完整声明保存在 `assets/NOTICE.txt`。

可复用规则与战役策略测试位于 `tests/`。运行程序、日志与截图统一放在工作区 `local/artifacts/iron-dawn/<时间戳>/`，不提交生成产物。
