# PXA 0.4.0 全应用发布验证

本轮使用 SDK `9cb5e6643be41e873154c4690eba3baf88b181cf`（0.4.0；Core 2.0，AOT ABI 未变）完成全部 22 个应用发布。版本、发布序号、每个完整 `.pxa` 包的字节数与 SHA-256 见 [artifacts.json](artifacts.json)。浏览器的脚本组件保留 Wasm，其余原生路径按目标编译。

- 22 个应用 × ESP32-S3、ESP32-S31、Linux x86_64 和可移植 Wasm，共 88 个包全部构建成功。
- 原生应用回归（含 Sanitizers）通过；发布 DevKit 的 114 项模拟器/SDK 回归通过。
- 全部应用更新至 app.doit.am，每个应用有 3 张实际运行截图，共 66 张。图像、版本、签名包哈希与显示参数见 [截图来源记录](screenshot-provenance.json)。实验室应用的多图展示不同屏幕配置；输入法由真实签名 Provider 与系统输入客户端共同运行。
- 对公网四个 0.4.0 Host profile，逐个申请下载票据并完整下载 88 个包；核对目录版本/序号、Content-Length、下载字节数和 SHA-256；全部通过。
- 逐个检查 66 张公开截图可解码、应用介绍与网页图片引用正确；全部通过。原始记录见 [public-verification.json](public-verification.json)。
- 发现并修复商城在升级能力快照后可能优先返回 Wasm 的问题：同版本优先匹配芯片与 ABI 的 AOT 包，不兼容时才回退 Wasm。后端增加回归检查，33 项测试通过。

本轮保留旧包与历史截图，更新媒体使用内容摘要识别并可安全重试，没有覆盖已发布的包。截图采用桌面 product 模拟器，并非设备性能测量；模拟器中的单应用 Host 未配置商城系统安装服务，因此本轮额外安装点击检查返回“不支持安装”。已验证的是公开签名包的完整下载与通用安装逻辑回归，不把它写成实机商城安装成功。也未重新烧录设备或测量游戏 FPS/触摸延迟。

SDK/工具链、容器与五板固件由各自发行页提供。主机端原生 Windows/macOS 编译器不包含在此次发行中；跨平台方案使用容器构建和宿主机 Python/PXADB 串口调试。
