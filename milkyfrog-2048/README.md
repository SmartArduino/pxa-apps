# 奶蛙2048超级版

将 [奶娃2048超级版](https://game.0z.hk/game/2048/) 适配为 PXA 独立应用 `pxa-milkyfrog-2048`。保留十二阶奶蛙造型、合并笑声、特殊解锁声音与冰块音；目标为 2048，最高形态 4096。源码中的 `core.hpp` 使用有界棋盘实现四向压缩和每步一次合并。

在棋盘内滑动或用方向键移动。B / 右侧「撤销」撤回一步，X / 暂停菜单「重新开始」开启新局。「奶蛙图鉴」展示已解锁形态，「自动」开关使用简单的空格与合并得分策略逐步移动。它不保证最优解。右侧「声音设置」或 Y 可独立开关录音和音乐，并试听原版笑声；音乐默认关闭。

整盘、一步撤销、得分、最高分、步数、解锁图鉴和声音偏好保存为带版本与校验的 64 字节存档。图鉴与最高分不会因撤销或重新开始而丢失。START / 右上角菜单暂停；系统菜单提供继续、重新开始、退出和中英文切换。

构建、模拟器验证和素材再生见[共用层说明](../common/milky-frog/README.md)。PXA 适配代码以 MIT 提供；图片、录音与形象权利见 `assets/THIRD-PARTY.txt`，原文件来源与 SHA-256 见 `SOURCES.json`。
