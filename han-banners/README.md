# 三国逐城

原创 PXA 单人三国策略游戏。新建战役后直接选择刘备、曹操或孙权，默认从赤壁前夕起兵，也可以在同一屏换到另两个历史时期。在 72 季内统一 56 处城关。各时期的初始城池、驻军、可用武将和夺城悬赏不同。

| 剧本 | 开局局势 |
| --- | --- |
| 208 年 · 赤壁前夕 | 曹军已入荆州，刘备驻夏口，孙权以柴桑为据。 |
| 214 年 · 益州攻守 | 刘备进入益州，刘璋守成都，曹军与孙权分守淮南与江东。 |
| 219 年 · 襄樊相持 | 汉中易手，刘备军与曹军在襄樊对峙，江东可从长江进兵。 |

战局从汉末史实展开，驻军、争夺与悬赏按玩法配置。城点以遗址或古县治附近为锚，使用现代地貌作底图。道路采样河谷、渡口或关隘的代表点，线段是区域尺度的交通走廊示意。秣陵在 212 年改为建业并移至石头城附近，许都在 221 年改名许昌。

### 战役难度

| 难度 | 开局与敌军行为 |
| --- | --- |
| 入门 | 开局多 120 金和 160 粮，前四季没有敌军主动攻城。敌军会判断攻城胜算，会战使用基础方阵。 |
| 常规 | 前两季为备战期。敌军会衡量城防、据点价值和出兵后留守的兵力，从相邻后方调兵补防，会战中会强攻、固守和发动将技。 |
| 群雄 | 前一季为备战期，进攻敌城多耗约两成粮草。敌军有把握时更重视夺取别家诸侯的最后据点，补防规模也更大。会战中会用邻路盾兵掩护或集中火力，也可能出城攻击攻城器械所随的战线。 |

难度在新建战役时选择，随战役存档。旧档继续时按常规难度运行。敌城每季补兵受当地物产和城防影响，邻城增援可以突破当地的补兵上限。已发出的敌军号令会显示在战场和号令面板，敌军协战会在战线图上用红线连起两路。看到「敌将蓄势」或守军扑向器械时，可调阵、固守或回撤。敌方将技一场只发动一次。常规和群雄的敌军败势明显且有退路时会提前示警，存活的撤军会回到原出发城或邻近的本方城池。

## 怎样玩

- **治城**　选己方城，点「内政」可征募、屯田、筑城、兴市、安民和搜寻。民心影响征募与季收入。任命太守可加快民心回升、补充守军并增加收入，也会占用一名可领军武将。
- **多城经营**　在「军议 → 领地」查看各城的守军、太守和自治方针，有敌袭时告急城排在首位。每城可直接打开内政或设为出发地。太守可选「民生」或「守备」，季末自动增加民心和钱粮，或补充守军。民生收益随智力提升，守备补兵随武力提升。自治无需花费政令，太守卸任时暂停，接任后恢复。
- **政令**　控制 1–4 城时每季 2 政令，5–12 城时 3 政令，13 城以上 4 政令。全势力共用，季初补满。可以让后方设为民生、前线设为守备，把手动政令用于调兵、筑城和出征。
- **搜寻**　每座己方城池每季可派一名武将搜寻一次，花费 35 金与 1 政令。智力较高、疲劳较低的武将更容易搜得军械。搜寻也能取得钱粮、兵书，或发现可延揽的在野人才。战役共有十五位在野人物，包括庞统、张任、吕玲绮、陈到、贺齐、马良、徐庶、王平、朱然和六位原创角色，各有偏好兵种、将技与专长。分布会随剧本变化，吕玲绮按传说形象设计。入帐后从武将名册任命、领兵、装备或培养。三位君主的开局据点都能找到人才。
- **行军与调兵**　选己方城市并点「设为起点」，也可在舆图连续选中同一座己城。设好的起点会随存档保留。随后点己方目标城并选「调兵」，或点敌城选「出征」。可选先锋、偏师或主力，需一名可领军武将和 1 政令。调兵页显示实际可派兵数、出发城留守和目标城余位，调入数量受目的地容量限制。多段路线可沿道路经过己方和盟友城池，会多耗粮。急行立即出发，扎营围城等下一季抵达并降低有效城防。扎营期间道路中断时会重新寻路，无路可走便撤回。最多可同时保有三路部队，在「军议 → 军情」可查看军列或撤营。
- **领军**　每方的君主和八名本阵武将都可独立领军，另可延揽在野人才、招降最多三名敌方客将。招揽面板显示成功率，遭拒只扣四分之一的费用，同一人须等下一季才能再访。武将按历练提升至五级，连续作战会积累疲劳，换将或等季末休整。军械可从搜寻、夺城和悬赏获得。名册中的「军械」可同时配置兵器、盔甲、坐骑和军策。青龙偃月刀的普通出招可波及相邻敌阵，丈八蛇矛可从更远处拒骑，铁胎弓可远射。明光铠保护阵前武将，鱼鳞甲减少弓弩伤害。赤兔让阵前领军的该路在强攻时推进更快，的卢省粮并减轻武将受创。白羽扇减少将技的军令消耗。也可在军械页消耗金与政令购置装备，或花金操练。
- **领军职业**　猛将和统将可以使用兵器出阵或发起单挑。统将领军时，部队在更低的军心下才会溃退。军师随军入场，可在后阵施展将技或用长弓射击，阵前更容易受伤。武将名册和布阵页会标注职业。
- **专属将技**　徐庶的「断援之计」解除敌军正在执行的邻路协战，压制敌方弓弩两合。王平的「无当定军」恢复军心，让尚在场上的溃兵归阵并护军两合。朱然的「江防火矢」打击武将所在一路，减缓该路敌军推进，水战伤害更高。襄樊相持剧本的孙权军开局已有朱然。三人和十二位名将均有独立的待机、双步行走与出招帧。其他人物在会战中使用职业通用帧。
- **名将将技**　刘备带双股剑，以「同袍誓约」恢复军心并集结溃兵。关羽的青龙偃月刀能横扫相邻战线，张飞的长坂断喝能震慑敌军并打断协战，诸葛亮的八阵伏兵能护军并推迟敌军下令。武将将技和装备可组合使用。个人动画按人物的经典形象绘制，装备会改变实际出招与属性。
- **战前布阵**　「编队」可给上、中、下路各选一种兵，共有枪兵、弓兵、骑兵、盾兵、弩兵和重骑。盾兵抗箭，弩兵射得更远，对重骑有优势，重骑善冲盾阵，枪兵可挡骑兵。远程部队能射击够得着的邻线。进「阵法军械」可选阵法与武将兵器。方阵减伤，锋矢阵强化中军，雁行阵增强两翼。
- **攻城器械**　进攻二级以上城防的城池时，可在「阵法军械」带一架冲车或投石车，并指定随哪一路行进。围城已去掉全部城防时无需携带。冲车近城后可撞两次，每次削两格城防。投石车射程更长，可投三次，每次削一格并压制还在城前的守军。操作耗 14 军令，每合至多一次，所随战线失守后无法操作。会战顶部显示城防余格，战线图标出城门和器械射程。
- **长战场**　双方从两端出阵，三路各自推进。横拖战场或点上方战线图可查看远端，点「随军」恢复镜头跟随。战线图上的绿点和红点显示两军三路位置，金线标记当前视野。弓兵可以在近战接触前放箭，平地骑兵推进更快。武将出招也受距离限制。
- **开阵号令**　入场后双方停在初始位置，直到你选择「下令进军」或「按兵待敌」。待敌时我军留在原位，敌军会推进。我方可在会战「号令 → 全军」随时驻守或恢复进军，也能单独派一路推进。
- **军心与溃逃**　战损、单挑和将技都会影响军心。军心低时，伤亡重的战线可能先溃退。溃兵停止进攻和协战，部分士兵会逃出战场。能稳住军心的将技可以重新集结仍在场的部队。战报单列逃兵人数。
- **分路指挥**　会战两侧的路牌显示双方上、中、下三路的兵种和余兵。点我方路牌，或从「号令」切换到对应战线，可单独强攻、固守、迂回或回撤，每次耗 9 军令，持续两合。强攻会加快推进，固守会就地停阵，回撤会拉开距离。号令面板按当前兵力、行进路线和交战距离预报伤亡。水乡无法迂回。可从距离合适的同兵种邻路调拨，也可派邻路填补空阵。单路号令结束后随全军行动，也可手动点「随军」。「进军」可立即结束全军与分路号令。
- **号令预览**　打开全军或分路号令后，会战暂缓。点「强攻」「固守」「迂回」或「回撤」可比较我军、敌军的预计伤亡以及下令后剩余的军令，再点「下令」执行。取消后可继续比较其他战法。战场左上角的主将卡片可直接打开主将所在一路的号令，底栏显示主将在该路的阵前或后阵及体力。
- **邻路协战**　点选要支援的战线，可指定相邻一路「掩护」「援射」或「夹击」。盾兵降低所援战线的伤亡，自身攻击会减弱。弓弩和近战部队会优先攻击支援目标，敌人须在射程或交战距离内。协战不调拨兵员，耗 8 军令，持续两合，每合与增援共用一次机会。下令后可以留在面板里看更新后的伤亡预报。
- **会战指挥**　可点己方战场或从分路面板把武将调到该路阵前、后阵。手柄用方向键选位置，A 确认。武将在阵前会受该路交战波及，退到后阵能恢复体力。兵器出招优先打武将所在的敌方战线，每合至多一次，耗 12 军令。长枪能破骑，环首刀在中路破阵压低敌方军心，长弓可以从后阵放箭。换阵耗 14 军令，同兵种部队可按新阵重新分配。第一合后可下战书单挑。暂停菜单中的撤军会结束战斗。
- **战后俘虏**　部队溃败、军心跌落或主将败阵时，两军都可能俘获败方武将和一部分幸存士兵。战报分别列出伤亡、被俘和溃散。及早撤军可减少被俘风险。
- **俘虏营**　从战报或「军议 → 俘虏营」进入。敌将可放归、索赎或尝试招降。仍效忠原势力的武将较难招降，关押过季有逃脱风险，城防与民心可改善看守。敌兵可消耗政令与粮食编入守军，也可遣返安民。被俘的我方武将暂时无法领军、理政或操练，可花金赎回、等其脱逃，或攻占关押城救出武将和士兵。每季也可能有小队士兵逃脱。 [《三国群英传》招降设定](https://www.uj.com.tw/uj/Games/GamesContent.aspx?p=34)
- **外交**　在「军议」可与其他主要势力议和或结盟，均消耗 1 政令。议和花 180 金、休战三季。结盟花 240 金、持续四季，可在最后一季续盟。盟城可供军队借道，最终目的地要选己方城池或可交战的敌城。对方城外有己方军列时，先撤兵再议和或结盟。
- **请盟军出兵**　结盟后在敌城侧栏点「请盟出兵」。盟友会比较相邻出兵点的可派兵力、留守压力和目标城防。确认花 100 粮和 1 政令，本季最多委托一支盟军，季末结算，攻下的城归出兵盟友。季末军议可查看计划或撤销。主动撤销或局势变化导致盟军未出发时退还粮草。 [《三国志14》外交指令](https://www.koeitecmoamerica.com/manual/rtk14/en/6100.html)
- **季末军议**　从舆图查看季末钱粮、已探明的敌袭与即将抵达的围城部队。敌袭卡会列出进军路线和双方预计兵力。点「查看前线」或舆图页脚的「告急」可跳到受袭城，先征兵、调兵或筑城，再回来确认推进。秋粮为平季的 125%，冬粮为 90%。每季可选照常结算、花金为己方各城抚民，或耗粮为留守武将增加历练并消解疲劳。已领军出征的武将无法参加整训。
- **州郡军略**　「军议 → 州郡军略」有八项独立悬赏。每项指定三座城，有些还要求稳定当地民心。可以从目标城名跳到舆图，达成后领取钱粮与军械。每项悬赏可领取一次。

触屏点选城标或城名。双指开合可围绕两指中点连续放大或缩小。双击地图空白处可就地放大，放大后可单指拖动。舆图默认隐藏地名，点底部「城名」可显示。显示时城名随城标移动，放大可看到更多地名。点舆图右下角的司南「回城」可回到出发城。手柄用方向键选择，A 确认，B 返回或暂停。经营、出兵、季节推进和战后处置会保存进度。升级可读取十城、三十二城、三十八城与四十八城旧档，新加入的城池按原剧本初始化。离开未结束的会战后，继续战役会回到会战之前的存档节点。

标题、舆图和会战使用三首不同的循环配乐。行军、换阵、兵器交击、战鼓和战果各有音效，冲锋、号令、将技与单挑动作有普通话语音。可从标题、军议及会战暂停菜单打开「音频」，分别开关音乐、音效和语音。选项会随游戏独立保存。

## 运行与打包

在 PXA 固件工作区根目录运行。

    tools/dev.sh sim han-banners --board doit-gamekit-2 --source-root local/pxa-apps
    tools/app.sh build han-banners --target all --board doit-gamekit-2 --source-root local/pxa-apps

多架构包包含 Wasm、桌面 AOT 及 ESP32-S31、ESP32-S3、ESP32-P4 AOT。应用需要包中声明版本的 PXA GameRender 和 Assets 服务。
