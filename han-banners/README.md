# 三国逐城

原创 PXA 单人三国策略游戏。新建战役后直接选择刘备、曹操或孙权，默认从赤壁前夕起兵，也可以在同一屏换到另两个历史时期。在 64 季内统一 48 城。各时期的初始城池、驻军、可用武将和夺城悬赏不同。

| 剧本 | 开局局势 |
| --- | --- |
| 208 年 · 赤壁前夕 | 曹军已入荆州，刘备驻夏口，孙权以柴桑为据。 |
| 214 年 · 益州攻守 | 刘备进入益州，刘璋守成都，曹军与孙权分守淮南与江东。 |
| 219 年 · 襄樊相持 | 汉中易手，刘备军与曹军在襄樊对峙，江东可从长江进兵。 |

战局从汉末史实展开，驻军、争夺与悬赏按玩法配置。城点以遗址或古县治附近为锚，使用现代地貌作底图。道路采样河谷、渡口或关隘的代表点，线段是区域尺度的交通走廊示意。秣陵在 212 年改为建业并移至石头城附近，许都在 221 年改名许昌。

## 怎样玩

- **治城**　选己方城，点「内政」可征募、屯田、筑城、兴市、安民和搜寻。民心影响征募与季收入。任命太守可加快民心回升、补充守军并增加收入，也会占用一名可领军武将。
- **搜寻**　每座己方城池每季可派一名武将搜寻一次，花费 35 金与 1 政令。智力较高、疲劳较低的武将更容易搜得军械。搜寻也能取得钱粮、兵书，或发现可延揽的在野人才。六位在野人才是独立于剧本史料的原创角色，各有武力、智力、偏好兵种、将技与专长。入帐后从武将名册任命、领兵、装备或培养。三位君主的开局据点都能找到人才。
- **行军**　点己方出发城，再点相邻目标。再点一次己方目标可把它设为新的出发城。出征可选先锋、偏师或主力，并任命领军者。急行立即在地图上移动。扎营围城等下一季抵达，降低会战中有效城防。最多可同时保有三路部队，回到「军议 → 军情」可查看悬赏、军列和撤营。
- **领军**　每方有八名本阵武将，另可延揽在野人才、招降一名敌方客将。武将按历练提升至五级，连续作战会积累疲劳，换将或等季末休整。军械可从搜寻、夺城和悬赏获得。青锋剑、山文甲、赤绒鞍和行军策分别改善输出、减伤、粮耗和初始军令。名册中的「军械」也能花金操练。
- **会战**　枪克骑、骑克弓、弓克枪。山地利枪、水乡利弓、平原利骑。看敌令再换阵，并在合适时机用将技。「号令」里可下达强攻、固守或迂回，战术持续两合，水乡无法迂回。打过第一合，可消耗军令发起单挑。突刺克佯攻，佯攻破格挡，格挡挡突刺。三合结果会改变双方军心。胜负用独立题字呈现，青铜木漆窗框与体力条由图块拼接。
- **俘将与外交**　会战胜利后有机会俘获敌方武将，可放归安民、索赎得金，或花金招为客将。军议还可通商买粮、招集边军和议和三季，对方城外有己方军列时可先撤兵再议和。
- **季末军议**　从舆图查看季末钱粮、已探明的敌袭与即将抵达的围城部队。秋粮为平季的 125%，冬粮为 90%。每季可选照常结算、花金为己方各城抚民，或耗粮为留守武将增加历练并消解疲劳。已领军出征的武将无法参加整训。
- **州郡军略**　「军议 → 州郡军略」有八项独立悬赏。每项指定三座城，有些还要求稳定当地民心。可以从目标城名跳到舆图，达成后领取钱粮与军械。每项悬赏可领取一次。

触屏点选或拖动地图。手柄用方向键选择，A 确认，B 返回或暂停。经营、出兵、季节推进和战后处置会保存进度。升级可读取十城、三十二城与三十八城旧档，新加入的城池按原剧本初始化。离开未结束的会战后，继续战役会回到会战之前的存档节点。

## 舆图与地点

在舆图点选城池，打开右侧「志」即可查古城地望、该开局的史载官员与篇目。早任、后任、任期未详会在条目中注明。本局太守由玩家在内政中任命。

- 侯官取今福州市区、闽江下游一带，史书也作「候官」。商升曾任候官长。建安取今建瓯建溪河谷，贺齐于 203 年进兵建安并置都尉府。两地沿闽江与建溪相连，向北可走浙闽沿海，向西可过闽赣山地。 [《三国志·贺齐传》](https://www.shidianguji.com/ens/book/LS0004/chapter/1kview8bnwn4c) · [福州沿革](https://www.fuzhou.gov.cn/zgfzzt/zjrc/qhyg/202509/t20250925_5083026.htm) · [建瓯地名沿革](https://mzt.fujian.gov.cn/ztzl/xczmxd/dmwh/202408/t20240826_6506583.htm)
- 交趾羸娄取今越南北宁顺成古城遗址，九真胥浦取清化马江流域，日南西卷取旧广平省北部作为区域锚点。士燮领交趾太守。士䵋曾任徐闻令、领九真太守，其起讫年未详。合浦至交趾按北部湾沿岸设置水路，九真至日南沿平原和山口南下。 [《后汉书·郡国五》](https://zh.wikisource.org/zh-hant/後漢書/卷113) · [《三国志·士燮传》](https://zh.wikisource.org/zh-hans/三國志/卷49) · [羸娄发掘报告](https://baotanglichsuquocgia.vn/DataFiles/asset/upload/data_hung_/thong_bao_khoa_hoc/so_2_nam_2015/Nguyen_Van_Doan_-_Di_tich_Luy_Lau....pdf) · [清化文物](https://baotanglichsuquocgia.vn/vi/Articles/3091/55756/tong-quan-di-san-van-hoa-tinh-thanh-hoa.html)
- 鄂县取今鄂州，221 年随孙权迁治改称武昌。陈仓取今宝鸡渭水谷地。谯县取今亳州，通涡水及淮水。平原取今德州平原一带，雒县取今广汉，位于成都北面的金牛道走廊。 [鄂州地名沿革](https://www.ezhou.gov.cn/zjez/ezrw/ezdm/201906/t20190626_199225.html) · [陈仓古城](https://wwj.baoji.gov.cn/zzzb/wbwy/202309/t20230905_755253.html) · [《资治通鉴》卷六十六](https://zh.wikisource.org/zh-hans/資治通鑑/卷066)

- 番禺取今天广州南越国宫署附近。始安取今桂林，属零陵郡。临贺取贺街汉代城址一带，广信取今梧州桂江口附近作为地图锚点，广信县治具体位置有梧州、封开等说。高要取今肇庆附近，合浦取廉州草鞋村一带，徐闻取雷州半岛二桥一带的汉代古港。 [《后汉书·郡国五》](https://zh.wikisource.org/zh-hant/%E5%BE%8C%E6%BC%A2%E6%9B%B8/%E5%8D%B7113) · [始安县治](https://www.yzcity.gov.cn/cnyz/fzlc/202108/83c96efd8e244b68b865884a2fd1595b.shtml) · [临贺汉代城址](https://hz.dnr.gxzf.gov.cn/csgh/ghgs/P020231013652642211792.pdf) · [广信地望讨论](https://www.cssn.cn/ztzl/jzz/rwln/wh/wh_tswh/202209/t20220923_5541295.shtml) · [合浦汉城址](https://www.bhlib.cn/d/file/2023-06-07/a26404393e23209dd68eabf2bb012ba9.pdf) · [徐闻古港](https://www.gdwsw.gov.cn/wsbl/content/post_33067.html)
- 汉魏洛阳、许都取故城一带，邺城取今临漳邺城遗址，下邳取睢宁古邳镇故城一带。 [洛阳与许都故城](https://wgl.xuchang.gov.cn/zcfg/004006/20221228/d1fe2a74-9452-4c05-a7fc-332f0e86e1cf.html) · [邺城遗址](https://wenwu.hebei.gov.cn/system/2023/10/16/030257953.shtml) · [下邳故城](https://www.jsjc.gov.cn/zl/6736/202406/t20240618_189271.shtml) · [秣陵与建业沿革](https://www.nanjing.gov.cn/zjnj/lsyg/202609/t20260930_5920372.html)
- 关中至汉中沿褒水、斜水谷地简化褒斜道。巴蜀以金牛道和长江三峡贯通。岭南西线由湘水经灵渠进入漓桂水系，可经广信沿西江至高要、番禺，也保留潇贺古道与粤北通路。道路绘制与行军动画共用同一组折点。 [褒斜道与蜀道](https://www.hanzhong.gov.cn/hzszf/xwzx/zwyw/202604/a30d6e11f04f4246bd46089569ae4787.shtml) · [灵渠与苍梧走廊](https://www.cssn.cn/ztzl/jzz/rwln/wh/tswh/202209/t20220923_5541344.shtml)

## 运行与打包

在 PXA 固件工作区根目录运行。

    tools/dev.sh sim han-banners --board doit-gamekit-2 --source-root local/pxa-apps
    tools/app.sh build han-banners --target all --board doit-gamekit-2 --source-root local/pxa-apps

多架构包包含 Wasm、桌面 AOT 及 ESP32-S31、ESP32-S3、ESP32-P4 AOT。应用需要包中声明版本的 PXA GameRender 和 Assets 服务。
