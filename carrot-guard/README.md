# 萝卜小卫队

PXA 触屏塔防游戏。18 个关卡分为花晴原野、蘑菇秘境、荷塘寻宝、沙丘绿洲、冰雪乐园和糖果王国六个主题。每个主题以独立首领结束，关卡包含寻宝、群怪、装甲、疾速和限时挑战。原始生成场景、角色、字图、按钮和音频均保存在本项目的 `art/`。

点击空草地格建塔；点击炮塔升级或按投入的 75% 出售。出售与关闭按钮之间留出空白区；出售只在按下并松手均落在出售按钮内时执行，拖离即取消。炮塔自动朝向目标，空闲时清理射程内障碍，也可点击障碍指定集火，清除后原地可建塔。糖果炮、冰晶塔、烟花炮从第一关可用；分别通关第 3、6、9 关后解锁回旋镖、电弧塔、熔岩炮。三个等级使用不同底座，弹丸、减速、范围、燃烧和连锁效果随等级变化。炮头和底座分层，炮头有四个生成关键帧、32 个朝向。图鉴说明各塔用途和解锁条件。

准备好后点击“开始波次”，波间提前出怪可获得金币；右上角切换双倍速度或暂停。冰封技能暂停敌人移动三秒，冷却三十二秒。十颗心通关获三星，至少六颗心获二星，其余通关获一星。寻宝关须在最后一波结束前清除全部宝箱；限时关从第一波开始计时。通关解锁下一关，星级、教程和音效设置自动保存；未完成战局不跨重启恢复。存档 v2 保存 18 关成绩，兼容原六关 v1 存档；无法识别的存档保留原样。

萝卜按剩余血量比例显示四种生成外观：满血健康、70% 及以上轻伤、30% 及以上重伤、其余濒危；第一口被咬后就会出现缺口。每种外观包含常态、眨眼、受击和点击微笑四个帧；点击场上或标题页萝卜会轻跳，受击反馈优先，互动不恢复血量。怪物阴影按各帧实际脚底接触点对齐，飞行怪物保留离地高度。

画面不显示整片建造网格，只显示当前选中格和射程。地图、占地、障碍和点击共用 32×32 世界网格。`maps.json` 同时生成道路贴图与 C++ 占地数据，横屏向两侧扩展可建列，格子编号保持稳定。道路、角色和背景等比适配，背景超出视口的部分裁去；出怪口和萝卜终点均为封口，入口有生成的爪印木牌。界面按实际密度、安全区和尺寸布局，支持横屏、竖屏和圆屏触摸操作。

绘制使用 Surface 0.2 的映射 RGB565 双缓冲，线性内存固定上限 6.25 MiB。离线导出保留 PNG 的颜色、透明覆盖和全部动画帧，标题背景随代码内置，其他主题按块预载；背景准备好后才提交完整场景，避免 UI 和道路先于背景显示；战斗帧不经过 Host PNG 解码和缩放缓存。静态背景、道路和入口只在改变时重绘，透明行裁切、预乘透明颜色、整数缩放坐标与定额缓存减少拥挤场景开销。怪物按实际水平位移选择左右朝向，竖直移动保持上次朝向；动画帧直接使用源区域，避免分数密度造成缓存变体；缓存优先使用空闲区，仅在必要时整理；分配顺序按地址维护，命中采用可删除的开放寻址表。小精灵缓存完整姿态并在复制时裁剪，跨越边界不会反复缩放。预处理像素的最长不透明段省略 alpha 字节，保留原始颜色与抗锯齿边缘；圆形和圆角框按行查找边界、批量填色，仍使用原来的像素中心判定，并按尺寸缓存几何边界；固定透明色与整体透明度使用精确的 RGB565 通道查表。HUD 的文字与按钮在状态改变时才重建，顶部和底部分别缓存为保留透明圆角的像素层；金币或进度改变时保留未变化的底部面板，合成直接遍历已记录的可见行段，物体仍能从其透明边缘下经过。建造选择栏的选项、翻页和关闭按钮避开面板边框，绘制和点击共用边界，边框与选项间隙不触发建造。Surface 双缓冲分别记录上次实际写入的行，只从静态底图恢复这些行；首次使用、换图、尺寸变化或绘制失败会恢复完整画面，避免残影。完整画面未改变时不提交。按钮边框使用共享物理边界的九片拼接，只绘制一层边框；进度条保留端帽，宽 Boss 血条仅延展中段。

游戏和音频实现位于本项目，直接调用 PXA 公共接口，不引用其他游戏及 `common/pxa_game_*`。配乐由 ComfyUI ACE Step 1.5 Turbo 生成，14 种短音效由 Stable Audio 3 Small SFX 生成，无参考歌曲。`art/audio/` 保留工作流、提示词、种子和原文件。Host 流式循环 Ogg 配乐并混音已准备的 S16LE 短音效；音频不依赖帧率推进。静音和后台暂停音频，权限拒绝时游戏仍可使用。像素解压使用公有领域 miniz 1.15，完整原始声明保留在 `vendor/miniz.c`。

在工作区根目录使用锁定的 DevKit 0.11.0：

```sh
SDK="$HOME/.local/share/pxa/releases/0.11.0/bin/pxa"
APP=local/pxa-apps/carrot-guard
"$SDK" run "$APP" --offline --debug
```

修改内容或美术后依次运行 `tools/import_content.py`、`tools/import_expansion.py`、`tools/import_actor_states.py`、`tools/compile_pixels.py`（扩展导入会一并调用地图与界面导入）。最后一步将 PNG 导出件保留在 `art/runtime/`，生成运行像素库和背景二进制，避免包内携带重复图片；图标保持 PNG；`text_bounds.hpp` 从字图可见笔画计算居中位置，透明边距不会影响对齐。文字和数字均按包含抗锯齿描边的可见区域限宽、等比缩放，价格图标与数字作为一组居中。导入器依赖 Pillow，音频导入另需 ffmpeg 和 numpy。原始生成图及提示词不要删除，素材未改时无需重新导出。

验证程序位于 `tests/`：

- `campaign_test.cpp`：18 关合法经济策略、解锁、寻宝、计时、装甲、分裂和首领能力。
- `core_test.cpp`、`grid_test.cpp`、`map_assets_test.py`：建造升级出售、胜负、集火、弹丸目标复用及 18 张地图的网格一致性。
- `pixel_renderer_test.cpp`：图集裁切、左右镜像、透明合成、双缓冲恢复、缓存淘汰、密度换算、分区 HUD 更新及背景无需异步读取；`ui_assets_test.py` 检查数字完整笔画与基线。
- `text_layout_test.cpp` 使用真实像素检查文字、长数字、价格组合及暂停图标在五种缩放下的边界与居中；`carrot_visual_test.cpp`、`actor_assets_test.py` 检查血量外观、点击和受击优先级及生成帧的落脚点。
- `blend_test.cpp`：逐透明度、逐通道检查查表混合与原始整数运算一致。
- `audio_test.cpp`：音频路径、14 种音效、静音、后台恢复、停止和权限拒绝。
- `basic.json`、`grid.json`、`placement.json`：真实模拟器中的基本操作、相邻格建造和清障；`complete.json`、`loss.json` 覆盖通关与重试；`sell.json` 检查拖离取消、关闭旁的留白区与明确出售。
- `check_evidence.py` 检查状态、原始截图、运行异常和资源拒绝，仍须逐张查看截图。

使用 `deps/pxa-system/ai/skills/pxa-debug/scripts/verify_app.py`，传入 `--pxa "$SDK" --headless --output local/artifacts/carrot-guard/<时间戳>/<场景>`、配置和场景。商城截图另加 `--store-screenshots`。`CARROT_TEST_SPEED` 只加速模拟时间，用于完整通关测试；`CARROT_PERF_PROBE` 禁止写存档并提供固定绘制压力场景，叠加 `CARROT_STRESS_PROBE` 为 24 炮塔、36 怪物，`CARROT_GALLERY` 用于六主题截图。叠加 `CARROT_LIVE_PROBE` 时改为运行真实移动、寻敌和弹丸逻辑，并补充被击败或离场的怪物；压力模式保持约 36 只怪物，未叠加时保持 6 只。它仍禁止写存档；`perf_probe_test.cpp` 检查 480×854 视口的实际 24 座炮塔、怪物补充、移动、射击与击杀。`CARROT_VISUAL_PROBE` 为不写存档的界面、血量外观及阴影检查场景。交付包移除全部测试宏；`CARROT_PROFILE` 仅输出构帧、绘制提交、帧间隔和缓存采样。模拟器性能不能替代真机测量。保留锁文件、签名身份和已有存档。
