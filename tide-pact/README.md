# 大航路时代 · 潮汐之约

一款 PXA 航海经营冒险游戏。你从十五世纪末的里斯本接手一张海图，循着可疑的灯标寻找失踪的制图师。可自由选择停靠港口，在通商、测绘和港口委托之间筹措远航经费。主线有六章和两个结局，另有三条跨港支线、护航和码头决斗故事。结局后可继续经营和探索。

## 航行与操作

- 触屏点选港口或打开目的地清单。拖动海图，使用加减按钮缩放，使用定位回到船的位置。
- 在里斯本、丰沙尔、拉斯帕尔马斯和加的斯靠港后，可从「港务 → 进城」进入港区。点路面可沿街走动，点标牌可走进市场、船坞、商会、档案室或酒馆。实际开放的设施随港口而异。在设施内点底栏「回城」可回到街上，走到码头可回海图。
- 港区上方的找人按钮会带船长去见当地人物。谈过的见闻和选择可以在「日志 → 港口故事」重读，没办完的事可回原港继续。
- 在「海图 → 目的地 → 出海」可以直接自由掌舵，也可以点海面设定初始方向。开局海图记录了五处已知港口。船经过的区域会显出海岸细节，驶近未知港湾或测绘水域会标出地点。手动航行时发现新地点会停船，随后可以继续或驶近锚地靠泊。支持旋转的大屏设备会以横屏显示海图。
- 蓝线记录最近一次手动航行的航迹，靠泊后也可查看，会随存档保留。靠近地点时点「近岸」放大，黄色虚线标出水域允许的进港方向。进入安全靠泊范围会停船，按「靠泊」入港，也可选择继续。航迹最多保留最近六十四个位置。
- 在「港务 → 港口商会 → 打听传闻」或目的地页的「传闻」抄录水手的消息。海图上的虚线问号圈出大致海域。故事指路和明确的领航线索可以直接记下泊地。自动航行只能选择已定位地点，沿已知航路经过陌生水域时也会逐步测出海岸。
- 「港务 → 港口商会 → 口译与学话」可请本港口译，或用船金和停泊时间学习。会短语时能认出方位、地形或货物词；通晓后可以抄录完整传闻。随船副官会为自己熟悉的语言代译，候任时也能帮忙。口译在本次停泊期间有效，学会的语言和已抄录的线索会随存档保留。
- 「航前计划」和「航段与停靠点」会标出已知港口的沟通状况。进市场先选货，再点「议价」。花一日可谈一次五件整批买入，会短语可减价 4%，通晓本地语言或有人代译可减价 8%。折扣用在该货物的一次五件订单，离港失效。
- 档案的书写语言和证人的口语可能不同。加的斯的《两岸渡船记》用阿拉伯语写成，证人说卡斯蒂利亚语。丹吉尔的「两岸潮簿」可带到加的斯核对，译清风向和水流后，可公开双语本或交还原主。
- 手柄用方向键移动焦点，A 确认，B 返回。海图上可用 Start 启航或停船。游戏内的手册位于日志页。
- 标题和日志的「设置 → 界面字号」可在自动、紧凑、标准之间切换，并记住选择。自动模式在 ESPP4-A 等横屏设备上使用较小的字模，并增大海图面积、增加列表可见行数。
- 市场显示库存冷热、可成交数量和总价。批量买卖逐件计价，库存越紧，单件价格越敏感。产地补货较快，港口也会逐渐消耗库存过多的货。「比价」显示已到访港口的当日买卖报价，「市况」可查已知港口的限时收货或集中到货，以及距开市或结束的天数。
- 里斯本、丰沙尔和拉斯帕尔马斯的市场可打开「船讯」。两家商号估算抵达时的库存和市况，结合航程及船金决定买卖。成交会改变当地库存与报价，风暴会耽误船期。点船讯可在海图上标记港口，已测绘的水域会显示经过的商队。船坞提供补给、维修、休整、招募、换船和火炮。
- 「航前」显示预计天数、各航段停靠点和分别需要的食物、淡水。港内可按计划补给并多备两日份，所选航路缺粮时会在离港前提示。在测绘点缺粮或船体破损时可请求拖带回港。遭遇结束后可查看实际变化，再决定何时继续航行。战斗中能接近瞄准、齐射或尝试脱离。
- 从「航前计划」或海上抬头栏打开「风况」，可查最多三日的天气、风向和预计航速。港内可以候风一天，也可以切换帆势比较航程。海上打开预报时会停船，航线中途可改为下一站靠泊。自由掌舵只预报眼下海域，驶入另一片海域后风况会变。雨和骤风会减速，炎热会多耗淡水，缩帆可减轻骤风影响。
- 「港务 → 港口商会 → 港际运单」可接急信、货运或载客，部分载客单需要在指定中途港实际靠泊。每次接一份，押金和占舱会在接单前列出。到站交付退回押金，迟到的运费减半，退单或遇难中断会扣除押金。「日志 → 运单」可查下一港、交期和最近一次交付结果。运单和行会采购委托可同时进行。
- 从「海图 → 航前 → 掌舵」进入自由航行。点海面设航向，也可用左右舵转向，手柄支持 X 和 Y 转舵。风箭头指风吹去的方向，顺风会提速，骤风时可缩帆护船。近岸会触礁，接近图上锚地后可靠泊。
- 海图上的节数表示每游戏小时航行的海里。两种模式连续航行时均约每 1.2 秒推进一游戏日。自动航线按整日结算，自由掌舵每步推进六小时，靠泊再启航会接着当前时刻走。手动位移按纬度换算经度方向的海里数。首次读取旧版存档时，会补一份尚未到期的运单和采购委托的剩余时间。
- 船坞「食物淡水」可在共享容量内分别装卸口粮与淡水，顶部图标旁按粮、水顺序显示库存。炎热天多耗淡水，自由掌舵时下雨能接到一些淡水。老存档中的水粮数量会初始化为等量食物和淡水。
- 航前计划、海图抬头栏、风况和「食物淡水」都能打开「配给」。食物与淡水可分别节用。航行中的偶数日少发一份，每项节用分别扣三点或四点士气，炎热天仍按常量发水。航前估算和途中预报会按配给计算补给和航速。配给命令随存档保留。
- 「船坞 → 副官」可以在里斯本招募安娜、在丰沙尔招募贝阿特丽丝、在加的斯招募杜阿尔特。每次出航由一位副官当值，靠港可让其他随船同伴接任。安娜让航行更快并减轻触礁损伤，贝阿特丽丝节省淡水，杜阿尔特减轻敌炮伤害并提高接舷体力。赢得加的斯比试后，杜阿尔特会降低招募费。
- 海战中可机动贴近并瞄准，在齐射后要装填火炮。顺风、远船距和较轻的货载有助于脱离。船距为一且有至少六名船员时，可以接舷决斗。决斗中格挡克突刺，佯攻破格挡，突刺截佯攻。
- 里斯本的「港务 → 港口商会」可接受银铃号护航，击退追船后可去丰沙尔交船契。加的斯的码头比试可练习决斗，获胜后提升海上决斗体力。商会也可入股商栈，降低该港的买价。
- 金色地标标出下一处主线地点，青色地标是测绘点，已到访港口的标记会加亮。地理页提供位置、坐标和注记。存档记下已踏查的海图和抄录的传闻，旧存档会保留已到访和已测绘的地点。
- 里斯本、丰沙尔、加的斯和埃尔米纳的「港务 → 档案室」提供考察手记。抄录时开始计时，可自费出海领取全额赏金，也可先领资助并在交稿时接受较低尾款。向当地水手问话还能得到可标记在海图的地点和观测提示。
- 抵达指定的测绘水域后，从海图进入「考察」。在锚地等待或实际观测各耗一天水粮。阿尔金须等沙洲露出，骤风时先避风。记录带回原港入藏，抢先观测有额外声望，晚到仍可提交复测。「日志 → 考察簿」可查进度与馆藏插画。
- 日志中的「港口故事」可查看支线去向和已完成的结局，海上纪事保留最近三次遭遇。带上木料、海盐和完成测绘，可以在相应的海上事件中多一种应对方式。
- 阿尔金外海可能遇见断桨的小船。送木料或领小船绕过浅滩，可得到一条海图线索。赤道附近遇到静风时，能用织锦接雨补充淡水，也能请领航副官找风。等风和绕浅滩会花一天，并按配给消耗水粮。
- 丰沙尔商会的「红漆木匣」会圈出港口西南的搜索海域。木匣随风在附近漂移，亲自掌舵靠近才能看见。风浪小时可放艇，备有木料也能架长钩，等风则消耗一日水粮。把匣里的名册带到加的斯，译出欠付的工资，再决定送交船工换取当地维修折扣，还是入档领取赏金。
- 交易、港务、剧情和抵达时自动存档。海上定期保存，回到游戏时会暂停在最近的航行记录。

## 构建与维护

标题或日志中的「设置」可单独打开或关闭配乐、航海音效和船员语音。港口、航行与战斗使用不同的配乐，PXA Host 流式播放单声道 Ogg，短音效和语音按需载入。游戏把内嵌美术保存在 `art/`，音频资源保存在 `assets/audio/`。

音频提示词与台词位于 [tools/audio-cues.json](tools/audio-cues.json)。可用 `python tools/make_audio.py 原始FLAC目录 处理记录路径` 重新生成游戏资源。模型在工作站生成，设备包只包含音乐和短录音。 [ACE-Step 1.5](https://huggingface.co/ACE-Step/Ace-Step1.5) · [Stable Audio 3 Small SFX](https://huggingface.co/stabilityai/stable-audio-3-small-sfx) · [Qwen3-TTS VoiceDesign](https://huggingface.co/Qwen/Qwen3-TTS-12Hz-1.7B-VoiceDesign)

从该目录使用锁定的 PXA DevKit 0.11.2 构建和运行。普通构建使用已经生成的资源，只需 SDK 的构建工具和 Python 3 标准库。

```sh
pxa run . --profile pai-touch
pxa build . --offline --target wasm,simulator,esp32s3,esp32s31,esp32p4
```

PXADB 安装器要求应用 ID 以 `pxa-` 开头。在 ESPP4-A 上测试时，先用 `pxa build . --target esp32p4 --aot-only --output out/tide-pact` 构建设备产物，再用 SDK 自带的 Python 执行 `tools/pack_espp4.py out/tide-pact out/pxa-tide-pact.pxa --sdk SDK目录`。设备包采用 `pxa-tide-pact`，通用包沿用 `tide-pact`。PXA 按应用 ID 保存进度，两种包各用自己的存档。

商城版沿用设备包的 `pxa-tide-pact` 标识和签名。发布时在独立的发布工作区复制本应用与相邻的 `common/`，将副本的 `package.json` 的 `id` 改为 `pxa-tide-pact`，再用 Agent Kit 的 `store build --targets wasm esp32p4` 和 `store publish-targets` 构建并提交。商城文字使用 `store.json`。

`game.cpp` 管理航行、经济、委托、剧情选择和存档；`main.cpp` 处理 PXA 生命周期、界面和输入。记录格式版本和固定地标编号保存在游戏逻辑中，扩充 `world.json` 时应保留旧地标的顺序。

`tests/voyage.cpp` 可用 C++20 编译器编译并链接 `game.cpp`。模拟器输入场景使用 `tests/journey.json`、`tests/stories.json` 和 `tests/preparation.json`，可交给 Agent Kit 的 `verify --scenario`。

## 海图与美术

海图范围为西经 45°至东经 59°、南纬 42°至北纬 72°。港口位置与近岸锚地分别记录，水域路径使用同一份陆地掩膜检查。在底图像素不足以分开直布罗陀两岸时，生成脚本保留一像素航道。游戏使用真实大致地理、简化的帆船航路与季节风模型，以及压缩的游戏时间。剧情、人物和委托是虚构的。港区画面为按区域制作的插画。

- 海岸数据来自公有领域的 Natural Earth 1:10m Land 5.1.1。可用 `python tools/make_chart.py ne_10m_land.zip` 重建海图和航路，需要 Pillow 和 PyShp。[数据](https://www.naturalearthdata.com/downloads/10m-physical-vectors/10m-land/) · [许可](https://www.naturalearthdata.com/about/terms-of-use/)
- 航速以适航时约四到五节为基础，按风向、载货量、船型和船员调整。历史量级参考达·伽马船队 1497 年从里斯本到加那利水域的航行日志。 [航行日志](https://www.cambridge.org/core/books/journal-of-the-first-voyage-of-vasco-da-gama-14971499/B37176D56DC08C06585EAE631D23BA6F/listing) · [节与海里](https://oceanservice.noaa.gov/facts/nautical-mile-knot.html)
- 语言按游戏中的说话人和文书设定。瓦伦西亚档案、基尔瓦贸易和刚果王国的口译记载提供了背景。 [瓦伦西亚大学历史图书馆](https://www.uv.es/uvweb/libraries-documentation-service/en/news/new-discovery-historical-library-1285923456427/Novetat.html?id=1286451015046) · [联合国教科文组织](https://whc.unesco.org/en/list/144/) · [刚果口译史研究](https://www.academia.edu/29773271/ARTICLE_Kongo_interpreters_travelling_priests_and_political_leaders_in_the_Kongo_Kingdom_15th_19th_century_International_Journal_of_African_Historical_Studies_49_2_2016_255_276)
- 佛得角里贝拉格兰德、埃尔米纳和基尔瓦的港口注记参考 UNESCO。开普航路时代背景参考英国国家海事博物馆。[里贝拉格兰德](https://whc.unesco.org/en/list/1310/) · [埃尔米纳](https://whc.unesco.org/en/list/34/) · [基尔瓦](https://whc.unesco.org/en/list/144/) · [开普航路](https://www.rmg.co.uk/collections/objects/rmgc-object-14176)
- 标题字标、场景、角色、货物、航海图标及界面材料由内置图像生成工具为游戏制作。帆船循环为 12 帧，炮击为 8 帧，决斗的三种出招各 6 帧。接舷和码头背景及序列图保存在 `art/`。素材可用 `tools/make_art.py --help` 查看预处理入口。
- 考察插画使用四联图，可用 `tools/make_discoveries.py` 生成运行时图集。阿尔金生态和本格拉寒流注记参考联合国教科文组织与 NASA。游戏按日离散潮汐与天气，手记、考察人物与竞赛为原创虚构。 [阿尔金浅滩](https://whc.unesco.org/en/list/506/) · [本格拉寒流](https://science.nasa.gov/earth/earth-observatory/namibia-3464/)
- 三位副官的原创肖像由内置图像生成工具绘制，用 `tools/make_officers.py` 从三联图生成运行时图集。
- 港区插画按四座港口的地景绘制，街道和建筑为游戏布局。用 `tools/make_town_art.py --help` 查看地图、设施图标和角色行走帧的预处理方式。
- 港城见闻使用内置图像生成工具绘制的四人头像。用 `tools/make_port_people.py --help` 将四宫格整理为运行时图集。
- 港城牌匾、按钮和对话纸的纹理使用内置图像生成工具绘制。用 `tools/make_port_ui.py --help` 生成四边可缩放的图集。
- 运单图标使用内置图像生成工具绘制。用 `tools/make_dispatch_icons.py --help` 将透明横条整理为游戏图集。
- 晴天、炎热、雨天和骤风的图标由内置图像生成工具绘制。用 `tools/make_weather_icons.py --help` 将透明四宫格整理为天气图集。
- 浅滩小船和赤道静风的事件插画由内置图像生成工具绘制。用 `tools/make_sea_stories.py --help` 生成两幅插画的游戏图集。
- 标准字模来自 Noto Sans CJK SC。紧凑字模使用缝合像素字体 12px 的简体中文比例版，缺字由 Noto Sans 补齐。增加文字后运行 `python tools/make_font.py NotoSansCJK-Regular.ttc --compact-bdf fusion-pixel-12px-proportional-zh_hans.bdf` 更新两个字模。[Noto Sans](https://github.com/notofonts/noto-cjk/tree/main/Sans) · [缝合像素字体 2026.11.10](https://github.com/TakWolf/fusion-pixel-font/releases/tag/2026.11.10)
