# 重力游乐场

离线 PXA 体感小游戏，包 ID `pxa-gravity-play`。包含摇摇骰子和星光弹珠迷宫，不需要网络、SD 卡或音频权限。

- **摇摇骰子**：一颗或两颗六面骰子，轻摇设备、确认或触摸骰子均可开始；显示点数合计和上次结果。加速度检测连续摇动，角速度参与翻滚动画，带触发冷却，避免一次动作连续出结果。
- **弹珠迷宫**：12 关固定种子的迷宫，收集三颗星后滚到金色出口，保存解锁进度和每关最好用时。横屏、普通竖屏和长竖屏分别使用适合比例的棋盘。球体惯性、摩擦和小步碰撞在应用中计算，静止画面保留，只有弹珠移动到新像素或计时等内容变化时重绘，绘制通过公开 GameRender 接口提交，无需 Guest 全屏像素缓冲。
- **校准与控制**：进入或恢复体感迷宫后保持设备不动约一秒，当前位置作为水平基准；向四周轻倾控制弹珠。暂停页可重新校准，或切换按键练习。设置提供三档灵敏度和每次90度的方向调整，用于不同设备的安装轴向。
- **三按键**：首页、设置、骰子工具栏与暂停页均用 ↑↓选择、确认执行。体感迷宫确认暂停，↑重新校准。按键练习中弹珠自行前进，↑↓转向，确认暂停。触屏迷宫支持按住并拖动控制，触摸右上角暂停。
- **前后台与断流**：暂停、回首页或退到后台时释放传感器订阅；后台停止游戏时钟，回前台从暂停页恢复。体感样本超过400毫秒未更新时冻结弹珠和计时，继续保留暂停入口。角速度不可用时仍可用加速度摇骰子；体感不可用或未授权时可以改用按键或触屏。

Gen4 使用 QMI8658，通过 `motion.acceleration` 和 `motion.angular-velocity` 语义发现传感器，并请求对应的 `sensor.read` 权限。采样周期遵循设备公布的范围，Gen4 为50毫秒。应用不会直接操作 I²C，也不会在首页持续订阅传感器。方向基准按 Gen4 的传感器安装方向设置，其他设备可在设置旋转方向。

支持 PXA Core 2.1、Window 0.3、GameRender 1.5、Assets 2.2、Sensor 0.1。绘制目标为约30帧每秒；大屏优先使用整数2倍输出，实际帧率取决于屏幕和 Host。没有传感器的模拟器可用按键练习；电脑确认键支持 Enter 或 Z。

## 构建

在 `pxa-projects` 根目录执行：

```sh
tools/app.sh build gravity-play --board doit-gamekit-1 --target esp32s3 --aot-only \
  --source-root "$PWD/local/pxa-apps" --output "$PWD/local/app-output/gravity-play"
```

模拟器包将目标改为 `simulator`。图标为本应用原创 SVG；字形图集由 `tools/generate_assets.py` 从工作区 Noto 字体生成，保留在资源中，安装时无需系统字体覆盖这些文字。重新生成需要 Pillow、fontTools、CairoSVG。

## 测试

`tests/test_core.py --output <本地产物目录>` 使用 AddressSanitizer/UBSan 验证地图连通、沿路线实际通关、碰撞边界、校准、陈旧样本、摇动冷却和骰子分布。

`tests/build_motion_simulator.py` 用现有模拟器构建目录链接隔离的测试模拟器，只替换公开传感器 Provider；不修改系统或固件源码。`GRAVITY_TEST_MOTION` 指定六个整数的输入文件，依次是三轴加速度（微米/秒²）和三轴角速度（微弧度/秒）；文件缺失或无效表示读取不可用。`tests/test_simulator.py` 以实际签名应用验证三按键、摇动、校准、断流冻结、暂停恢复和多尺寸界面，截图和日志写入 `--output` 指定的本地目录。

`tests/test_touch.py` 验证不同尺寸的触摸菜单、拖动指针归属、取消，以及灵敏度和方向设置在实际重启后的恢复。

代码与图标使用 MIT；图集沿用 Noto 的 SIL OFL 1.1，相关声明随包保存在 `assets/FONT-*`。没有新增运行时第三方库。
