# 漫画

轻量 PXA 触摸漫画阅读器，固定使用 DevKit 0.11.1。

大屏（包括 espp4-a）按屏幕密度放大列表、按钮和输入框，并增加每屏列表与书源数量；240 像素高的小屏保留紧凑布局。阅读图片继续使用完整物理视口，工具栏显隐不改变画面位置。

支持拷贝漫画、瓜子漫画、我爱漫画、MangaDex、MangaKatana、MangaPill 和 MangaTown 七个多作品站点，提供搜索、书架、章节目录、正序／倒序及页码跳转。读到的漫画自动加入书架，点击书名直接续读，右侧 `≡` 单独打开目录；目录可收藏或移除书籍。旧版下线书源的条目和选中项会被清理，保留 MangaDex、拷贝漫画的收藏、章节及页码。损坏的记录保留原文件并禁用覆盖保存。

阅读占满物理屏幕，允许圆角遮挡少量画面。轻点显示工具栏，闲置 6 秒或开始拖动后隐藏；显隐不改变漫画位置或缩放。左右滑动翻页，上下拖动长页，`+` 切换整页／适宽／放大，放大后可横向平移。点底部页码输入或用 `−`／`+` 调整后跳转。按钮位于安全区域。

界面使用原生保留式控件和单张 Canvas 图片，不加载封面、网页脚本或整章预取。图片和章节按需直连源站；失败可重试，加载可取消。短暂 I/O 或超时自动重试一次，权限拒绝和限流不会无限重试。

## 书源

| 站点 | 功能 |
| --- | --- |
| [MangaDex](https://api.mangadex.org/docs/) | 搜索，简中／繁中／英文切换，仅请求 safe 内容。 |
| [拷贝漫画](https://www.mangacopy.com/) | 中文搜索、热门目录及章节分组。目录通过公开 HTTP API 获取，公开网页中的 AES 图片列表在应用内解析。 |
| [瓜子漫画](https://www.guazimanhua.com/) | 简体中文多作品目录、搜索和章节阅读，支持 WebP 图片。 |
| [我爱漫画](https://www.woimh.com/) | 简体中文目录、搜索和公开章节；解析懒加载图片，跳过隐藏图片及付费锁定条目。 |
| [MangaPill](https://mangapill.com/) | 英文目录、搜索和章节阅读，整章仅解析图片地址，图片按页下载。 |
| [MangaTown](https://www.mangatown.com/) | 英文目录、搜索和章节阅读，当前页 HTML 按需获取，图片地址在本章内复用。 |
| [MangaKatana](https://mangakatana.com/) | 英文多作品目录、搜索和章节阅读。公开 HTML 和图片地址采用有界扫描，不执行脚本。 |

瓜子漫画、我爱漫画、MangaPill、MangaTown 按 Keiyoushi 的站点协议提供原生适配，搜索、章节和图片都直接从站点获取。书源列表分页显示，保持触摸按钮尺寸；重新进入时定位到当前源所在页。

不加载 dragonx943／Keiyoushi 的 Android 插件，也不包含漫画内容。站点域名或协议改变时需要维护适配器；不包含登录、验证码或付费章节接口。没有演示书源或自定义 JSON 入口。

## 图片与存储边界

Guest 线性内存上限 8 MiB。系统直解上限 512 KiB、262144 像素，支持 PNG／基线 JPEG。MangaDex 省流图无法直解时尝试同页原图；直连站点的大 JPEG 通过应用内 picojpeg 逐 MCU 行解码并缩小，再生成有界 PNG 交给系统显示，不分配整张原图。原图下载最多 4 MiB，成功后删除临时文件，中断残留在下次启动清理。渐进 JPEG 由应用内 JPEG 专用解码器处理，原图最多 1048576 像素，解码分配上限 6 MiB；缩小后仍最多 262144 像素。WebP 在应用内逐块解码并缩小，编码输入最多 1 MiB、源图最多 8388608 像素、解码器分配上限 4 MiB、输出最多 262144 像素。透明区域合成白色；动画容器仅显示首个完整画布帧。超出预算或部分画布首帧会提示错误。

书架最多 24 部，每章最多 512 页。JSON 上限 96 KiB，拷贝漫画公开章节 HTML 上限 192 KiB，MangaKatana 页面上限 256 KiB、整部目录上限 512 KiB；新增站点目录页上限 512 KiB，整部章节目录上限 1 MiB、4096 章，章节页上限 256 KiB。保存采用临时文件加原子替换，不提供离线整章下载。

## 构建与验证

```sh
pxa build . --target simulator --offline
pxa run . --profile doit-gamekit-2 --debug
pxa build . --target simulator,esp32s3,esp32s31,esp32p4 --offline
```

GameKit 2 使用 ESP32-S31 AOT，与 ESP32-S3 不通用。模型、来源解析、图片兼容与触摸场景位于 tests。测试服务仅用于开发验证，不是应用书源，测试漫画不会打包。编译 sources_test.cpp 时将 vendor/tiny-aes/aes.c 以 C 编译，定义 CBC=1、ECB=0、CTR=0。

验证产物写入工作区忽略的 local/artifacts。商城分别提供 Wasm、ESP32-S3、ESP32-S31 和 ESP32-P4 包，保持相同应用 ID、签名、版本及发布序号；截图必须来自真实模拟器的矩形视口原图。

默认使用拷贝漫画。部分固件与 MangaDex 的 TLS 握手不兼容，连接失败时可切换拷贝漫画或 MangaKatana；不会通过关闭证书校验来连接。
