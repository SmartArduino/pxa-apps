# 漫画

轻量 PXA 触摸漫画阅读器，固定使用 DevKit 0.11.1。

大屏（包括 espp4-a）按屏幕密度放大列表、按钮和输入框，并增加每屏列表与书源数量；缩放同时受视口宽高约束，ESP-Mosaico 等 480×480 高密度方屏不会被放大到每屏只剩一条列表；240 像素高的小屏保留紧凑布局。阅读图片继续使用完整物理视口，工具栏显隐不改变画面位置。

支持拷贝漫画、瓜子漫画、我爱漫画、MangaDex、MangaKatana、MangaPill 和 MangaTown 七个多作品站点，提供搜索、书架、章节目录、正序／倒序及页码跳转。读到的漫画自动加入书架，点击书名直接续读，右侧 `≡` 单独打开目录；目录可收藏或移除书籍。旧版下线书源的条目和选中项会被清理，保留 MangaDex、拷贝漫画的收藏、章节及页码。损坏的记录保留原文件并禁用覆盖保存。

支持双指围绕手势中心缩放，最多放大到适宽的 4 倍；缩放后可单指平移，双指操作不会误触翻页。窄屏列表保持单列，宽屏可使用双列书架和发现列表。

阅读占满物理屏幕，允许圆角遮挡少量画面。轻点显示工具栏，闲置 6 秒或开始拖动后隐藏；显隐不改变漫画位置或缩放。左右滑动翻页，上下拖动长页，`+` 切换整页／适宽／放大，放大后可横向平移。点底部页码输入或用 `−`／`+` 调整后跳转。按钮位于安全区域。

书架的「设置」可选择自动／条漫／分页阅读、开关自动缓存及清除缓存。条漫模式将相邻图片拼成连续画布，同一次拖动可跨越图片边界，缩放作用于整列图片，向上回看会自动载入前一张。缓冲未完成时停在已加载内容边缘并保留待滚动距离，完成后继续，不在松手时翻页。滚动加载与磁盘缓存开关独立；关闭自动磁盘缓存仍可连续阅读。当前图片显示后按需预取后续图片；跳页、离开阅读或撤销权限会取消预取，前台请求优先。自动模式优先使用 MangaDex 的 Long Strip 标签，否则以高宽比大于 1.8 的长图作为提示并随书架保存；不会因后续图片被切短而反复切换模式。没有标签的短切片无法可靠自动识别，可手动选择条漫。拖动时使用快速采样，松手恢复平滑显示。

空间充足时，自动缓存已处理的页面，最多 64 MiB／128 张，并按最近使用顺序淘汰。缓存以作品、章节和图片序号为键，复读时不因 CDN 图片地址更换而重复下载；旧版本以 URL 为键的缓存仍可读取。最近阅读章节的图片地址也会保存，以便重启后直接命中已缓存页面；这不等于已下载整个章节。缓存和索引位于应用私有数据中，跟随应用安装位置；安装到 SD 卡后也缓存在 SD 卡。清除缓存不删除书架与进度，正常卸载由系统连同私有数据删除缓存。通过固定应用媒体根只查询同一安装卷的剩余容量，页面仍写入私有数据。保留至少 2 MiB 空间，并仅将额外可用空间的一半纳入缓存预算；旧 Host 无法报告容量时暂停新增磁盘缓存，内存滚动缓冲不受影响。不再写入大文件探测容量，避免稀疏存储扩张；升级时清理旧版探测文件。存储写入失败时淘汰较旧缓存，前台下载最多重试一次。不写公共漫画文件。

界面使用原生保留式控件和一个 Canvas，不加载封面、网页脚本或整章预取。当前图显示后，按视口与内存预算预取后续图片，常规提前 4 张，短分片可继续加载以填满视口；一个可取消的生产者顺序复用下载与处理缓冲，翻页和离开阅读会取消它。相邻图片按实际驻留字节保留，最多 12 张邻图／4 MiB；达到 Host 资源限额时保留已经成功缓冲的邻图并收缩窗口，资源压力事件还可释放邻图。SDK 未提供原始 PSRAM 剩余容量查询，不按板型猜测。兼容转换取消固定 256 色调色板。有损 WebP 和需要兼容处理的 JPEG 优先编码为高质量 4:4:4 基线 JPEG（95，编码超限时逐级到 90／85），保留尺寸并减少存储和显示内存；不是无损转换。已缓存结果直接解码，不再次转码。无损 WebP 优先使用完整 RGB 加无损 PNG 压缩；若超过 Host 的 512 KiB 编码上限，先使用每通道 5 位的舍入（保留空间分辨率），仍超限才缩图。原始 JPEG／PNG 在系统支持时直接解码，不为像素尺寸提前强制转换。WebP 已缩放到目标尺寸时直接借用 RGB 输出并提前释放解码器，不再复制整张图片。解码与压缩按时间预算分批执行；写盘也在每批之间让出执行时间。网络图片使用 16 KiB 接收缓冲；不超过 512 KiB 的编码输入先留在 Guest 内存，大 WebP 不再为兼容解码反复读取临时文件。更大输入才写临时文件。当前图片处理时启动一个可取消的网络预取，最多先保留 256 KiB 压缩数据；其余正文及连接留给下一次读取继续消费，不重复发起请求。只提前一个网络响应，不整章并发下载；翻页、退出、权限变化会取消它。缓存命中时跳过网络及兼容转换。画质缓存使用新的键，避免继续命中旧版已减色页面。图片和章节按需直连源站；失败可重试，加载可取消。短暂 I/O 或超时自动重试一次，权限拒绝和限流不会无限重试。

## 书源

| 站点 | 功能 |
| --- | --- |
| [MangaDex](https://api.mangadex.org/docs/) | 搜索，简中／繁中／英文切换，仅请求 safe 内容。 |
| [拷贝漫画](https://www.mangacopy.com/) | 中文搜索、热门目录及章节分组。目录通过公开 HTTP API 获取，公开网页中的 AES 图片列表在应用内解析。 |
| [瓜子漫画](https://www.guazimanhua.com/) | 简体中文多作品目录、搜索和章节阅读，支持 WebP 图片。 |
| [我爱漫画](https://www.woimh.com/) | 简体中文目录、搜索和公开章节；解析懒加载图片，跳过隐藏图片及付费锁定条目。 |
| [MangaPill](https://mangapill.com/) | 英文目录、搜索和章节阅读，整章仅解析图片地址，图片按页下载。 |
| [MangaTown](https://www.mangatown.com/) | 英文目录、搜索和章节阅读，当前页 HTML 按需获取，图片地址在本章内复用。 |
| [MangaKatana](https://mangakatana.com/) | 英文多作品目录、搜索和章节阅读。公开 HTML 和图片地址采用有界扫描，不执行脚本。 |

瓜子漫画、我爱漫画、MangaPill、MangaTown 按 Keiyoushi 的站点协议提供原生适配，搜索、章节和图片都直接从站点获取。书源列表分页显示，保持触摸按钮尺寸；重新进入时定位到当前源所在页。

不加载 dragonx943／Keiyoushi 的 Android 插件，也不包含漫画内容。站点域名或协议改变时需要维护适配器；不包含登录、验证码或付费章节接口。没有演示书源或自定义 JSON 入口。

## 图片与存储边界

Guest 线性内存上限 8 MiB。系统直解的编码上限 512 KiB，支持 PNG／基线 JPEG。大屏最多请求 1048576 像素，小屏最多 262144 像素，解码宽度优先匹配物理屏幕，最高 1024；内存分配被拒绝时逐级降低本张图片的像素预算，保留当前画面。长图仍受 2048 高度及设备内存预算约束，无法保证无限缩放时保留原图细节。MangaDex 省流图无法直解时尝试同页原图；直连站点的大 JPEG 通过应用内 picojpeg 逐 MCU 行解码并缩小，再生成有界基线 JPEG 或压缩 RGB PNG 交给系统显示，不分配整张原图。原图下载最多 4 MiB，成功后删除临时文件，中断残留在下次启动清理。渐进 JPEG 由应用内 JPEG 专用解码器处理，原图最多 1048576 像素，解码分配上限 6 MiB；缩小后仍受同一屏幕像素预算限制。WebP 在应用内逐块解码并缩小，编码输入最多 1 MiB、源图最多 8388608 像素、解码器分配上限 4 MiB、输出遵循同一屏幕像素预算。透明区域合成白色；动画容器仅显示首个完整画布帧。超出预算或部分画布首帧会提示错误。

书架最多 24 部，每章最多 512 页。JSON 上限 96 KiB，拷贝漫画公开章节 HTML 上限 192 KiB，MangaKatana 页面上限 256 KiB、整部目录上限 512 KiB；新增站点目录页上限 512 KiB，整部章节目录上限 1 MiB、4096 章，章节页上限 256 KiB。保存采用临时文件加原子替换，不提供离线整章下载。

## 构建与验证

```sh
pxa build . --target simulator --offline
pxa run . --profile doit-gamekit-2 --debug
pxa build . --target simulator,esp32s3,esp32s31,esp32p4 --offline
```

GameKit 2 使用 ESP32-S31 AOT，与 ESP32-S3 不通用。模型、来源解析、图片兼容与触摸场景位于 tests。测试服务仅用于开发验证，不是应用书源，测试漫画不会打包。编译 sources_test.cpp 时将 vendor/tiny-aes/aes.c 以 C 编译，定义 CBC=1、ECB=0、CTR=0。

验证产物写入工作区忽略的 local/artifacts。商城分别提供 Wasm、ESP32-S3、ESP32-S31 和 ESP32-P4 包，保持相同应用 ID、签名、版本及发布序号；截图必须来自真实模拟器的矩形视口原图。

默认使用拷贝漫画。部分固件与 MangaDex 的 TLS 握手不兼容，连接失败时可切换拷贝漫画或 MangaKatana；不会通过关闭证书校验来连接。
