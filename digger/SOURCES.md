Digger Remastered sources are pinned to sobomax/digger commit `638125eecc2a36629b886f58d7b75253894cf3d3`. The included VGA tables and built-in title are part of that Remastered source distribution; the original DOS program and original Windmill source archive offered separately by digger.org are not inputs to this port. Retain the original author credits and every per-file notice.

The engine is distributed under GNU GPL version 2 together with its original mixed permissive notices. The adapter and independent bitmap font retain their MIT notices. microsippy uses BSD-2-Clause; the MD5 implementation selects its offered MIT-0 option. The independent application icon has its own MIT notice. Full notices intended to accompany the binary are under `assets/licenses/` and `assets/ICON-LICENSE.txt`.

When distributing object code, provide a corresponding source companion alongside the same download. It must include this application's compiled C/assembly files and headers, `CMakeLists.txt`, `package.json`, the used `../common/retro-games/` headers, the exact PXA Guest interface/build-source files, all notices, and the build/install instructions. Include upstream `engine/title_gz.c`, the decoded/editable pixel table `engine/title-decoded.c`, and `tools/decode-title.py`; the transformation is zlib decompression without image changes. Verify it with `python3 tools/decode-title.py --check engine/title-decoded.c`. Both source encodings are supplied; no original art-authoring file is claimed. Include the PXA-specific source change notices and SDK lock/identity information. Do not substitute an unpinned upstream checkout for the modified PXA sources.

Use a normal SDK workspace and a developer signing identity. The validated recipe uses PXA DevKit 0.11.1, WASI SDK 34/Clang 23 and Binaryen 133. It requires `--no-wasm-opt` support. Configure the selected SDK explicitly and migrate the copied project's SDK lock through the normal tooling. Build the explicit Release portable target and, where needed, the supported native target with the same source. The publisher private key is not part of the source companion; use the SDK's normal developer-signing workflow for modified packages.

The SDK/runtime license companion covers PXA MIT interfaces and the standard WASI/LLVM runtime family; it does not apply the application's GPL to separately running Host services. No additional restriction on the GPL program is created by a temporary private release hold.
