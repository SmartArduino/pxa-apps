# 奶蛙的奶块雨

将光影集的[奶蛙的奶块雨](https://naiwa-milk-rain.pages.dev/) 适配为 PXA 应用 `pxa-milkyfrog-rain`。保留五类掉落物、三颗心、开局十五秒保护、大小变化、速度与双倍加成、三连击双倍、五连击大笑清屏，以及原版笑声、提示音、特殊录音和背景音乐。大笑动作从原版图集中提取二十帧；画面按小屏重新布局。

点击「开始接奶块」或 A 开始，拖动屏幕左右移动，手柄持续按住左右键也可以。B 返回首页，Y 进入声音设置，START / 右上角菜单暂停。声音设置可以分别关闭笑声与音乐，并试听原录音。切换中英文使用公共暂停菜单。

保存最高分与声音偏好，当前正在下落的奶块不跨进程恢复。游戏计算使用 20 ms 有界步进，暂停期间不消耗倒计时与加成。静音、声音权限拒绝或音频设备不可用时仍可继续游玩。

构建、验证和素材来源说明见[共用层](../common/milky-frog/README.md)、`SOURCES.json` 和 `assets/THIRD-PARTY.txt`。适配代码的 MIT 不改变原图与录音的权利归属。
