# Marble Islands

Marble Islands 是为 PXA SDK 2.1 编写的八关滚珠游戏。画面由原版 small3dlib 0.905d 实时投影、光栅化和深度测试：岛面、厚度、墙、弹柱、潮汐门、宝石和多面体滚珠都是真实三维网格。关卡、图标、文字与合成音效均为本项目原创。

仅保留收集、碰撞、落水与通关短音，不播放背景音乐。暂停、后台及退出由共享运行时静音；旧版棋局存档可直接升级。

界面默认中文，可在 START 或右上角共享菜单的“语言 / Language”中切换中英文。教学、关卡名称与提示、奖章结算、选关和操作按钮即时切换。正式包按屏幕原生分辨率绘图，使用 Host 系统字体显示清晰中英文字，长提示按UTF-8字形宽度换行。语言偏好由运行时单独保存。

## 玩法与操作

拿到当前岛上所有金色宝石，再滚入插旗的薄荷绿终点。没有护栏的边缘和水洞会让滚珠落水；短暂落水动画后自动重开当前关。通关依次解锁下一岛，已解锁关卡随时可重玩。

| 操作 | 手柄 | 触屏 |
| --- | --- | --- |
| 连续倾斜 | 按住方向键，可组合斜向 | 在游戏区按屏幕方向拖动；位移控制倾斜强度，松开归零 |
| 体感设置 | Y 或 SELECT | 底部「体感」按钮 |
| 刹车 | 按住 A | 按住右下 BRAKE 圆钮 |
| 重试 | X | 底部 RETRY |
| 选关 | B；方向键选卡、A 开始 | 底部 ISLANDS；轻触已解锁卡片 |
| 通关后继续 | A | NEXT |
| 暂停/继续/重开/退出 | START 打开共享菜单 | 右上共享菜单 |
| 重看教学 | 选关页 HOW TO PLAY | 选关页 HOW TO PLAY |

Gen4 三按键：竖屏自动启用「上 / 下 / 确认」焦点导航。上下循环选择金色框，确认执行；倾斜设备控制滚珠。默认焦点在右下「慢速」，确认切换持续慢速刹车，再次确认恢复普通速度；不用一直按住确认。上下在此模式下只移动焦点，不影响滚珠方向。底部选岛、重试、体感设置、右上菜单、八张关卡卡片、玩法说明、返回和通关后的下一岛均可三键操作。持有确认只触发一次，上下长按会连续选择。

横屏在体感设置的「三按键导航」行可选择自动/开启/手柄；自动在横屏沿用完整方向键操作。竖屏始终保留三键导航，避免旧存档的手柄偏好使Gen4无法返回。三键导航适合搭配体感，缺少体感时可用触屏拖动；它不把两个方向键当作二维滚动输入。慢速刹车是本次游戏的临时状态，重试、选岛、设置和重启时恢复普通速度。

触屏使用共享运行时的第一指针捕获；拖动结束、取消、切入菜单和进入后台都会释放操纵输入。刹车会快速耗散速度，也允许小幅移动，适合窄桥和转弯。选关和教学页面冻结关卡计时与物理。

每关清空即可获得铜章；时间不超过金章目标的 1.5 倍获得银章，不超过目标获得金章。通关面板展示本次奖章，选关卡展示历史最好时间和最高奖章。目标时间在通关面板列出。

| 岛 | 主题 | 金章目标 |
| --- | --- | --- |
| First Ripples | 宽岛收集与终点教学 | 26 秒 |
| Ribbon Bridge | 连续窄桥和两次转弯 | 18 秒 |
| Blue Windows | 水洞与环路 | 29 秒 |
| Tidal Gate | 弯曲单行桥和错相潮门 | 30 秒 |
| Pebble Garden | 四个弹性柱和可选通路 | 26 秒 |
| Windmill Walk | 实体墙、外环与中心潮门 | 34 秒 |
| Three Tides | 三个不同步潮门组成的环路 | 35 秒 |
| Sunset Crown | 墙、弹柱、潮门与四宝石综合关 | 37 秒 |

潮门薄荷绿时开放、珊瑚红时关闭。各门每 4.4 秒循环，开放 2.7 秒，并按所在格错相。门的碰撞与视觉来自同一关卡计时；暂停不会错过开门窗口。

## 体感操作

进入游戏后自动发现三轴 `motion.acceleration`，并在可用时融合三轴 `motion.angular-velocity`。两项 `sensor.read` 权限均为可选；加速度计用于稳定的重力方向，陀螺仪用于两帧间响应与补偿。缺少陀螺仪时可用重力体感；缺少加速度计、拒绝权限或连接失败时仍可触屏和按键操作。应用不直接绑定某个 IMU 驱动，也不引入新依赖。

初次启用、从暂停或后台回来时，把设备拿到舒服的角度，保持稳定约一秒完成中立姿态校准。体感设置支持开关、重新校准、三级灵敏度、四向旋转、左右镜像与三键导航，选项即时保存。默认轴向与现有 Gen4 体感应用一致：屏幕水平取负Y加速度，垂直取X；其他安装方向可用设置调整。中立姿态随每次连接重新建立，不把旧握持角度套到下次游戏。

正在连接、校准或加速度读数超过400毫秒未更新时，停止滚动物理和关卡计时；完整手柄模式的方向键或游戏区拖动可临时接管。暂停、后台、选关、关闭体感与退出会释放订阅和权限；恢复时重新校准。支持三轴、正确单位且最小采样周期不超过100毫秒的传感器，订阅周期按设备范围选取约50毫秒。滤波、死区、非法值与倒序样本检查均在 `motion.hpp`，异步权限、资源释放及迟到回包处理由 `motion-service.hpp` 接入共享的 `common/pocket-imu/service.hpp`。

## 构建与集成

包 ID 为 `pxa-marble-islands`，版本 1.7.0，release_sequence 11，入口 `pxa_main`，使用 `../common/pocket-play/runtime.cpp` 的回调运行时。按仓库的 PXA CMake 包流程构建本目录；不需要图形硬件、第三方运行时、网络或外部数据文件。清单声明 2 MiB 固定线性内存、64 KiB 栈和可选 `audio.playback` 权限。音频不可用时游戏与存档仍正常工作。

图标及全部许可文本位于 `assets/`，随包分发；`assets/icon.svg` 是可编辑的原创矢量版本，`assets/icon.png` 是 128×128 包图标。上游完整头文件与 README 位于 `upstream/small3dlib/`；不要格式化或修改这两个文件。

## 实现边界

- `core.hpp/.cpp` 包含八关数据、碰撞、收集、解锁、奖章及存档；不依赖平台。
- `renderer.hpp/.cpp` 独占引入 small3dlib。RGB565 场景按实际游戏区域比例选择渲染尺寸，最长边不超过320像素。使用 small3dlib 原生动态分辨率接口与透视相机，宽屏调整视角以保留完整岛屿，竖屏增加可见海面；不拉伸旧场景。32位完整 z-buffer 上限409,600字节，颜色缓冲上限204,800字节。所有光栅像素运算由 small3dlib 的整数路径完成。
- 岛面按连续行段合并，只有临水边缘生成垂直侧面；静态网格切换关卡时重建。动态宝石、门、阴影和多面体滚珠独立生成或变换。滚珠旋转由世界位置决定，不在原地自动旋转。
- 物理最大单步 10 毫秒，单次 `tick` 最多接纳 100 毫秒；斜向输入归一化。滚珠半径 0.18 格，普通阻尼 2.6、刹车阻尼 18。球与墙/关闭的门按圆与矩形碰撞，弹柱按圆与圆碰撞。物理只使用传入的前台 elapsed，不使用墙上时钟。
- `main.cpp` 提供教学、关卡选择、HUD、拖杆/刹车、通关和落水反馈，并通过共享运行时合成收集、碰撞、落水及通关短音。背景Surface覆盖整个显示区；按钮锚定布局底部，教学与结算居中，选岛卡片和设置行随高度分配空间。只有内容边距避让宿主圆角及安全区，触点按同一内容坐标逆变换。横竖屏切换不修改游戏物理、成绩或体感偏好。

## 存档

共享运行时以应用 ID 隔离存储。当前保存 104 字节，兼容旧版 88 字节，低于 SDK 2.1 的 2048 字节限制。重开、开始关卡、收集、落水、通关和每两秒请求保存；运行时在菜单、进入后台和退出时抓取当前快照。当前关卡、位置、速度、已收宝石、门计时、落水/通关状态以及全部历史成绩均可恢复。

棋局核心的88字节部分为显式小端 wire format，不依赖 C++ 结构体布局：`MISL` 魔数、版本 1、解锁数/关卡/阶段、八个奖章、八个最佳时间、当前计时/宝石掩码/落水计时、四个 Q16.16 位置速度、12 个保留零字节，以及前 84 字节的 FNV-1a 校验和。载入先在临时对象中检查长度、校验、版本、范围、奖章与时间对应关系、解锁顺序、地面/固体位置及通关条件，再整体替换；损坏数据不会部分覆盖当前状态。单局计时在一小时封顶。

104字节格式在原88字节棋局后附加：`MCTL`、版本2、开关、灵敏度、方向、镜像、三键导航模式、两个保留零字节，以及覆盖前100字节的FNV-1a32。旧版88字节载入时采用默认体感选项；1.5.0的版本1扩展保留原体感选项并默认自动导航；新格式先验证全部选项和外层校验，再原子替换棋局与偏好。

## 原生验证

在仓库根目录运行，产物目录应始终放在忽略的 `local/artifacts/` 下：

```sh
sh local/pxa-apps/marble-islands/tests/run-native.sh \
  "$PWD/local/artifacts/marble-islands/$(date +%Y%m%d-%H%M%S)"
```

`SANITIZE=1` 可打开 AddressSanitizer 和 UndefinedBehaviorSanitizer。测试不构建包、不启动模拟器，也不连接设备。

`tests/native.cpp` 使用 BFS 选择行走路线、PD 控制器驱动真实滚动物理，逐关拿齐宝石并抵达终点；途中的周期性序列化/重载也继续同一局。它另外检查刹车距离、落水、过早触碰终点、弹柱反弹、实体墙、逐位损坏/截短/非法字段的原子拒绝，以及真实 small3dlib 的球移动、宝石消失和门状态像素差异。

`tests/app.cpp` 编译实际游戏钩子，使用生产环境的共享字体，检查连续 held 输入、模拟拖杆、CANCEL/越界 UP、刹车、选关计时冻结、锁关、解锁和载入，并输出教学、游戏、选关、落水、通关及八关最长计时的 PPM 图。文字检查包含完整字形高度和顶部菜单避让，切换语言还会验证存档字节不变。默认测试中文；设置 `POCKET_TEST_EN=1` 可复跑英文。两组测试生成的所有图像和可执行文件仅进入调用者指定的本地产物目录。

## 签名包集成验证

`tests/integration.py` 复用 `common/pocket-game/tests` 的真实传输工具，接受已经签名并展开的包。模拟器通过控制 socket 发送实际控制器/触屏输入；脚本不会向宿主存档写入测试状态。

```sh
python3 local/pxa-apps/marble-islands/tests/integration.py \
  --simulator /path/to/pxa-simulator \
  --package /path/to/expanded-signed-package \
  --publisher-key /path/to/publisher.der \
  --output "$PWD/local/artifacts/marble-islands/$(date +%Y%m%d-%H%M%S)/simulator"
```

设备入口使用 `--port PORT` 替代上面三个模拟器参数，要求已安装应用、没有其他活动包且串口由测试独占。Python 环境须包含 Pillow 和 pyserial。设备模式仅用单指触屏验证游戏输入，不依赖 `controller_mask=0` 的板卡无法提供的手柄注入，也不假定游戏支持多指同时倾斜与刹车。首次启动若本应用的音频权限提示出现，脚本保存实际画面后允许音频并等待 mixer 就绪。设备模式还读取三秒前台 PERF 的实际 raster/present 样本，以面板完成间隔计算呈现 FPS；等待自动锁屏、验证后台零绘制和解锁后的同一暂停场景。`--skip-idle-lock` 可跳过等待锁屏。若设备日志明确报告 DROP，启动检查可在同一连接重放一次历史日志，只保留本次启动时间之后的记录；缺失 ready 行时还须有成功启动、画布、首帧和实际截图证据。`--device-from lifecycle` 仅补跑真实 EXIT／重启、性能与锁屏检查，`--device-from performance` 只补跑性能与锁屏；两者都不能代替完整玩法验证。游戏直接提交 RGB565 画布，前台 host raster 样本可以为零，呈现性能以有效 present 间隔为准。安装与运行设备测试须由负责设备集成的一方串行执行。

共享的玩法断言包括持续方向加速、刹车、实际拖杆、越界释放/CANCEL、菜单冻结像素和当前状态、落水自动重试，以及第一关的三宝石收集、终点和第二关解锁。模拟器默认用方向键与 A 验证手柄控制，通关多数路段同时按 A 与拖杆限制速度；终点附近仅用触屏，避免惯性提前通关后新的 A 按下事件进入下一关。设备用持续拖动验证加速、屏幕 BRAKE 验证刹车；释放后的停球检查依靠自然阻尼，不用新触摸掩盖释放问题。设备通关采用 3 像素低幅倾斜，并读回实际持久快照逐段校正方向，全程不写入测试存档。模拟器传入 `--touch-only` 可离线验证同一单指路线。`--skip-solve` 仅用于跳过该较长的实际通关检查。之后以真实 EXIT 提交当前局，等待四秒后重新启动，再验证历史成绩、位置、速度和关卡计时恢复；所有读取的保存值均独立检查格式和校验。

## 许可与来源

本游戏、图标、原创建模/关卡/声音和测试为 CC0-1.0。small3dlib 作者 Miloslav Ciz 同样采用 CC0-1.0，并额外放弃全部知识产权。完整 CC0 文本、上游附加声明、作者、来源 URL 和文件 SHA-256 记录于 `assets/LICENSE-CC0.txt` 与 `assets/NOTICE.txt`。

选岛、重试、下一岛和教程按钮均在同一按钮内松手后触发，拖出按钮或取消触摸不会执行操作。只有游戏区域的拖动用于倾斜，刹车仍支持连续按住。

触屏倾斜按摄像机水平基向量换算，向右拖即在画面中向右滚。短暂拖尾表示运动，拾取宝石时增加金色碎光和计数高亮；这些效果不参与碰撞、计时或存档。

`tests/motion.cpp` 检查校准、姿态融合、方向变换和失联；`tests/motion-service.cpp` 使用实际SDK消息编解码检查权限拒绝/撤销、降级、关闭背压和暂停后的迟到回复。`tests/motion-simulator.py` 使用真实签名包和文件驱动的公共IMU提供者验证倾斜、失联、手动接管、双语设置、重启与旧版升级；它不向存档写入测试状态。提供者可由 `common/motion-games/tests/build_motion_simulator.py` 构建为独立模拟器，输出仅放在本地产物目录。

`tests/three-keys-simulator.py` 使用真实签名包，以Gen4上/下/确认三键验证焦点不误操纵、慢速切换、体感滚动、八卡片、锁关、返回/教学、设置、语言、退出、断线冻结、重启与1.5.0存档升级。新包流程不使用触屏、START、B、X或Y；旧包升级准备使用其原有手柄快捷键。共享驱动位于 `common/pocket-studio/tests/three_keys.py`。

`common/pocket-studio/tests/fullscreen.py` 验证两款应用在240×284、240×320、320×480、480×320、240×240和296×240圆角屏上的满屏Surface、双语布局、真实触屏命中、按键及保存退出。
