# 相机

通过 workspace `org.doit.peripherals` 0.7（兼容0.6） 枚举 Host 提供的相机档位。
打开应用自动预览，点击顶部“画质”按钮依次切换 Host 提供的档位。打开摄像头需要
`camera.jpeg` 权限。方向键选择操作、确认键执行，亦支持触摸。

- 320×240预览按原始像素居中裁剪，其余档位与相册保持比例。
  PAI Touch 直接使用 Host RGB565 图像，仅提供JPEG的设备由Host解码后显示。
- 拍照保存原始分辨率 JPEG，文件名 `photo-000001.jpg` 自动递增。
- 录像将连续 JPEG 和可选Opus声音封装为MKV，使用毫秒时间戳保存实际采集节奏。
  录像与预览复用同一帧。采集、编码、存储与显示速度决定实际帧率。
  原生预览可用时，用固定64 KiB缓冲合并连续写入，内存不足时直接分块写入。
  时长由存储空间决定，缓冲占用不随时长增长。当前读取器使用32位文件偏移。
  停止时顺序追加时长标签与相册元数据，避免LittleFS回写文件头时复制整段录像。
  保存完成前断电会留下尚未完成的 `video.tmp`。
- 视频模式顶部“录音”可开关麦克风。获得 `audio.capture/microphone` 权限后，
  从Host的16 kHz单声道Opus采集流持续读取，直接写入音轨，录制期间无需解码。
  采集任务与摄像头等待并行推进，编码包队列固定64 KiB。
  麦克风不可用或权限未获准时，计时栏显示“无声”。相册回放时才解码声音，
  使用 `audio.playback/media` 权限、PCM输出和系统音量。
- 照片和视频位于应用私有文件的 `album/` 目录。正常结束后视频名为 `video-000001.mkv`。
  编号会检查已有文件，重启后继续保留旧文件，可从设备相册查看。
- 拍照写盘与录像收尾前暂停摄像头，保存后自动恢复取景。后台停止摄像头和麦克风并收尾录像。强制终止或断电可留下 `video.tmp`，完整的旧文件保留。
  空间或设备错误会显示错误，临时文件在下一次拍照或录像时重新创建。

Host 当前发布的档位均为 JPEG。PAI Touch 的 GC2145 由 Host 直接从 YUYV422 软件编码，
提供160×120、320×240、640×480。Watcher 使用 Himax 当前的原生 JPEG
尺寸。ESP32S31 Korvo-1使用OV3660硬件JPEG编码，提供320×240与640×480。
分辨率、编码、质量、最大帧长和建议周期随 profile 返回，实际可用性以打开结果为准。

构建需要工作区的 `extensions/peripherals` 与 PXA SDK，执行
`bash tools/app.sh build camera --source-root local/pxa-apps --target all`。

## 操作与相册

深色取景器，底部选择照片或视频，中央大圆按钮拍摄或开始/结束录像。
左侧相册入口以分页缩略图分别浏览照片、视频，视频缩略图显示时长。
点开后可左右滑动或通过上一张/下一张按钮切换，视频支持播放、暂停、
重播。顶部返回相册或取景器，回到取景器自动恢复预览。系统返回键逐级返回，
轻点图像可隐藏或恢复浏览控件。所有控件都可用方向键
聚焦和确认键操作。预览与相册保持原始比例，随屏幕密度和安全区域布局。

相册逐次扫描目录，每页最多六项，按安全区域和屏幕密度调整行列。
缩略图由 Host 限制到64×64，翻页后释放，文件数量不设 App 上限。视频回放按
MKV块界限创建有限 JPEG Stream，由 Host 解码，避免加载整个文件和重复 JPEG
解码器。相册也能读取之前录制的无声AVI与PCM音轨AVI。
照片与视频均由系统私有文件服务管理。

## 使用限制

摄像头和麦克风由设备及其固件提供；未接入相机扩展的桌面或浏览器 Host
可以浏览已有照片，但不能直接取景、拍摄或回放视频。麦克风不可用时录制无声视频。
存储写入仍可能同步阻塞。录音缓冲只能覆盖有限停顿，慢速 Flash、SD 卡或
底层文件分配长时间阻塞可能导致预览停顿和录音缺口。录像保存前不要拔卡或断电。
