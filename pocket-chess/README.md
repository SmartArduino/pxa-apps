# Pocket Chess（口袋国际象棋）

独立 PXA 国际象棋应用，基于 drummyfish 的 CC0 smallchesslib 0.8d 规则引擎。默认执白对轻量 AI，也可随时切换本地双人。画布 288×224，棋盘始终白方在下，棋子使用原创双色标记：中文为王、后、车、象、马、兵，英文为 K、Q、R、B、N、P。

界面默认中文，可在公共暂停菜单切换中文或 English。标题、棋子名称、模式、行棋方、将军和全部胜负/和棋原因、升变选项及操作提示随语言即时切换；棋盘坐标保留国际通用字母和数字。语言偏好由公共运行时保存，既有棋局存档保持兼容。中文采用共享 10×10 字形，英文采用 5×7 字形。

## 操作

- 方向键移动黄色光标，A 选择棋子，再移动到目标格按 A；合法目标以绿点或绿框提示。
- 触屏依次点起点和终点；滑出棋格后松手不会走棋。
- B 取消选择。兵到达底线时，在右侧选择 Q/R/B/N，再按 A；也可直接点对应升变选项。
- X 或右下角「新局 / NEW」重新开局，保留当前对战模式。
- Y 或「模式 / MODE」切换「白方对 AI」与「本地双人」，保留当前棋局。
- START 或右上角菜单按钮打开公共暂停菜单，可继续、重开、返回或退出。

支持王车易位、吃过路兵、四种升变、将军、将死与逼和。应用自动判定三次相同局面、100 个无吃子/无兵步半回合（50 回合）及明确的子力不足和棋。和棋采用自动结束，无需另行声明。复杂封闭局面的不可将死状态不做穷举判定。

## AI 与存档

AI 是入门强度的一层静态评估，考虑子力、中心、兵推进、落点受攻、将军及易位，不使用 smallchesslib 的递归搜索。每次 tick 最多生成一个棋子的合法走法，或评估一个候选走法；每步硬上限 256 个候选、320 次 tick。不会在事件回调里进行整棵搜索。它可能漏看一步将杀或组合，应按轻量陪练理解。

局面、完整的可逆走子重复检测历史、对战模式、光标、选择和待升变状态会通过公共运行时保存；AI 中途退出后从当前棋局重新计算。存档含版本、长度、范围、当前棋盘一致性及校验检查，损坏数据不会替换正在运行的棋局。单份存档最大 3531 字节，低于运行时 3900 字节存档上限（为 4096 字节控制消息保留协议头和键名空间）。

## 来源、构建和测试

上游固定提交 `aa7911f532c34b5b37a9e8f58a32ea17d2f6aa72`。`third_party/SOURCES.json` 记录三个原始文件的大小与 SHA-256；上游核心、README 和完整 CC0 许可逐字节保留。适配代码、测试、棋子和 96×96 图标也以 CC0 发布，无外部音画素材。

按仓库 PXA CMake 流程构建 `package.json`；可直接使用[公共运行时说明](../common/pocket-game/README.md)中的三目标构建和模拟器、实机集成测试命令，将应用名替换为 `pocket-chess`。SDK 2.1，主循环组件，1 MiB 线性内存上限、64 KiB 栈；使用 surface/ui/clock/window/log/storage/permission/audio 服务，audio.playback 为可选权限。

主机规则测试可用 C++17 编译 `chess.cpp` 和 `tests/chess_test.cpp`，建议启用 AddressSanitizer/UndefinedBehaviorSanitizer。测试覆盖开局 perft 20/400/8902、易位阻挡及穿越将军、吃过路兵与牵制、四种升变、将死/逼和、三次重复、正确 100 半回合和棋、存档截断/篡改及 AI 工作上限。`tests/ui_test.cpp` 与 `chess.cpp main.cpp` 一起编译，使用运行时桩验证手柄、触屏、模式切换及界面状态恢复，并按共享 UTF-8 字形尺寸检查两种语言的棋子、模式、帮助、升变、将军和全部终局界面；检查文字边界、文字重叠及语言切换前后的存档一致性。保留的上游头文件有有意的 switch fallthrough，严格警告构建可单独关闭 `-Wimplicit-fallthrough`。

## 音效

版本 1.1.2 / release_sequence 4 取消背景音乐，保留选子、落子、吃子（包括吃过路兵）、将军、终局、取消和新局音效。音效由共享运行时以 16 kHz 单声道 PCM 实时合成，不含外部录音或素材；没有操作或玩法事件时保持安静。暂停、进入后台和退出时立即清空音符并 flush Host 队列。

audio.playback 权限为可选；拒绝权限、设备不可用、异步音频打开失败或写入受阻均不会阻止玩法和存档。公共菜单保持四行顺序，所有原有棋局与语言偏好字节布局保持不变。主机测试验证静置无声、操作反馈和静置 tick 前后的存档一致性。
