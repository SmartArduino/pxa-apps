# 声屿音乐

面向 PXA GameKit 的在线音乐播放器。深色专辑界面、真实封面、逐行同步歌词、搜索、16 个持久化收藏、播放队列，以及顺序／列表循环／单曲循环。支持完整 MP3 曲目；不包含歌曲或歌词素材包。

发现页从网易云公开推荐新歌接口实时获取最多 12 首歌曲，启动时联网更新；右上角刷新或列表页按左键可重新获取。无账号时使用公共推荐，不冒充账号的个性化每日推荐。最近一次成功列表会保存为单个有大小上限的原子缓存；播放中只更新内存，暂停或停止后再提交缓存，避免存储写入阻塞音频。离线或刷新失败时保留并标明上次结果，首次联网失败显示重试状态。搜索结果与发现列表分开保存，刷新不会改变当前播放或已建立的队列。连续刷新间隔至少 10 秒，返回发现页在 15 分钟内复用当前列表。

首页点歌后进入播放页；点击“词”或按 Y 切换歌词，歌词页可上下滑动查看，同步歌词停留四秒后恢复跟随。进度依据 Audio 服务确认消费的源采样帧计算，暂停和网络缓冲期间不会按墙上时间推进。歌曲结尾会播放完队列中的剩余 PCM，再按播放模式切歌。点击或拖动进度条可跳转；拖动期间预览时间和歌词，松手后定位。短按左右切歌，长按左右预览快进／快退，松开后跳转，暂停时调整进度仍保持暂停。支持 HTTP Range 的 CBR MP3 或带 Xing TOC 的 VBR MP3 会直接请求目标片段并解码预滚；其他音源从头解码定位，可能较慢。MP3 分帧与 VBR 索引有定位误差。

GameKit：上下选歌；A 播放（播放页为暂停／恢复）；B 逐层返回，发现页再返回关闭；START 暂停／恢复；短按左右切歌、长按左右快进退；X 收藏；Y 歌词；SELECT 收藏页；音量由所在设备的系统控制。播放页左下角图标切换播放模式。

搜索输入完成后可按 A 或 START 提交，键盘遮住屏幕按钮时也可使用。首次播放按系统提示允许联网和音频权限。后台会停止播放。收藏保存曲目标识和显示信息，播放前重新获取会过期的音源地址。网络请求、音频、图片和歌词均有固定内存上限。元数据连接失败会有限重试；音频断线会尝试从当前进度重连。

## 音源与歌词

参考 [Meting](https://github.com/metowolf/Meting) 汇总的接口形态，应用使用平台同源、无需身份信息的 HTTP 网页接口，请求公开的搜索、详情、歌词和标准 MP3 地址；未嵌入 Meting 服务端实现，也不依赖公共代理。该网页接口并非平台承诺稳定的开放 API，可能因地区、版权、接口调整或限流不可用。服务端响应为完整可播 MP3 且无试听标记时才开始播放；需要登录、会员、仅试听或不支持的格式会显示原因，不解锁限制内容。

网易云未返回歌词时，使用 [LRCLIB](https://lrclib.net/docs) 的匿名歌词查询。请求携带应用名称、版本与项目地址，顺序请求并遵守 `429` 的 `Retry-After`。无歌词、纯音乐和请求失败分别显示状态，不生成替代歌词。支持 LRC 多时间标签、毫秒、正负 offset、UTF-8；纯文本歌词也可阅读。封面使用曲目详情中的原始地址，并通过 Host Assets 2.2 解码为有大小上限的图片。

首页不再内置固定曲目；推荐元数据来自 `/api/personalized/newsong?limit=12`，歌曲标识、名称和歌手均读取实际响应。音频、封面和歌词在运行时向各自来源请求。代码许可不改变音乐、封面和歌词的权利归属。

PCM 跨 MP3 帧合并为完整的 20 ms 数据包，队列背压时保留原包，曲目末尾提交不足一包的剩余采样。音频补给优先于重绘，唱片等动效降低刷新频率，避免界面占用声音的缓冲余量。

UI 图标来自 `../common/media/tools/generate_icons.py` 中的自绘矢量；修改图形或配色后重新运行生成器。CairoSVG 和 Pillow 仅用于开发机生成 PNG，运行时使用已有的 Canvas 图像缓存。

窗口采用边到边内容并隐藏系统栏；根容器和画布内容铺设应用背景，逻辑尺寸向上取整，避免非整数密度下露出系统主题背景。

## 构建与测试

要求 Core 2.1、Net 0.5、Audio 0.10、Assets 2.2 和 UI Canvas。工作区根目录：

```sh
tools/app.sh build music --source-root local/pxa-apps --target esp32s31,simulator --aot-only --output local/artifacts/music/build
```

`tests/discovery_test.cpp` 验证实际推荐响应、异常数据、去重、原子缓存、缓存与网络的先后顺序，以及刷新不改变播放队列。`tests/model_test.cpp` 验证 JSON、Unicode、较大标识、LRC 和收藏；`tests/playback_test.cpp` 使用短 MP3 夹具验证音频背压时原包重试、文件结尾完整消费、暂停以及歌词消费时钟。测试程序和报告输出应放到工作区 `local/artifacts/`。

自有代码 MIT；共用 MP3 解码器 minimp3 为 CC0-1.0，固定来源与原许可位于 `../common/media/vendor/`，包内 `assets/NOTICE.txt` 保留完整声明。系统不增加解码库或其他链接依赖。

播放使用原始 PCM 增益，音量统一由系统控制。App 不再保存独立音量百分比。系统返回、工具栏返回和手柄 B 共用逐层导航；从播放页返回时保留来源列表、搜索结果、焦点与滚动位置。

封面加载成功后直接显示原图，不叠加占位背景或旋转动效；尚未加载时使用缓存占位图。顺序播放、列表循环、单曲循环采用自绘图标。滚动时重用静态图片，压缩音频使用滑动窗口，避免逐帧搬移缓冲。

音频补给允许在一次回调内解码多个 MP3 帧，收到队列背压立即让出；避免低于实际单帧解码时间的固定预算导致高采样率音频长期供给不足。

音量完全由系统负责，App 不显示或处理任何设备专用音量快捷键。暂停时提高触摸滚动刷新频率；播放时保留稳定的重绘间隔，补足 PCM 队列后才重绘，静止页面减少重绘以保留解码余量。

再次点击正在播放或暂停的当前曲目只打开播放页，保留播放进度、暂停状态、封面、歌词和原队列；自动单曲循环仍从头播放。画布页面之间复用界面容器，仅搜索输入页创建或移除原生输入框。

播放界面不常驻操作教学文案或手柄按键后缀；保留歌曲、歌手、歌词，以及加载、缓冲和错误状态。
