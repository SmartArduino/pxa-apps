# 星壤物语 · Starsoil

面向 PXA Core 2.1 的原创 2D 像素沙盒首版。世界可选择小型（256 × 96）、中型（384 × 112）或大型（512 × 144），包含蕨木森林、花语草甸、琥珀沙丘、霜落雪原、繁茂雨林及流光深境。支持采集、挖矿、建造、合成、装备、NPC 交易、战斗、守卫挑战和持久存档。

## 开始游玩

首页提供八个独立世界槽位。选择世界卡片后进入，也可使用卡片右侧的播放和删除图标；删除需要再次确认。创建世界时选择实际地图大小，输入 0～4294967295 的数字种子；种子留空时随机生成。种子键盘支持触屏和手柄方向键选择、确认与取消。同样的大小和种子会生成相同地形。不同大小均包含全部地形分区、矿物、水、熔岩与地下祭坛。

游戏中可从暂停菜单选择“保存并返回首页”切换世界，背包、装备、建造与进度均随各自世界保存。手柄在首页使用方向键选择、A 进入、X 创建、Y 请求删除，L/R 翻页。旧版存档保留原文件并作为世界 01 出现在列表中，升级不会自动创建或覆盖它。

出生点的小屋配有工作台和床，右侧有入门矿井。先与屋外向导交谈领取凝胶和药水；砍树、挖石头，在工作台制作熔炉。用矿石和煤炼锭，再制作铁砧，逐步锻造铜、铁和晶体装备。金矿需要铜镐，晶体、红宝石、深岩和黑曜石需要铁镐。

合成手册列出全部 52 条配方、已有材料数量和所需设施；没有材料或没有靠近设施时不会扣除物品。向导提供两个进阶委托，商人、铁匠和园丁提供材料交易。地下宝箱可开出材料、衣服、药水与饰品。在地下坐标约 `(194, 91)` 的祭坛合成星核，再与祭坛互动挑战星核守卫。

背包有 40 格，其中前 8 格是快捷栏。头盔、胸甲、护腿、衣服、披风、靴子和护符独立穿戴；装备页以静止站姿放大展示实际穿戴外观。护甲提供防御，疾行靴提升速度，云靴提供二段跳，辉光项链扩大照明，磁石护符扩大拾取范围。弓消耗箭，星杖消耗可恢复的魔力。

右上角的旅途目标跟踪向导会面、开采和合成委托；达到要求后返回向导领取原有奖励，再继续寻找地下祭坛。采矿会产生碎屑，矿脉偶尔闪光，拾取物品和战斗伤害会显示短暂飘字。连续拾取相同材料时合并数量。`effects.hpp` 使用固定大小的粒子和文字池，不改变游戏随机数或存档。

画布按屏幕比例扩展并铺满显示区域，方屏会增加可见场景高度；场景保持相同的横纵缩放比例。界面在场景缩放完成后绘制，字体直接使用输出像素上的整数倍率，避免整屏缩放让笔画变成不同宽度；480 × 480 屏幕的常规字体为 12px 原始点阵的 2 倍，即 24px。页签使用整屏宽度，操作按钮固定在屏幕底部，菜单内容在剩余空间居中，触控坐标跟随布局调整。

## 操作

| 操作 | 手柄 | 触屏 |
| --- | --- | --- |
| 移动 | 左右方向键 | 按住底部左右按钮 |
| 跳跃 | A；云靴可再次按 A 二段跳 | 跳跃按钮；按住方向按钮向上拖动也可边走边跳 |
| 瞄准 | 朝向前方，上下键调整 | 按住世界中的目标方块并拖动 |
| 挖掘、砍树、攻击、放置 | 按住 B | 按住使用按钮或世界中的目标 |
| 切换手持物 | L / R | 点选上方快捷栏 |
| 背包 / 合成 | X / Y | 右上角背包 / 合成 |
| 互动 | SELECT | 互动按钮 |
| 穿戴 / 使用背包物品 | 方向键选择，A 使用 | 再次点选已选中的物品，或使用 / 穿戴按钮 |
| 检查人物两侧外观 | 衣橱中按左右方向键 | 衣橱或背包中轻点人物转身 |
| 移到当前快捷格 | 背包中按 Y | 背包中点击放到当前快捷栏 |
| 暂停 / 保存退出 | START | 右上角菜单 |

模拟器键盘映射遵循 PXA：方向键移动，`Z=A`、`X=B`、`A=X`、`S=Y`、`Q=L`、`W=R`、`Tab=SELECT`、`Enter=START`。暂停菜单可以切换中英文。手柄按键提示默认隐藏；实际按下手柄按键后显示，再次触屏、断开手柄或重新启动后隐藏。仅连接手柄不会开启提示。模拟器的映射键同样作为手柄输入处理。

地面和木平台的落脚位置对齐实际表面，短时步更新也保持站稳状态。木平台支持从下方穿过和按住下键落下。按住下键放置木板会搭建背景墙。与门互动可开关，与床互动可设置回城点。死亡会返回家中并保留背包。矿物采集后自动收入背包，背包满时留为地面掉落。

手持玻璃、瞄准水或熔岩并使用，可以装瓶取走一格液体；切换到装好的瓶子即可放置。

制作的储物箱共享 12 格物资，可存取整组物品；拆下箱子不会清空物资。地下藏宝箱为一次性宝物，不可通过重复放置刷取奖励。橡子可种在泥土或草地上，随游玩时间生长。

## 构建与运行

在 `pxa-projects` 工作区根目录：

```sh
tools/app.sh build starsoil --target all --source-root local/pxa-apps
tools/dev.sh sim starsoil --board doit-gamekit-1 --source-root local/pxa-apps
```

签名包名为 `pxa-starsoil.pxa`，可安装到具有所需服务和足够应用内存的 PXA 系统。线性内存上限为 3 MiB。模拟器验证不等同于 ESP32 实机性能验证。

## 图像与维护

`tools/draw_art.py` 是游戏内原创像素美术的源文件，输出 16 × 16 方块、16 个方向连接变体，20 × 32 像素人物的空手、持物、双手持弓、举工具四种手臂姿势（8 个步态帧，另有站立与跳跃帧，共 20 个分层部件），以及铜、铁、晶体三套头盔、5 类生物的 6 帧动画和物品图标。人物源文件为 `tools/characters.py`，人物以 `art/characters/design-reference-v1.png` 第一套原创角色为依据，采用蓬松的十三像素头部、大眼侧脸、贴合下巴的衣领和紧凑四肢；颈部、肩肘腕、髋膝踝足、衣服、护甲、披风与靴子共享 16 个关节锚点；两条手臂及布袖、甲袖独立分层：人物默认朝右，近侧手固定为主手，操作工具并拉弓弦，远侧手负责扶弓；肘、膝按同一朝向弯曲，转身时只整体镜像一次。远侧手臂和腿先绘制，再绘制身体及近侧肢体，肤色、袖口和护甲遵循同一深度关系。肩、肘、腕由固定长度的两段骨骼在生成阶段求解，并吸附到像素网格，运行时仍只读取精灵表及关节锚点。左右手与近远侧身份不会随动作重新分配。行走中同侧手脚反向摆动，两腿轮流前伸；步态按实际移动距离推进。工具动作拥有独立的完整周期，不驱动双脚；持物时主手稳定持物，扶手协调摆动。背包、衣橱和对话中的人物使用静止站立帧。重复精灵行及与姿势无关的衣甲资源会复用，避免新增动作增加不必要的内存。每条腿分别提供髋、膝、踝、足锚点，抬脚时同步调整膝盖；裤管、护腿和靴口共用这些位置。前后脚保留不同的横向位置，袖子止于肘部。每种手持物都有不透明手柄握点，弓额外对齐弦手；玩家与 NPC 使用同一套 `actor_renderer.hpp`，手指最后绘制在手柄上。整个人物、装备及握点一起镜像和整数缩放。佩戴头盔时隐藏外侧蓬松头发，并保留眼睛和侧脸；帽檐位于眼睛上方。角色参考图由 imagegen 生成，提示词和参考来源保存在 `art/characters/source.json`，原生头部点阵保存在 `tools/characters.py` 的 `HEAD` 中。渲染器补充对角内角、材质着色、昼夜和局部照明。`art/` 中保存可编辑生成源对应的精灵表；实际运行使用 `art.hpp` 内嵌资源，不需要在线加载。

`tools/visuals.py` 统一地形、矿物、物品、植物、工具、武器与五类怪物的原生像素绘制。铜甲采用铆钉与包覆胸板，铁甲采用中脊和分段护板，晶甲采用晶面胸饰；三种衣服分别绘制衣领、背带和袍摆。`background.hpp` 绘制随镜头分层移动的山脊、云、地形植被和地下晶簇，区分森林、草甸、沙漠、雪原、雨林及晶洞。自然树木使用原创整树枝冠素材 `art/trees/oak-canopy-v1.png`，由 imagegen 绘制；原始提示词和摘要保存在 `art/trees/source.json`。`tools/build_trees.py` 编译为 112 × 96 像素的三种树冠配色，`trees.hpp` 将树冠绑定到实际树干，按叶块的采集状态遮罩，并绘制逐渐加粗的树干与根部。叶团大小、枝杈、垂枝和透光间隙来自完整画面，不再重复铺满同一叶片纹理。独立建造的叶块和木材仍使用拼接变体；远景阔叶树使用相连的多簇树冠，主干连续延伸至冠内。雪原和雨林另有树叶配色。远行指南第五页提供五类怪物的动画图鉴。

地形使用四向连接精灵表与对角邻居共同确定外轮廓：露出的外角使用像素圆弧，内凹角从相邻实心块取色，在空白格角落补画弧形过渡，相连边保持不透明。泥土、草地、石头和矿脉按实体地形连接，材质交界不产生透明裂缝；木板和砖块保留较方直的边角。独立叶块采用较大的低对比叶簇，露出的外角使用七像素弧度，在连接边和内部交点保持填实；自然树冠使用上述完整枝冠素材。`terrain.hpp` 负责对角连接与空白格弧角填充，不增加整套256变体的资源内存。拼接图形不改变方块碰撞规则。

`art/cover.png` 为使用内置 imagegen 生成的启动画面，提示词与来源记录在 `art/artwork.json`。商城宣传封面与独立图标分别保存在 `store/cover.png`、`store/icon.png`，生成提示词及摘要记录在 `store/artwork.json`；应用启动器选用其 128 像素版本 `assets/icon-v2.png`，由 `package.json` 指定。商城资料源文件为 `store/listing.json`，公开页面为 [星壤物语](https://app.doit.am/apps/starsoil)。游戏截图应从真实 PXA 模拟器或设备获取。

```sh
python3 local/pxa-apps/starsoil/tools/draw_art.py
python3 local/pxa-apps/starsoil/tools/build_trees.py
python3 local/pxa-apps/starsoil/tools/build_font.py
```

美术生成需要 Pillow。界面、数字、英文和暂停菜单统一使用 [ZLabs Pixel 12px](https://github.com/Astro-2539/ZLabs-Pixel-12px) CN 原始点阵；中文按 12 像素、英文按 6 像素字距显示，行高 13 像素，不从轮廓字体缩放生成。内嵌子集命名为 Starsoil UI 12。`ui_canvas.hpp` 按输出表面的整数像素绘制文字，并使用相同的字号计算宽度、行高、居中与换行。场景只在进入界面绘制阶段时缩放一次，文字和后续弹窗保持正常绘制顺序。中文逐字换行，英文优先按单词边界换行；超长按钮文字以省略号收尾。合成列表每页显示四条配方，为物品名称和材料各留一行。字体工具仅使用 Python 标准库，源 KBitX、固定上游提交与 SHA-256 分别保存在 `art/fonts/` 和 `art/font-source.json`，无需访问网络或安装系统字体。原始 OFL 授权与版权声明保留在 `art/FONT-LICENSE.txt`，并随应用包的 `assets/font-license.txt`、`assets/font-notice.txt` 分发。代码、网格美术与原创整树素材按 MIT 分发；应用运行层从现有 CC0 pocket-play 运行层派生。没有引入 Terraria 的素材或游戏代码。

`core.hpp` / `core.cpp` 管理与平台无关的规则与按世界尺寸编码的存档；分配步长固定为最大尺寸，游戏边界使用各世界自己的宽高。`main_menu.inc` 管理世界列表、大小选择、种子键盘和删除确认；`world_storage.inc` 管理文件目录与异步原子存档。`items.hpp` 管理物品与配方，`main.cpp` 管理呈现及操作，`runtime.cpp` 管理 PXA 显示、事件、音频与存档。`tests/font_test.cpp` 检查每个内嵌字形在不同坐标相位下的 2 × 2 像素、字宽和弹窗遮挡；`tests/core_test.cpp` 可在原生编译器配合 AddressSanitizer、UndefinedBehaviorSanitizer 下运行；`tests/actor_test.cpp` 调用游戏实际人物合成器，检查不同穿戴、姿势、帧、朝向下的连接、双足、握点和缩放，并可导出检查图。`tests/layout_test.cpp` 调用实际页面绘制和点击处理，检查画布覆盖、触控区域及采集战斗反馈。`tests/assets_test.py` 检查源点阵及分层素材，`tests/save_fixture.cpp` 提供可重复的模拟器测试存档。

`tests/simulator_test.py` 默认通过 SDL dummy 驱动无头运行真实 PXA 模拟器，只测试一个 480 × 480 配置；可用 `--width`、`--height` 和 `--density` 指定当前目标设备，用 `--headed` 显示桌面窗口。截图是模拟器原始输出，同时检查是否存在整行或整列黑边。操作、装备转身、存档以及同一分辨率下的穿戴组合也会检查。日常迭代以原生检查和一个目标配置为主，显示布局变更时才补充相关屏幕尺寸。检查世界管理时可用 `--worlds-only --fixture-tool <fixture程序>` 验证三种尺寸、种子复现、切换、重启、删除与损坏存档保护；可用 `--legacy-fixture-tool` 指定旧版本生成器检查真实旧文件兼容。检查按键提示时可用 `--input-hints-only` 验证中英文界面在手柄按下、松开、切回触屏及重启后的显示，并逐像素对照模拟器截图中的中文原始字形，确认没有二次缩放。检查动作时可用 `--motion-only` 记录真实模拟器的左右行走、站立挥工具动画，并验证衣橱站姿不随全局时钟变化、挥工具时双脚不乱迈。仅修改树木和人物美术时，可用 `--appearance-only` 集中检查三种树木配色、便装与各套装备的双向显示；可加 `--fixtures plain` 等仅选择本轮需要的场景。仅修改动作或武器时，可用 `--weapons-only` 快速检查采集反馈和双向武器显示；修改图块拼接时，可用 `--terrain-only` 检查地形拼接、森林、雪原、雨林树木和洞穴。`tests/trees_test.cpp` 检查实际树木绘制的树干、枝杈与树冠像素连接。`tests/terrain_test.cpp` 使用实际绘制函数检查整片邻域的像素连通性，覆盖混合地形和三种树叶配色，防止实心区域产生透明孤洞。测试输出遵守工作区 `local/artifacts/` 约定。

## 存档与当前边界

世界分别存放在应用私有目录：世界 01 沿用 `starsoil-world-v1.bin`，其余为 `starsoil-world-2.bin` 至 `starsoil-world-8.bin`。首页仅扫描和校验文件，选择进入后才加载游戏状态。自动保存、暂停和退出会保存世界编辑、背包、装备、储物箱、掉落物、委托及玩家位置。先写临时文件，关闭成功后通过 PXA FS 原子替换发布；读取时检查版本、范围、文件长度和校验和。损坏或无法读取的世界会保留原文件、占用原槽位并显示不可读取；其他世界仍可正常使用。新建世界只使用空槽位，删除损坏世界也需要明确确认。切换或删除前完成当前世界的待提交保存，写入中的快照不会被新世界状态替换。活动世界删除后停止其后续自动保存，避免重新生成已删除的文件。

这是有明确内容规模的可玩首版：80 种非空物品、52 条配方、4 位 NPC 和 1 个守卫。当前为单人模式，可保留八个独立世界、同时游玩其中一个，没有联网、复杂液体流动、沙块重力、独立箱子库存、NPC 住房判定或大型剧情。敌人及其临时战斗状态不存档，普通敌人重开后按规则重新生成；守卫未被击败时可重新合成星核召唤。暂停菜单可保存并返回世界列表，后续加载保留离开时的位置和进度。
