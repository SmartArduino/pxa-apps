# 网络收音机

背景铺满窗口，交互内容避开 Host 发布的安全边距、圆角和系统手势输入区域。窗口指标或显示环境变化时自动重排，搜索与自定义地址输入框和触摸命中使用同一内容原点；安全边界按实际 DPI 向内取整，支持非对称圆角与圆形屏幕。

PXA 网络电台应用，接入 [Radio Browser](https://docs.radio-browser.info/) 公共目录，无需 API key。支持中文电台、热门列表、按名称搜索、翻页、12 个持久化收藏和自定义 HTTP/HTTPS MP3 直播地址。电台是否可用取决于广播方与网络；目录中的不可用流和 AAC/HLS 流会被过滤，连接后仍会检查实际响应。

首页采用暖色电台卡片与底部迷你播放器。点击电台开始播放，点击底部名称或按 Y 打开独立的唱片播放页；播放页提供切台、停止／恢复、收藏。推荐页显示内置电台，全球页请求公共目录，搜索按钮打开输入页，右上角加号可添加直播地址。列表支持连续拖动、惯性滑动和滚动位置指示；目录末尾按向下可获取下一页。

搜索／自定义地址输入完成后可按 A 或 START 提交。收藏保存在应用私有存储中。后台会停止播放，回到前台后可点击播放继续。首次使用按系统提示允许联网和音频权限。

GameKit：上下选择，A 播放所选电台（播放页为停止／恢复），B 逐层返回，推荐页再返回关闭，START 停止／恢复，X 收藏或取消收藏，Y 播放页，SELECT 收藏页，音量由所在设备的系统控制。

窗口采用边到边内容并隐藏系统栏；根容器和画布内容铺设应用背景，逻辑尺寸向上取整，避免非整数密度下露出系统主题背景。

## 构建

在固件工作区根目录执行：

```sh
tools/app.sh build internet-radio --source-root local/pxa-apps --target simulator --aot-only --output local/artifacts/internet-radio/build
```

目标可换为 `esp32s31` 或 `wasm`。要求 Core 2.1、Net 0.5、Audio 0.10；WASI 仅声明时钟能力。网络服务需允许最长 24 小时的流式交换。连接建立仍使用短超时，应用在持续 20 秒没有数据时关闭连接并至多重试三次。

HTTP 接收环 64 KiB、压缩数据使用 64 KiB 滑动窗口、最多预取 32 KiB，PCM 单帧解码，并跨帧拼接成完整的 20 ms 音频包；压缩窗口通过游标前进，只在尾部空间耗尽时整理，避免每个 MP3 帧都搬移整个缓冲；不下载整段直播。启动先积累 24 KiB（64 kbps 电台约三秒），遇到网络抖动重新缓冲后继续，减少短促断音。兼容含 ICY 元数据的 MP3 流，元数据会在解码前移除。音频按源采样率和声道提交，队列满时保留原 PCM 重试；不丢弃已解码分包。电台跳转由应用显式处理，沿用系统的联网权限校验。

## 接口与许可

目录请求为 `/json/stations/search`，使用 `codec=MP3`、`hidebroken=true`、点击次数排序和每页 16 条结果。播放使用 `url_resolved`，请求带应用 User-Agent；播放内容仍由各电台提供，不随应用打包。内置 32 个已验证的中文 MP3 电台，包括中国之声、北京交通、上海新闻、动感 101、广东音乐之声等；首页直接显示完整内置目录。推荐页保留这些电台，全球页和搜索请求公共目录。首次打开不等待海外目录即可选台。海外目录暂不可达时仍可选内置电台、收藏或自定义地址；电台音频本身仍需要联网。

应用自有代码采用 MIT；MP3 解码器 [minimp3](https://github.com/lieff/minimp3) 采用 CC0-1.0，来源、固定提交与哈希见 `../common/media/vendor/upstream.json`，完整许可保留在 `../common/media/vendor/LICENSE`。系统改动仅扩展已有 HTTP 请求的时长上限与连接超时处理，没有增加系统解码依赖。

原生模型测试涵盖 JSON/UTF-8、格式过滤、地址编码、收藏和分段 ICY 元数据。运行时输出目录应放到工作区 `local/artifacts/`。

播放使用原始 PCM 增益，音量统一由系统控制。App 不再保存独立音量百分比。系统返回、工具栏返回和手柄 B 共用逐层导航；从播放页返回时保留来源列表、搜索结果、焦点与滚动位置。

音频补给允许在一次回调内解码多个 MP3 帧，收到队列背压立即让出；避免低于实际单帧解码时间的固定预算导致高采样率音频长期供给不足。

音量完全由系统负责，App 不显示或处理任何设备专用音量快捷键。触摸拖动与惯性滚动时提高界面刷新频率，静止时减少重绘以保留音频解码余量。

播放界面不常驻操作教学文案或手柄按键后缀；保留歌曲、歌手、歌词，以及加载、缓冲和错误状态。
