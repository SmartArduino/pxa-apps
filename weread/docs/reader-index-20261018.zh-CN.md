# 阅读解析索引：一次分配与编译期字段查询

2026-10-18。本记录接续 [有界输入](reader-input-20261018.zh-CN.md)，只说明后续解析索引候选。开发源码已更新；本轮完成了真机固定对照和正确前后页验证；冷启物理堆峰值及显示延迟未达目标，已恢复设备原包。本地书签的真机验收仍未完成。已采用包继续为 `b2b44db1…`，Host 为 `234edd19…`。

## 改动与取舍

- 序列化函数的参数数量在解析头部就能确定。用一次经预算检查的 `malloc` 和有类型的原位构造保存精确数量的绑定项，交给 `unique_ptr` 管理，查询和排序使用 `span`。没有索引扩容分支或默认缓存；分配失败返回受控的容量错误，不依赖关闭异常的 `new` 失败语义。
- 每次准备新文档时释放旧绑定和字段容量，避免新旧索引同时存在或因旧文档的保留容量误拒绝新文档。正常阅读本就按请求创建解析器；没有牺牲应用实际使用中的缓存命中。
- 阅读字段由同一份固定名称表定义，内部查询使用 `get<"bookInfo">()` 一类编译期键。无效键编译失败，运行时直接按槽位读取；传入网页的属性仍经过原有验证，不执行 JavaScript。
- 输入上限、共享预算、正文格式、章节入口和授权判断不变。300 项是当前目录窗口容量，不是整本目录上限。

绑定类型限制为平凡析构、默认构造不抛出且不超过 `malloc` 的对齐保证；因此可以在明确建立类型生命周期后由自定义 deleter 释放。没有自建通用容器或给 SDK 增加默认开销。字段容器、阅读模型和 SDK 仍有其他动态分配，不能据此宣称所有 OOM 均可恢复。

## 功能与失败恢复

本轮最终开发根源码 **88 项 AOT/Wasm 集成检查**全部通过：每种模式各为大页面/分片/目录往返 3、小页面 2、限额/重试 4、书签 16、多屏基础/恢复/搜索 19。笔记版派生 AOT 的大页面 3、小页面 2 和完整私有响应离线回放 2 项分别记录，不能将它们算成同一个二进制的 95 项覆盖率。C++26 原生 hydration 检查通过 `-Wall -Wextra -Werror`、ASan 和 UBSan，包括全部 2538 项目录尾部遍历。

新增 `tests/index_pressure.cpp` 是可选独立 Guest，不进入正常阅读包。它先生成 9000 别名，再将真实线性堆分配至失败，验证索引分配拒绝、释放压力后同一解析器成功、退出后资源归零；AOT 和 Wasm 各固定三次通过，2 MiB 上限不变。

实验用私有状态恢复器另有 7 类正常/错误用例、1 次幂等重开、1 次提交前并发修改和 6 类输入拒绝检查。它通过相同 App 身份的 SDK 原子替换阅读位置文件，不读写会话文件。并发用例使用仅测试构建的明确暂停点，原先未经同步的测试曾因恢复先完成而失败，失败证据保留。这是提交前重查，不是跨进程 compare-and-swap：使用前必须停掉正常应用，任意时刻断电也可能留下独占临时文件；不会自动删除来源不明的文件或回滚历史凭据。

## 复现

完整大页面合成回归沿用有界输入记录中的命令。可选的堆耗尽检查须在独立源码副本中构建：

```sh
cmake --build build/simulator/pai-touch --target pxsys_resource_app_test
python3 local/pxa-apps/weread/tests/build_memory_probe.py \
  --build build/simulator/pai-touch \
  --runner deps/pxa-system/simulator/desktop/product_runner.c \
  --output local/weread-index-observer
mkdir -p local/weread-index-test-source
test ! -e local/weread-index-test-source/weread
cp -a local/pxa-apps/weread local/weread-index-test-source/weread
cp local/pxa-apps/weread/tests/index_pressure.cpp local/weread-index-test-source/weread/main.cpp
PXA_BUILD_CACHE_DIR="$PWD/local/weread-index-test-cache" tools/app.sh build weread \
  --source-root local/weread-index-test-source --target simulator \
  --output local/weread-index-test-package
python3 local/pxa-apps/weread/tests/index_pressure.py \
  --simulator local/weread-index-observer \
  --package local/weread-index-test-package/pxa-weread \
  --publisher-key local/pxa-apps/.dev-signing/publisher-public.der \
  --ime-package local/app-output/pai-touch/pxa-pinyin-ime \
  --output local/weread-index-test-results
```

仅在模拟器运行诊断包，不覆盖用户应用。测试所用内存观察器可由 `tests/build_memory_probe.py` 在独立输出路径构建；普通模拟器没有诊断 JSON 时不能运行依赖该文件的内存断言。原生 `hydration_test.cpp` 检查全部 2538 目录项、逐阶段取消后复用、非法输入和分片字面量。

具体二进制摘要、每组测试数量、全部固定计时样本和失败限制见 [结构化记录](reader-index-20261018.json)。之前 160 项检查对应之前的二进制，不重复计入本轮覆盖。官方客户端完整功能、已购图书的 Web 授权差异、漫画专用浏览、跨端写入和端到端显示延迟仍未解决或未验证，README 功能矩阵继续有效。
