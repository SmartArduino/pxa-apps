# 长目录与阅读权限修复

本轮针对“已购买《C++ Primer Plus》，但后续内容无法阅读”和重复二维码失效进行排查。真实账号、章节正文、二维码与会话只保存在忽略版本控制的私有验证目录中。

## 已确认的问题与实现

- **目录游标单位错误。** 实际图书有 635 个目录条目、34 个实际章节。嵌套标题重复使用同一章节编号。原实现把第 300 条目录项作为 `rangeEnd=300` 发给服务，得到成功但空的响应。修复后，显示窗口与服务端章节编号分开保存；远程请求使用实际 `chapterIdx`。
- **保留完整小节目录。** 每次最多保留 300 条。若原页面已含全部目录，继续浏览时重新取得同一官方页面，按需投影下一窗口，不常驻保存整份 HTML，不把目录简化为只有大章。阅读正文、页码与已有位置不随目录切换而改变。小节目前仍使用其所属章的官方 URL，精准跳转到小节锚点尚未实现。
- **空边界与异常响应。** 服务端成功返回空目录时停止该方向加载；非法或倒序页不会替换已有目录。缺失实际章节索引时不猜测远程游标。
- **权限提示。** 区分已购、部分章节已购、免费、限时免费、当前可试读及未知状态。免费/限免分类参考官方网页的 `payType` 标志；提示不作为本地阻拦条件，是否能读仍以当前章节的官方授权为准。旧接口的 `paid=0` 不能证明用户没有购买。
- **内容错误。** `errorInfo` 的空值、空对象和零错误码不再误判为失败。内容获取错误 `-505` 与需要购买分开提示，不要求已购用户重复购买。错误使用持久的阅读提示页，点“返回”或系统返回后回到发起页面，原正文仍保留；不再仅依赖短暂 Toast。
- **扫码等待。** 官方长轮询约 55 秒返回的 `scan:0` 表示尚未扫码，不表示二维码已经失效。使用同一登录请求继续轮询到本地期限；打开登录设置、系统返回不会取消在途轮询。会话确实过期时提供重新登录入口，同账号保留阅读位置，切换账号清除旧账号的位置。

## 真实授权差异仍待解决

用户确认手机官方客户端可以完整阅读且已购买。已用新扫码会话核对当前账号一致；同一图书的墨水屏旧接口和桌面官方图书接口都返回 `paid=0`、`free=0`、`maxFreeChapter=8`、`soldout=1`。旧接口的后续章节返回需要授权和内容获取错误 `-505`。这些是**接口返回事实**，不据此否认用户的购买状态，也不把目录修复等同于已解决后续正文授权。

续期后的同账号只读复核仍未取得该书后续正文，补齐响应 Cookie 合并的 Web 分片对照也返回空内容。尚未直接验证真实 Kindle 浏览器中的官方页面，因此不能据此断言所有已购书都不支持。按用户 2026-10-17 的要求，对本书停止继续尝试 Kindle 轻量路径及 Web 分片替代，不反复要求扫码或接入未通过的全文回退。详见[参考核对的停止条件](official-skill-koreader-20261017.zh-CN.md#续期后复核与停止条件)。尚未实现官方手机专用内容协议，不宣称已支持该书全文。
