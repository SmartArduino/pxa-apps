# 服务与客户端边界

本客户端使用腾讯官方页面已经使用的 HTTPS 服务。应用为非官方实现，服务响应仍决定登录和阅读授权；未将账号代理到第三方，也不在 Host 装入脚本引擎。

书架、目录与章节正文使用扫码登录保存的网页登录 Cookie。图书详情、个人划线/想法与云端进度读取按官方 Skill 的 HTTP 协议接入：先通过已登录会话只读调用 `/api/skills/apikeyGet?only_show=1` 取得账号已有的 Key，再以 `Authorization: Bearer` 调用 `https://i.weread.qq.com/api/agent/gateway`。Key 仅在当前任务内存中使用，不创建或重置 Key，也不写入安装包或诊断日志；Cookie 与 Bearer 凭据按固定来源隔离。

未取得可用 Key 或 Key 接口拒绝授权时，详情、划线和想法页显示可翻页的开通指引：在手机或电脑访问 `https://weread.qq.com/r/weread-skills`，用同一账号获取 API Key 后返回刷新。已加载的信息仍保留在内存中；网络连接或响应格式错误单独提示，不直接判定为未开通。正文阅读不受 Skill 开通状态影响。

目录和正文的只读 GET 遇到明确会话过期时，仅在同账号续期确认成功后重试一次；拒绝续期、限流及阅读权限错误不会循环重试。目录跳章继续读取新的正文与授权信息，同书目、目标章节身份匹配时复用当前目录窗口，减少重复解析；再次选择已加载章节可直接返回本地开头。失败、取消和响应章节不匹配均保留旧正文与目录。

目录保留官方章节字段 `isLock`，为值为 `true` 或 `1` 的条目显示锁图标。章节请求明确返回 `isCurChapterNeedToPay` 时更新当前窗口中同 UID 的锁定标记，成功读取正文后清除该章节标记。锁定条目仍可点击，以请求时的官方授权结果为准，便于购买或限免变化后重新验证。

正文请求可协商 gzip，压缩缓冲上限 256 KiB。先校验并统计解压大小，再一次分配准确的正文缓冲，避免增长过程中的双份大内存；两遍处理均有取消边界，最多 16 个 gzip 成员共享原有正文上限。压缩体超过缓冲上限时，只读 GET 可回退一次无压缩传输。gzip 校验和、尾部大小、截断或未知压缩格式不通过时，不提交阅读模型。应用只链接 Zlib 许可的 zlib 解压子集，来源、逐文件校验值和许可保存在 `vendor/zlib/`，不增加 Host 或固件依赖。

返回书架保留最近成功加载的一节正文、目录及原有阅读位置；同账号在加载后十分钟内重新打开同书同章节可直接复用内存。仅保留一份阅读模型，不写入正文磁盘缓存；打开其他书、缓存超时或账号重新授权时先释放旧模型，再请求服务端，以免大型响应与旧正文争用有限的连续内存。退出账号会清除保留的阅读内容。

首次打开图书先展开当前章节附近最多 64 项目录，后续窗口最多 300 项；目录总长度与官方游标保留完整，按需继续加载。向前加载时以当前窗口起点为边界，避免窗口大小变化造成章节跳过或倒翻前进。

保留正文时，若整页响应因内存不足无法加载目录窗口，可按已有章节索引游标改用官方目录接口。备用响应仍需完整验证后才替换目录，失败不清除正文和原目录；目录行偏移不作为服务端章节索引发送。

| 路径 | 用途 | 客户端处理 |
|---|---|---|
| `/wrwebsimplenjlogic/api/getuid` | 获取扫码会话 | 不写入诊断日志 |
| `/wrwebsimplenjlogic/api/qrcode` | 官方 PNG 二维码 | 严格 Base64、有限临时文件、Host 解码 |
| `/wrwebsimplenjlogic/api/getlogininfo` | 等待手机确认 | 异步、有超时；官方过期结果立即结束 |
| `/wrwebsimplenjlogic/api/weblogin` | 提交确认并取得 Cookie | 保留 VID 的 JSON 类型；结果不明时不重放 POST |
| `/wrwebsimplenjlogic/api/shelfloadmore` | 书架分批读取 | 整批验证后提交游标，错误保留原页 |
| `/wrwebsimplenjlogic/api/catalogloadmore` | 前后目录及章节入口 | 最多保留 300 项；沿用官方 `readerUrlParmas` 拼写 |
| `/wrwebsimplenjlogic/reader` | 已授权章节 | 有限 HTML / Nuxt 数据读取，不执行网页脚本 |
| `/api/store/search` | 官方图书搜索 | 电子书类型、范围 17、会话游标和有界分页 |

搜索到的书通过目录服务取得首个正式章节入口，不在客户端重制不透明阅读参数。付费和不可用状态保留，不把搜索结果等同于阅读授权。

- [阅读和目录页面逻辑](https://cdn.weread.qq.com/web/wrwebsimplenjlogic/client/reader.4efb56.js)

这些是页面内部协议，不是腾讯对第三方承诺稳定的公开 SDK。新响应必须先更新合成测试与真实服务验证，解析失败应保留原有页面和私有数据。不要让登录令牌、二维码、书架或正文进入公开测试样本。

正常构建固定腾讯服务域名；测试构建仅接受编译时的本机端口。请求有响应体、头、超时与路径上限。Cookie 仅发送到固定服务域名，不发送到任何第三方站点。Guest 日志仅记录阶段、数量和错误码；设备 Host 的网络诊断可能包含请求 URL，应仅放在私有验证目录。

会话仅在凭据变化或用户改变保持登录选项时写入。阅读位置保留 UTF-8 字节偏移，最多 32 本的惰性 LRU；连续翻页合并保存，后台、返回书架和正常退出立即请求保存。强制停止或掉电不等同于正常退出，可能丢失尚未提交的最后一段位置。账号退出使用单一后台写入队列，删除会话与临时凭据文件后再生成新的扫码会话，避免旧保存任务把令牌写回。


## 数据解析与容量

序列化数据支持 Nuxt 压缩后的 `.15`、`-.5e2` 等小数写法，验证数字语法后转换成带前导零的 JSON。去除标签、还原字符后的 UTF-8 正文限额为 192 KiB。服务端排版 HTML 可大于这个值，其大小受整页输入预算约束。正文超限或图片元数据超限均保留原页并显示对应提示。

当前开发源码的阅读 HTML 上限为 1,302,528 B，响应按需分配。Hydration 只接受受限字面量和最多 24 层数据；不执行任意脚本。形参别名与简单对象/数组初始化项按实际数量分配，并与响应缓冲的实际容量共享 1,310,720 B 工作预算，不再分别固定为 8,192 和 4,096 项。数组长度仍最多为 8,192，下标必须是小于 8,192 的规范非负十进制整数；拒绝计算属性、函数调用和全局写入。共享对象仅允许空占位符初始化，避免与已有字面字段重叠。

读取书籍时只生成阅读 DTO，输出上限为 384 KiB，并进一步受共享工作预算扣除响应与索引后的剩余空间约束。目录围绕当前章节保留最多 300 项及其官方入口，正文最多 192 KiB，字符映射和分页模型另有独立限制；容量上限不等于启动预分配。首次下载页面仍会占用响应正文，不能将“没有完整展开 JSON”误称为完全流式下载解析。Guest 最大线性内存保持 2 MiB；解析预算不代表整机物理内存上限，实际增长和峰值需要在运行时单独记录。设备包与模拟器使用相同的输入和索引限额。

## 尚未接入的云端写入

官方阅读前端包含 `/api/bookread`，携带真实正文坐标、章节、进度与阅读秒数；坐标来自原始 DOM 的 `wco`，并非本地 UTF-8 字节偏移。当前本地翻页与位置保存没有伪造这个坐标，也没有上报自动测试或后台停留的阅读时长。后续需先验证 DOM 坐标与解码、排版、跨节分页之间的映射，再接入进度、划线与时长；目前不宣称跨端同步。
