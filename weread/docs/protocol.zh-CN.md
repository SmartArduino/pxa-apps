# 服务与客户端边界

本客户端使用腾讯官方页面已经使用的 HTTPS 服务。应用为非官方实现，服务响应仍决定登录和阅读授权；未将账号代理到第三方，也不在 Host 装入脚本引擎。

| 路径 | 用途 | 客户端处理 |
|---|---|---|
| `/wrwebsimplenjlogic/api/getuid` | 获取扫码会话 | 不写入诊断日志 |
| `/wrwebsimplenjlogic/api/qrcode` | 官方 PNG 二维码 | 严格 Base64、有限临时文件、Host 解码 |
| `/wrwebsimplenjlogic/api/getlogininfo` | 等待手机确认 | 异步、有超时；官方过期结果立即结束 |
| `/wrwebsimplenjlogic/api/weblogin` | 提交确认并取得 Cookie | 保留 VID 的 JSON 类型；结果不明时不重放 POST |
| `/wrwebsimplenjlogic/api/shelfloadmore` | 书架分批读取 | 整批验证后提交游标，错误保留原页 |
| `/wrwebsimplenjlogic/api/catalogloadmore` | 前后目录及章节入口 | 最多保留 300 项；沿用官方 `readerUrlParmas` 拼写 |
| `/wrwebsimplenjlogic/reader` | 已授权章节 | 有限 HTML / Nuxt 数据读取，不执行网页脚本 |
| `/api/store/search` | 官方图书搜索 | 电子书类型、范围 17、会话游标和有界分页 |

搜索到的书通过目录服务取得首个正式章节入口，不在客户端重制不透明阅读参数。付费和不可用状态保留，不把搜索结果等同于阅读授权。

实现时核对的公开官方前端版本：

- [扫码登录页面逻辑](https://cdn.weread.qq.com/web/wrwebsimplenjlogic/client/login.dc74cd.js)
- [阅读和目录页面逻辑](https://cdn.weread.qq.com/web/wrwebsimplenjlogic/client/reader.4efb56.js)
- [服务端序列化数据和正文字符表](https://cdn.weread.qq.com/web/wrwebsimplenjlogic/server/2018e7e.js)
- [新版图书搜索页面逻辑](https://cdn.weread.qq.com/web/wrweb-next/_nuxt/CBsFeTqQ.js)

这些是页面内部协议，不是腾讯对第三方承诺稳定的公开 SDK。新响应必须先更新合成测试与真实服务验证，解析失败应保留原有页面和私有数据。不要让登录令牌、二维码、书架或正文进入公开测试样本。

正常构建固定腾讯服务域名；测试构建仅接受编译时的本机端口。请求有响应体、头、超时与路径上限。Cookie 仅发送到固定服务域名，不发送到任何第三方站点。Guest 日志仅记录阶段、数量和错误码；设备 Host 的网络诊断可能包含请求 URL，应仅放在私有验证目录。

会话仅在凭据变化或用户改变保持登录选项时写入。阅读位置保留 UTF-8 字节偏移，最多 32 本的惰性 LRU；连续翻页合并保存，后台、返回书架和正常退出立即请求保存。强制停止或掉电不等同于正常退出，可能丢失尚未提交的最后一段位置。账号退出使用单一后台写入队列，删除会话与临时凭据文件后再生成新的扫码会话，避免旧保存任务把令牌写回。


## 数据解析与容量

当前开发源码的阅读 HTML 上限为 1,302,528 B，响应按需分配。Hydration 只接受受限字面量和最多 24 层数据；不执行任意脚本。形参别名与简单对象/数组初始化项按实际数量分配，并与响应缓冲的实际容量共享 1,310,720 B 工作预算，不再分别固定为 8,192 和 4,096 项。数组长度仍最多为 8,192，下标必须是小于 8,192 的规范非负十进制整数；拒绝计算属性、函数调用和全局写入。共享对象仅允许空占位符初始化，避免与已有字面字段重叠。

读取书籍时只生成阅读 DTO，输出上限为 384 KiB，并进一步受共享工作预算扣除响应与索引后的剩余空间约束。目录围绕当前章节保留最多 300 项及其官方入口，正文最多 192 KiB，字符映射和分页模型另有独立限制；容量上限不等于启动预分配。首次下载页面仍会占用响应正文，不能将“没有完整展开 JSON”误称为完全流式下载解析。Guest 最大线性内存保持 2 MiB；解析预算不代表整机物理内存上限，实际增长和峰值需要在运行时单独记录。此输入与索引候选尚未替换设备正常包，实测范围与未达标项见 [索引验证记录](reader-index-20261018.zh-CN.md)。

## 尚未接入的云端写入

官方阅读前端包含 `/api/bookread`，携带真实正文坐标、章节、进度与阅读秒数；坐标来自原始 DOM 的 `wco`，并非本地 UTF-8 字节偏移。当前本地翻页与位置保存没有伪造这个坐标，也没有上报自动测试或后台停留的阅读时长。后续需先验证 DOM 坐标与解码、排版、跨节分页之间的映射，再接入进度、划线与时长；目前不宣称跨端同步。
