# Quake SD

资源自动绑定到 SD 卡 `/PXA/media/<AppKey>/`，无需选择目录。资源名称和转换步骤见 [公共说明](../common/recrof/TEST_DATA.md)。代码与私有存档目前仍在内部存储。

真机最低目标为实际关卡 15fps；构建成功不代表通过真机验收。测试结果记录在工作区 `docs/validation`。Clock 0.3 协商 8ms，旧 Host 回退 16ms；保持原始画质和音频。

本轮配置使用64KiB引擎栈、16KiB回调栈和16KiB续体，固定上限3.5MiB。
须配套本轮完整辅助栈及固定内存加载器固件。0.1.5诊断包在GameKit实际START中
为2.875MiB线性内存，引擎栈水位39,320字节；帧率仍约5.9fps，尚未达到目标。
