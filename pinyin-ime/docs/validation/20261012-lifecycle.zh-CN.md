# 可安装输入法的按需生命周期（2026-10-12）

中文解码仍由签名 PXA Service Component 提供；英文、密码和键盘绘制在 Host 完成。中文词库按需加载，关闭即释放，没有新增常驻 Guest、加载线程或帧缓冲。最终手机式键盘、截图和真机验收见 [手机式键盘报告](20261012-phone-keyboard.zh-CN.md)。本页保留此前生命周期改动的独立对照，不与后来的键盘改版混为一个实验。

## 改动

| 原因与实现 | 收益 | 内存及验证 |
|---|---|---|
| 焦点明确是否需要中文 Provider；英文/密码不启动，切换英文取消或卸载 | 英文立即编辑，关闭后的普通运行不轮询空 Guest | 无常驻词库；英文、密码、取消和重复释放回归 |
| 元数据、签名、清单枚举及 16 KiB 文件摘要分步推进 | 步骤之间处理前台事件及取消 | 复用原 I/O 缓冲；0/1 B 预算和六类损坏包回退 |
| ESP 校验到激活持有包事务租约；安装忙时非阻塞重试 | 防止文件被中途替换；切换前台先取消租约 | 原事务锁，无新线程；最终设备切换/停止回归 |
| 元数据/AOT 读入最终缓冲，复用目录已知类型，根路径按长度分配 | 减少重复查找、临时文件缓冲和路径占用 | 保留摘要验证及打开前后文件检查；安装器与加载回归 |
| 关闭后的原子 dirty 快速路径、空组件不检查 watchdog | 关闭时避免无意义 LVGL 锁竞争和调度 | heartbeat 与 builtin 对照；8 次开关释放 |

分步验证只有返回成功后才能激活。字节预算约束摘要读取，签名、目录步骤和最后 WAMR/解码器激活仍是同步工作。通用 POSIX 调用者须保证源目录在验证到激活期间不可替换，并串行使用安装器；ESP 由包事务租约保证。

## 受控真机对照

pai-touch 296×240，160 DPI，同五个应用、同词库和 Provider、每轮重新启动、Wi-Fi 关闭、系统数字字体按相同顺序预热。原始结果的公开摘要为 [改动前](20261012-lifecycle/controlled-before.json) 和 [改动后](20261012-lifecycle/controlled-after.json)。早期未统一字体及应用条件的记录仅作诊断，不再作为收益依据。

| 指标 | 生命周期改动前 | 改动后 |
|---|---:|---:|
| 三次热打开键盘绘制 | 28 / 28 / 28 ms | 28 / 28 / 28 ms |
| 热打开候选就绪中位数 | 3314 ms | 2538 ms（−23.4%） |
| 中文加载期间最大前台回调间隔 | 3394.7 ms | 794.6 ms |
| 打开后立即关闭，最大前台回调间隔 | 3320.9 ms | 232.6 ms |
| 关闭、PXA 被选中，最大前台回调间隔 | 21.59 ms | 21.93 ms |
| 关闭、builtin 被选中，最大前台回调间隔 | 21.62 ms | 21.41 ms |
| 各监测窗口最大 SRAM 占用 | 269832 B | 269812 B |
| 各监测窗口最大 PSRAM 占用 | 3526908 B | 3525296 B |

关闭阶段中位回调间隔均约 15 ms；没有观察到选中 PXA 输入法引入持续前台负担。回调间隔不是显示 FPS。首次记录存在 0 ms 绘制事件，不能解释成零显示延迟，故首帧收益使用最终键盘报告的有效配对。局部监测窗口之外的 MEMORY 快照仍可能显示开机历史最低空闲量，不能拿它当本次峰值。

SRAM 各窗口最大值下降 20 B，但中文冷打开窗口单独为 269744→269812 B（+68 B）；不可将全窗口下降说成每个阶段均下降。中文稳定占用 265644→265624 B，PSRAM 稳定占用 3504852→3503288 B。最终键盘另有新配对，不能用这些旧数据替代最后版本验收。

## 边界与复现

最后的同步激活仍可能阻塞前台约 0.8 s，完整中文候选就绪仍需数秒；这里只实现先画键盘、分步加载和可取消，没有宣称所有加载均异步。没有测物理触摸到 LCD 完成延迟，也不能由 heartbeat 推导游戏 FPS。

模拟器覆盖签名 AOT 和纯 Wasm、13 种分辨率/DPI/轮廓、英文/密码、目标删除、背压、旧回复、故障隔离、0/1 B 预算、六类损坏或链接包、重复开关释放。此前 90 项系统回归通过；最终键盘的具体复测数量见新报告。

```sh
cmake --build build/simulator/pai-touch -j8
bash deps/pxa-system/tools/package/test_cpp_ime_app.sh \
  build/simulator/pai-touch/pxsys_ime_test \
  /path/to/signed/pxa-pinyin-ime /path/to/publisher-private.pem
python3 local/pxa-apps/pinyin-ime/tests/measure_pai_touch.py \
  --port /dev/ttyACM1 --two-row --phone-layout --output /tmp/ime-benchmark
python3 local/pxa-apps/pinyin-ime/tests/measure_lifecycle.py \
  --port /dev/ttyACM1 --phone-layout --output /tmp/ime-lifecycle
```

设备脚本用于 296×240 pai-touch，运行前确认 HELLO 序列号，安装相应 fixture，保持前台空闲。截图在局部峰值窗口之外。脚本停止自身应用并恢复输入法选择；完整设备应用、数据及设置恢复记录在最终报告中，私有存档与网络日志不发布。
