# PXA 学习应用

五个主题按亲子启蒙、小学、中学、成人拆成20款独立应用；每个包只编译本年龄内容。
共用全屏原生声明式UI，儿童版使用小芽插画、柔和配色与星星反馈，成人版采用简洁书本图案。
所有按钮均为原生可聚焦控件。支持触摸，以及Host提供的上、下、确认三键顺序导航；
两列选项按控件顺序逐项选择，无需左右键。页头可返回，首页页头可退出应用。
长讲解及使用说明提供按页阅读，上一页、下一页都可用确认键操作。
设备Host必须实现控件焦点导航（例如MZ79 / zuowei-gen4）；应用不把手柄方向键当作点击坐标。
不需要 SD 卡，联网操作由用户主动发起，不修改系统 Wi-Fi 开关。

| 主题前缀 | 每个年龄包的内置内容 | 在线扩展 |
| --- | --- | --- |
| `learn-math` | 对应年龄本地计算题、逐题解释、最近错题 | 无需联网 |
| `learn-poetry` | 6组古诗文全文或明确标注的节选、接句练习 | 今日诗词随机诗句 |
| `learn-words` | 24张中英词卡 | Free Dictionary API 英文释义、音标 |
| `learn-hanzi` | 12张语境读音卡 | Hanzi Writer Data 笔顺中线示意 |
| `learn-cards` | 12张对应年龄知识卡 | 用户提供 HTTPS 地址的小课程 |

目录后缀为`preschool`、`primary`、`teen`、`adult`。例如`learn-math-preschool`是启蒙口算，
`learn-words-adult`是成人词卡。年龄仅作选材参考，不限制使用者；应用内不切换年龄，记录彼此独立。
每轮最多10题。口算错题保留最近8道；其他应用最多跟踪88张卡，优先保留尚未
掌握的错题。翻卡要先展开核对，再选择记住或再学。复习采用固定的1、3、7、14、
30、60天间隔，不是FSRS；系统日期未校准时仍可使用错题复习。

## 内部存储与联网

学习记录采用带版本、应用类型和校验和的912字节快照，作答后保存，兼容嵌入式
Host 单条 Storage 值最大960字节的限制。
在线响应最多8KiB，使用8个按URL映射的缓存槽。碰撞时替换旧内容，读取时核对完整
URL，不会误用别的卡片数据。缓存正文外有少量URL元数据；写入先落临时文件，关闭后
再重命名。清理缓存不删除学习进度或下载课程。音频与完整字库不随应用打包。

单词与笔顺优先读取缓存；每日诗句先尝试更新，网络失败时读取旧缓存。在线资源需要
系统Wi-Fi已经开启及相应联网授权。取消授权、HTTP失败、超时、过大或无效响应都保留
已有学习内容。首次查看尚未缓存的笔顺需要网络。笔顺显示笔画中线，使用“下一笔”
逐步观察，不提供书写评分。单词首版提供文字释义和音标，不播放发音。

固定来源只申请各自域名的可选网络权限；知识卡盒为了读取用户填写的HTTPS地址，申请
可选的`web`范围。在线每日诗句是随机资源，不用于分级答题或自动填充儿童课程。

## 自定义知识课程

在知识卡盒的“我的小背包 / 设置与资源”填写HTTPS地址，点击下载。格式如下，UTF-8、版本1，
4至24张卡，总响应不超过8KiB：

```json
{"version":1,"cards":[
  {"level":0,"question":"1+1等于多少？","answer":"2","explanation":"两个一合起来是二。"},
  {"level":0,"question":"2+2等于多少？","answer":"4","explanation":"两个二合起来是四。"},
  {"level":0,"question":"3+3等于多少？","answer":"6","explanation":"两个三合起来是六。"},
  {"level":0,"question":"4+4等于多少？","answer":"8","explanation":"两个四合起来是八。"}
]}
```

`level`为0/1/2/3，分别对应亲子启蒙、小学、中学、成人。所有卡片必须与当前安装包年龄一致，
否则整份课程被拒绝。各知识卡工程的`example-course.json`提供对应年龄示例。问题、答案、解释分别不超过180、120、480个UTF-8
字节。卡片不可重复，答案至少有4种不同值，用于构造四选一。验证和保存成功才替换
课程，重开应用仍能使用。可以随时恢复内置课程。服务端请返回JSON正文，不需要HTML
网页或专用后台；课程没有内置公共服务器。

## 构建与维护

从工作区根目录执行`tools/app.sh build learn-math-preschool --board doit-gamekit-1 --target esp32s31 --aot-only`，
其余应用替换目录名。发布包只保留目标设备架构以减小体积：doit-gamekit-1选`esp32s31`，
zuowei-gen4 / MZ79选`esp32s3`；模拟器包另外构建。安装与运行需要PXA Core 2.1，
旧版0.4.0 Host需要先升级，不能只修改安装包的最低版本标记。
原始题库位于五个无年龄后缀目录的`content.json`，它们仅用于内容维护，不是额外的安装包。
`tools/create_content.py`为各独立工程生成只含本年龄内容的`content.inc`及清单。
需要修改题库时修改生成器并重新生成；外部课程不依赖该生成器。

`tests/test_host.sh`检查题目生成、复习间隔、记录校验、下载课程与笔顺解析边界。
所有源码和原创解释采用MIT；古诗文正文为公版作品。在线内容和应用代码分别许可，
词条显示返回的来源与许可，笔顺数据适用随应用保留的Arphic Public License。
