# Gameplay Image Sources

`bird.png` is original artwork rendered at its final in-game size (`34x21`)
from `bird.svg`. The game draws it at 1:1 scale.

`pipe-body.png`, `pipe-top-cap.png`, `pipe-bottom-cap.png`, and `ground.png`
are original project artwork rendered from the SVG sources in this directory.

The generated runtime PNG files are stored in
`apps/pxa/arcade/assets/flappy-bird/`.
