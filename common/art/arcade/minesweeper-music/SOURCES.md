# Music source

`gymnopedie_1.mid` is Erik Satie's *Gymnopedie No. 1* (1888), downloaded from
the Mutopia Project on 2026-08-24:

- https://www.mutopiaproject.org/ftp/SatieE/gymnopedie_1/gymnopedie_1.mid
- https://www.mutopiaproject.org/cgibin/piece-info.cgi?id=37

Mutopia identifies the source edition as public domain. The game converts the
first phrase of the treble and bass tracks into `../minesweeper_music.inc` for
the PXA synthesizer; it does not decode or ship the MIDI file at runtime.

# Icon source

`icon.svg` and its rendered `icon.png` are original project artwork for the
PXA Arcade Minesweeper menu entry.

# Gameplay art source

`flag.png` and `mine.png` are original project artwork rendered from the SVG
sources in this directory at their native in-game sizes.

`background.png` is original project artwork rendered from `background.svg`.
The generated runtime PNG files are stored in
`apps/pxa/arcade/assets/minesweeper-music/`.
