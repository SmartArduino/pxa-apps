# 3D小赛车

独立PXA游戏，包ID `pxa-mini-racer`，离线运行，无SD卡依赖。

晴空海岸、云上山路、星光夜城三条赛道均可直接选择。每场两圈、三辆对手车；碰撞和驶出公路会减速，六处加速带可提供短时冲刺。每条赛道分别保存最好用时、最好名次与完成标记。

道路和低多边形车辆使用世界坐标和透视投影，包含弯道、坡道、近裁剪和屏幕裁剪；通过公开GameRender四边形命令绘制。路边树木、建筑和昼夜配色随赛道变化。资源仅包括少量字形和图标，绘图不依赖外部模型或第三方3D运行时。以场景草地色清屏，天空、道路和两侧路肩分别绘制，减少重复像素填充；三辆对手的前后顺序每帧只计算一次；多边形完全可见或在同一边界外时，直接接受或舍弃，只有跨越边界时执行完整裁剪。

- 自动加速。三按键游玩时，↑向左转、↓向右转，确认暂停；菜单中↑↓选择、确认执行。按住方向键连续转向，松开回正；也支持标准左右方向键。
- 体感模式先拿稳约一秒校准，之后左右轻倾转向。使用加速度中的重力方向，避免角速度积分漂移。读数断流超过400毫秒时自动暂停，可切换按键继续。
- 触屏按住画面左侧或右侧转向，拖动可改变转向幅度；抬手或取消即回正。顶部和底部均可点击暂停，第二根手指不会夺取当前手势。
- 实际使用按键或触屏后会记住所选控制方式；暂停菜单可重新校准并恢复体感。车库可设置灵敏度、四种方向与镜像、三种车身颜色。
- 暂停、返回首页、后台和每15秒保存一次比赛快照，包含位置、速度、计时、对手位置、加速状态和倒计时。重启后首页默认“继续比赛”；新比赛和赛道切换有独立入口。后台暂停后不会自动冲出去。

在 `pxa-projects` 构建：

```sh
tools/app.sh build mini-racer --board doit-gamekit-1 --target esp32s3 --aot-only \
  --source-root "$PWD/local/pxa-apps" --output "$PWD/local/app-output/mini-racer"
```

模拟器改为 `--target simulator`。`tests/test_core.py --output ...` 验证完整比赛、碰撞、加速、断点和裁剪；真实签名应用测试见[共用支持](../common/motion-games/README.md)。代码与原创图标为MIT，字体为SIL OFL，完整声明随包保留。

本应用的 `art/font.json` 选择内嵌字形：资源生成工具会无损打包全部灰度覆盖值，启动时通过公开GameRender上传字形页，后续逐帧不解码；原始字形页保存在 `resources/` 供校验，不重复装进设备。构建使用LTO与WASI提供的整数格式化库；运行时接口与SDK兼容下限不变。
