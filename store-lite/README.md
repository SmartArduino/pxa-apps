# 轻量应用商城

面向只有上下和确认键的小屏设备，也支持触摸。首页使用纵向入口；列表、详情和下载管理
共用原生焦点与滚动，返回键按页面退回。字体由系统提供，包内只保留一个图标，不附带
字库、截图、离线目录或网页引擎，截图按需加载，安装包由 Host 下载与验证。
页面按需创建，切换成功后释放上一页的控件；列表、搜索与账号数据保留在应用状态中。

搜索直接使用系统文本输入控件与输入法。未提供文本输入控件的设备在搜索页显示三键
字母/数字分组输入，无额外输入页面；保留四个常用搜索词。

支持应用/游戏、分类、热门、关键词搜索、详情与权限/兼容信息、截图浏览、下载安装、
仅下载、已安装应用、逐应用检查更新、签名身份打开/卸载、下载清理、网页登录短码及点赞。
应用详情可切换同一版本的 AOT／WASM 安装包。默认推荐 AOT；WASM 下载体积较小，
运行速度及运行内存不一定更好。选择后仍由系统验证签名与兼容性，保留原应用私有数据。
版本切换位于“仅下载”下方，并显示当前所选包的下载大小；切换后主操作显示“安装”。
安装、卸载仍需系统确认；设备的防沉迷策略决定目标应用能否打开，商城不提供绕过入口。

与完整版商城共用有界目录解析、配置识别、发布者绑定和账号协议。一次加载 6 个目录项，
已安装及下载数量遵守当前 Host 接口上限。网络出错保留已加载列表，可以重试；无 SD 卡可用。
缺少 Installer 0.7 的系统需先升级。账号凭据仅保存在本应用私有 Storage，退出登录会撤销凭据。

应用及其私有 C++ 运行库使用链接时优化和 `-Oz`。目录窗口与每页 6 项保持一致，
下载列表在进入下载页时读取；目录、详情与截图共用 HTTP 流，等待数据时使用就绪通知。

```sh
tools/app.sh build store-lite --target simulator --source-root local/pxa-apps
tools/app.sh build store-lite --target esp32s3 --source-root local/pxa-apps
tools/app.sh build store-lite --board esp-mosaico --target esp32s31 --source-root local/pxa-apps
```

安装到指定设备时按其架构构建，可减少下载和安装占用；`--target all` 用于分发多架构通用包。
