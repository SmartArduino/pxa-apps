Toyokumono is the original MIT OBONO game from fixed commit d4b1f041789dcd1d71907654e4025d613b4ab420. Original MIT audio attribution is retained in vendor/original/MyArduboyPlaytune.cpp. AVR rand reference carries BSD-3-Clause notice.

The original integer 60 FPS admission uses 16 ms. Original 128×64 framebuffer is scaled exactly 2× in the 400×416 PXA simulator. Ordinary visible directions and A/B retain their original masks; HOME exits. No hidden controls, restored game state, forced Guest seed, difficulty changes, extra Host imports, or shared SDK changes are used.

The owner retains original MyArduboyPlaytune score interpreter, priorities, pitch, repeat, timer toggle counts and ISR bodies. Virtual timer1/3 use original OCR/prescale at 16 MHz and advance 16,000 cycles per original 1 ms software clock. Physical GPIO/speaker and RGB LED output are omitted. Audio is silent; hardware output has not been tested.

RECORD_T retains the original AVR 26-byte layout (hiscore at0, playFrames at20, playCount at24), and checksum reads explicit little-endian words. Session EEPROM is 1024 bytes of RAM, fresh FF at each new process; scores do not persist across process exit. NEW and RESTART preserve session EEPROM and clock while resetting original globals and running original setup. MyArduboy2 is constructed with its original default constructor at wrapper boot; no added constructor flag.

Original AVR module function pointers are read without narrowing native64/WASM32 pointers to16 bits. Logo shifts outside0..31 are suppressed; valid original signal frames are unchanged. Original Arduino permissive static/extern declaration conflicts are corrected locally. No AVR firmware was executed and no physical board was flashed. Full original source and complete platform/CMake/frontend diffs are included.

Four original calls with multiple random arguments use explicit right-to-left evaluation. Isolated AVR-GCC7.3 assembly for both GNU++11/C++17 and Os/O2 verifies that original ordering; paired native original/candidate tests preserve all3908 state bytes and RNG call counts. This is an assembly witness, not execution of AVR firmware. The preserved Clang AVR record probe has alignment2; a separate AVR-GCC7.3 probe has alignment1. Both retain size26 and the same field offsets; the old Clang alignment1 metadata mistake is retained and corrected by an append-only receipt.

Audio cursor observation uses the same original score array as the existing MARK pointer, including its one-past STOP position. This avoids mistaking a completed score cursor for an adjacent score start on WASM. All eight pinned scores keep MARK inside their own array. The patch changes only observation helpers and pack expressions; original interpreter, control, ISR, writer order and64-byte layout are unchanged, with no added mutable state.
