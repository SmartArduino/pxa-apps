Evasion is the original MIT game by OBONO at ArduboyWorks commit d4b1f041789dcd1d71907654e4025d613b4ab420. The original embedded title, player art, font, patterns and score data are retained; MyArduboyPlaytune attribution is preserved. The AVR rand boundary retains its BSD-3-Clause notice.

Original 60 FPS uses the original integer 16 ms frame admission. The original 128x64 bitmap is scaled exactly 2x in a 400x416 simulator window. LEFT/RIGHT dodge pillars; A opens the original game menu; B confirms and retries. UP/DOWN and LEFT/RIGHT adjust original settings. PXA MENU pauses, CONTINUE retains full state, NEW/RESTART run original setup, HOME exits.

The original AVR ten-byte settings/score record retains packed field widths and explicit little-endian checksum reads. EEPROM is 1024 bytes of session RAM, initially FF; it survives NEW/RESTART but does not persist across process exit. Original AVR 16-bit function-table truncation is replaced with actual typed callbacks. Settings bits are read by named fields instead of unaligned host pointer casts. Arduino's mismatched drawText forward declaration is corrected locally.

Original AVR double arithmetic is explicitly single precision for death-particle trigonometry. Logo shifts outside the original 32-bit signal pattern produce zero; valid signal bits remain unchanged. Dither explicitly samples the current pixel address before increment, matching AVR-GCC7.3 GNU++11/C++17 Os/O2 assembly; full-width address parity is used, with its original pattern phase checked by the native raster boundary witness. These changes and all observation additions are included in full original-to-platform patches.

The original MyPlaytune interpreter and ISR bodies run with software 16MHz timer1/3 state. Speaker/GPIO and RGB LED output are omitted: audio is silent. All mutable source fields, inactive arrays, callbacks and score/cursor IDs are typed and serialized, with 3136 core bytes plus337 game bytes. The native oracle boots once from each actual Guest's observed seed and replays ordinary inputs/time; no state loading interface exists. Native/WASM parity does not establish execution on AVR or a physical board. No board is flashed.
