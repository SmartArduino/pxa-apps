# 四博学习宝

独立 PXA 应用，包 ID `pxa-sibo-learning`。诗词、儿童故事、蒙学诵读、小学听题、英语词卡、同步教材与科学图文放在同一个安装包中。

- 75 首课本古诗原文离线阅读；在线每日诗词、随机诗词、按诗人查找、拼音伴读、诗意讲解及小挑战。
- 拼音伴读按屏幕可用高度分页，底部上一页、下一页并排固定显示；带声调拼音与汉字对齐，长音节保留足够宽度，三按键无需额外滚动正文。22 首已有服务注音的课本古诗内置离线拼音，按需载入当前一首，正文校验匹配后才使用；其余诗词首次注音需联网，最近获取的数据可复用缓存。当前专门注音入口用于诗词，未向全部故事或蒙学自动注音。
- 已有音频的 22 首课本古诗提供「跟着读一读」，接入原服务的跟读版本，与普通朗读分别缓存。没有跟读资源的内容不显示该入口，不额外请求音频合成。
- 故事按分类浏览，支持分页阅读、现有插图、朗读及选择题。
- 蒙学书目和一至六年级听题按目录、分段进入。书目与在线内容随原服务更新。
- 英语单词岛接入中考、高考、大学四/六级、考研、托福、雅思、GRE、学术英语共9个词包，按单元读取；词卡先隐藏词义，确认翻卡后直接进入下一词，并支持单词片段发音及词义选择题。
- 同步小课堂按语文、数学、英语、科学与年级上下册选课，读取知识点、例题与解析。选择/判断题自动判分；填空、排序、计算等开放题先思考再核对答案并自评，适合无键盘设备。当前教材以文字学习为主，不提供其 Opus/M4A 音频。
- 科学发现馆按主题和章节阅读 vistep 图文，逐章查看原有插图与来源。
- 全屏原生界面，按物理屏幕尺寸、显示缩放与横竖比例调整布局。小屏单列；大竖屏多列卡片；大横屏侧栏与功能区并排。目录每页数量、阅读字号、行宽及插图区随可用空间调整。首页使用柔和卡片配色，实际按键焦点以边框表示。支持触摸及“↑、↓、确认”。进入内容后默认选择阅读，进入新题后默认选择第一项答案。
- 图片支持全图至8倍缩放。触屏可以拖动、双击放大或恢复全图；三按键设备默认选择“放大”，通过“缩小”“全图”和方向按钮查看各处。横屏全图模式同时显示正文，放大后使用整个插图区。静态图片优先按原始细节解码，上限为2048像素单边、1048576像素，内存不足时降至262144或65536像素；旧 Host 自动使用旧上限。全部沿用 Host 内存配额，放大、拖动复用同一张位图。
- 长题干与选项通过“完整题目”分页查看，翻卡后可打开“完整词卡”，答案与自评支持“分页看讲解”。阅读时用上下键选择上一页/下一页，确认翻页；微型屏允许单行一页，大屏按实际空间增加内容。新阅读位置同时保存正文偏移，换布局后继续读时定位到相同内容。
- 保存正文阅读位置、阅读篇数、答题记录与最多 12 篇收藏。单篇收藏正文最多 8 KiB，新增收藏的序列化数据合计最多 20 KiB，个人快照最多 28 KiB，以适配 64 KiB 应用存储；达到上限会提示移除收藏，不自动删除个人记录。

在线内容来自原四博学习宝的 `https://wtoy.doit.am` 和同步教材 `https://pindou.doit.am/study/` 服务。应用不会开启设备 WiFi；在线内容需要用户先在系统中联网，并授权网络及音频播放。75 首古诗原文、22 首内置拼音不触发网络；其他拼音、讲解、朗读、跟读、插图由用户主动请求。每日和随机诗词优先获取新内容，网络失败时尝试上次缓存。

最近内容使用 4 个缓存槽，单份与合计最多 62 KiB，预算按个人记录体积自动缩减，为旧、新两份个人快照和必要开销留出空间；较大的响应仅在内存使用；收藏与阅读位置另行保存到内部存储。不需要 SD 卡。MP3 流式解码为 PCM。音频使用最多 3 条、合计 1 MiB 的运行缓存；已知长度且不超过此上限的音频边听边缓存，重复播放直接复用，超限或长度未知时继续在线流式播放。短音频和有明确覆盖时间的单词 MP3 前缀另有最多 24 KiB 的沙盒持久缓存，和正文缓存共用动态预算；已覆盖的发音片段重启后也可复用，较长音频仅在本次运行中缓存。缓存仅在收到完整数据或确认单词片段边界后发布，并检查长度、地址和内容校验；截断、损坏或中断文件会丢弃重取。插图不写入持久缓存。小书包里的“清理在线缓存”同时清理音频与正文缓存，保留收藏及阅读位置。音频落盘在停止输出后进行；学习记录保存会暂停缓存写入，必要时释放音频、正文缓存后重试。个人记录原子替换失败时会释放可清理缓存并重试；临时文件失败或重启时清理。正文与收藏合计超过个人快照上限时会提示阅读位置未保存，原记录保留。

原生版本中需要独立设备账号授权的教材音频服务不包含在本应用中。小程序的微信登录、家庭账号和蓝牙配网等平台功能未移植。在线内容、音频和配图的可用性取决于原服务；没有自动创建新插画的请求。

## 构建与运行

在 `pxa-projects` 根目录构建 ESP32-S3 安装包：

```sh
tools/app.sh build sibo-learning --board doit-gamekit-1 --target esp32s3 --aot-only \
  --source-root "$PWD/local/pxa-apps" --output "$PWD/local/app-output/sibo-esp32s3"
```

需要模拟器包时将 `--target` 改为 `simulator`，或用 `esp32s3,simulator` 构建双架构开发包。发布到设备时使用 ESP32-S3 单架构包以节省存储。

要求 PXA Core 2.1、Window 0.3、FS 0.2、Net 0.5、Audio 0.10、Assets 2.2。音频使用应用内 minimp3 解码及 Host PCM 输出，不依赖 Host Music 解码器。Host 未接任意采样率 PCM 时，仅在返回“不支持”后协商标准单声道会话，应用流式混音、重采样；保持原始时长和单词片段边界。

模型测试不需要设备或网络，可选传入本地保存的公开 API 样本：

```sh
python3 local/pxa-apps/sibo-learning/tests/test_model.py \
  --output local/artifacts/sibo-learning/<时间戳>/models
```

`tests/test_simulator.py` 使用 `common/study/tests/build_three_key_simulator.py` 构建的实际 Gen4 导航桥接模拟器，仅以 ↑↓确认验证核心流程。通过 `--workspace`、`--package-root`、`--executable` 和 `--output` 指定路径。测试状态、日志和截图全部保存在指定的本地产物目录。

`tests/test_pinyin.py` 使用相同路径参数，逐页核对拼音与汉字的完整性、实际 LVGL 文本边界和字体测量，覆盖长音节及三按键前后翻页。导航桥接器仅在设置 `STUDY_TRACE_LAYOUT` 时输出布局证据；该测试会自动设置。

`tests/test_offline_follow.py` 验证内置拼音不触发网络或持久缓存，再显式访问已有跟读 MP3，验证播放时打开拼音、自然结束与重复播放命中运行缓存；`--offline-only` 跳过音频联网。

`tools/build_course_pinyin.py` 从本地保存的公开 `index.json` 与 `<诗词ID>-meta.json` 生成紧凑内置拼音，逐字比对 `course.inc` 后写入 `course_pinyin.inc`。通过 `--fixtures` 指定样本目录、`--report` 指定被忽略的本地产物目录；构建与运行时不会自动请求或生成整套注音。

`tests/test_learn.py` 验证英语、教材和科学数据模型，可用 `--fixtures` 读取本地 API 样本。`tests/test_extensions.py` 验证词卡、题型、自评和重启恢复；构建专用导航模拟器时使用 `--private-quota-bytes 65536`，可覆盖 Gen4 的空间不足与重试保存流程。

`tests/test_touch.py` 使用真实指针点击验证多尺寸卡片、目录和答题命中，以及正文行宽。`tests/test_large_picture.py` 显式验证大屏公开插图。`tests/test_picture.py` 用 Sanitizer 验证缩放几何、边界与定位；`tests/test_zoom.py` 使用公开插图和原始截图，验证实际缩放、拖动、双击、按键移动和全图恢复。`tests/test_pcm.py` 用 Sanitizer 和独立积分参考验证采样率转换、声道及帧边界；`tests/test_legacy_audio.py` 配合 `--legacy-audio` 专用模拟器验证旧音频输出。

`tests/test_learning_live.py` 显式运行时验证现有词包、单元首尾单词的音频片段和科学插图。

`tests/test_live.py` 使用相同路径参数，显式运行时访问已有的公开 MP3、插图、目录与书目；不请求 AI 插画或 TTS 生成。加 `--wait-completion` 可验证整段朗读自然结束。

## 来源与许可

内容模型与服务契约参考 `paixueji_nertc_demo_new` 中的学习宝实现；75 首古诗原文沿用其 chinese-poetry 数据。原项目与数据、ECDICT、vistep 的 MIT 声明，以及 minimp3 的 CC0 声明保存在 `assets/` 并随包分发。本应用界面、图标和代码使用 MIT。在线故事、音频及图片按需访问原服务，不随安装包分发或重新授权。

`tests/test_audio_cache.py` 使用现有公开 MP3 验证重复播放、发音片段持久缓存、重启恢复、截断/校验失败重取及清理时保留个人记录。`tests/test_long_text.py` 验证长题干、选项、解析和词义的三按键完整阅读，`tests/test_text_pages.py` 用 Sanitizer 验证单行分页、大屏多行及 UTF-8 字节完整性。
