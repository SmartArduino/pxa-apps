# 奶蛙工厂

将 [frog-miner](https://github.com/66970010-boop/frog-miner) 的矿工玩法适配为 PXA 应用 `pxa-milkyfrog-miner`。原作者 66970010-boop，协作者 junjunya2020；原 MIT 声明保留在 `assets/LICENSE-frog-miner.txt`。

首版包含矿工模式：摆动放钩、抓取和收回、45 秒目标关卡、三档难度、大蛙携钻移动、困难模式吊点移动、融化冰块、47 种稀有奶蛙图鉴，以及原版笑声、大小变调、特殊音和音乐。大蛙声音低、小蛙声音高，笑声在抓取期间循环，收回后播完当前一轮。原站的忍者模式与扩展剧情未包含。

首页点击难度按钮切换档位，A /「开始挖矿」开始。点击画面或 A 放钩，再点可提前收钩；达到目标后进入下一关，超时可重试。X 打开图鉴，Y 打开声音设置，B 返回工厂。START / 右上角按钮打开公共暂停菜单，可继续、重新开始、退出或切换中英文。

32 字节校验存档保存历史最高得分、最高已到达关卡、47 位图鉴、难度及声音设置。每次启动从工厂首页开始，正在收钩的局面不跨进程恢复。最高关卡是记录，不是自动续关入口。

构建、音频缓存预算与素材再生见[共用层说明](../common/milky-frog/README.md)。全部来源与原文件哈希记录在 `SOURCES.json`；原角色、图片与录音权利单独保留，见 `assets/THIRD-PARTY.txt`。
