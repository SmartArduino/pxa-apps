# 水平仪 / Spirit Level

独立的 PXA SDK 2.1 测量工具，包 ID `pxa-spirit-level`，版本 1.1.10。双轴气泡、边尺刻度与原生系统字体均由代码绘制，不需要网络、图片场景或额外运行库。界面默认中文，右上菜单可切换 English。

## 使用

把设备放稳，等待状态变为「实时 · 已稳定」。双轴模式显示左右 X、前后 Y 和总倾角；绿色表示在所选容差内。气泡刻度为 ±5°，超出后气泡停在刻度边缘，数字仍显示实际角度。边尺模式显示选定边的倾角与距离水平/垂直的偏差；轻点上方 X/Y 切换测量边。角度读数范围为 ±90°，坡度为 `tan(角度) × 100%`，接近垂直时显示无穷，超出数字空间时用明确的不等号显示。

Gen4 的三个实体键直接对应「上、下、确认」：上下循环移动金色焦点框，确认执行。测量页可依次选择锁定、归零、视图、测量边、设置与右上菜单；设置、标定、说明、返回、语言切换及保存退出都能只靠这三个键完成。按住上下会连续选项，按住确认只执行一次。界面按实际可用屏幕比例排布，240×284屏幕对应240×284逻辑画布，480×320横屏对应336×224逻辑画布；方屏和长竖屏分别重排。背景铺满整个显示区，只有文字、按钮与仪表避让系统安全区和圆角。触屏点击同一控件也可执行操作。

- 「锁定」保留当前读数，界面始终标明已锁定；「解锁」恢复实时。锁定只保留显示，不写入持久存储。
- 「归零」以当前姿态作为相对基准，始终显示相对标记；「绝对」恢复重力基准。相对零点不跨进程保存。
- 「边尺 / 双轴」切换视图；边尺上方的「轴向」按钮切换测量边。
- 「设置」可调单位、容差、轴向旋转，进入标定或使用说明；每页都有可选择的返回/取消按钮。
- 右上菜单的「恢复绝对基准」解除锁定与相对归零，保留仪器标定、单位和容差。菜单可上下选择，确认执行。

完整手柄保留快捷键：B归零、X切换视图、Y设置、L/R切换测量边或单位、START菜单。A始终执行当前焦点，默认焦点为锁定。触屏按下后取消或在控件外松开不执行操作。

0.1° 是显示分辨率，不是准确度承诺。实际误差受传感器零偏、安装、温度、参考面与运动影响。测量应放稳；持续加速不能仅凭加速度计与陀螺仪可靠地与重力分离。绿色容差仅说明当前读数满足用户选定条件。

## 标定与传感器

支持三轴 `motion.acceleration`（µm/s²）和可选的三轴 `motion.angular-velocity`（µrad/s）。目标订阅周期20毫秒，并遵守设备的采样范围，要求最小周期不超过100毫秒。陀螺仪改善转动时响应，加速度计保持重力参考；只有加速度计时仍可工作。无传感器、未授权或超过400毫秒无有效加速度样本时显示无效读数，不以虚构零度代替。锁定中的历史读数保留并继续标为锁定。暂停、后台和退出释放订阅与权限，恢复后重新获取重力，不把当时姿态自动清零。

默认将 Host 设备坐标投影为屏幕 X=-Y、屏幕 Y=X、Z 不变，不包含某块开发板的安装补偿；芯片到设备的轴向转换由固件传感器 Provider 负责，加速度和陀螺仪必须使用相同坐标。设置中的0/90/180/270°用于用户主动旋转测量方向。

测量坐标的 Y 正方向朝上，绘制气泡时转换为向下递增的屏幕像素坐标。气泡朝较高一侧移动；这一显示投影不改变角度读数、传感器数据或仪器标定。

「在水平面上标定」与相对归零不同：请将屏幕朝上放在**已知水平**的参考面上，再开始采样。只接受接近面朝上、稳定约两秒的读数，晃动或断线会重置采样窗口。完成后需点「保存标定」才生效；取消保留原标定。标定修正面板与传感器的对齐，不是完整的六面加速度计比例/零偏标定。清除旧标定须单独确认。

## 实现与存储

- `estimator.hpp`：有界的重力/角速度融合、单位换算、非法值与倒序样本拒绝、稳定状态和失联检测。没有游戏控制死区、灵敏度缩放或隐式姿态清零。
- `model.hpp/.cpp`：三维参考旋转、双轴倾角、边尺偏差、锁定、相对测量、稳定采样及显式64字节存档。
- `services.cpp`：复用 `common/pocket-imu/service.hpp` 的可取消异步发现、权限和订阅管理。
- `main.cpp`：按显示区实际比例排布的横竖屏界面与三键焦点导航，通过 Pocket Studio 在实际输出分辨率绘制几何图形及 Host 字体，适配矩形、圆角与安全区。

测量画面的绘图节拍为20毫秒。双轴模式缓存完整输出缓冲的背景、静态表盘与安全区外的延伸背景，布局变化后重新生成；读数、气泡、状态与按键仍按实时状态绘制。缓存放在包声明的有界线性内存中，分配失败时继续普通绘制，原生字体与输入元数据不会被缓存。绘图节拍是请求频率，实际显示帧率仍取决于设备的绘制与显示管线。

气泡显示使用80毫秒时间常数的指数平滑，按实际帧间隔计算权重，长帧后继续平滑靠近目标；这一插值不修改传感器数据、测量角度或标定参考。

存档键 `pxa-spirit-level.save.v1`，64字节：`SPLV`、版本1、视图/单位/容差/轴向旋转/测量边、标定标志、三个Q2.30标定参考分量、保留零字节，以及前60字节的FNV-1a32。长度、校验、范围、保留位与参考向量全部有效才原子替换偏好。只保存偏好和仪器标定，不保存瞬时读数、锁定或相对零点。语言由共享运行时单独保存。

## 构建与验证

从固件工作区根目录运行，全部运行产物写到被忽略的 `local/artifacts/`：

```sh
level_artifacts="$PWD/local/artifacts/spirit-level/$(date +%Y%m%d-%H%M%S)"
sh local/pxa-apps/spirit-level/tests/run-native.sh "$level_artifacts/native"
tools/app.sh build spirit-level --source-root local/pxa-apps \
  --target simulator,esp32s3,esp32s31 --aot-only --output "$level_artifacts/packages"
```

`tests/native.cpp` 检查已知角度（含0.1°）、重连后绝对参考、三维归零/标定、锁定、稳定窗口、完整性拒绝及双语界面、触摸与Gen4三键导航。`tests/simulator.py` 在真实签名包上通过公共传感器服务验证测量、标定与取消、断线、重启、三键全流程与小屏画面，不修改存档。可复用文件驱动模拟器由 `common/motion-games/tests/build_motion_simulator.py` 生成到本地产物目录。

图标源文件为 `assets/icon.svg`，PNG是其128×128栅格版本。本应用代码、图标与测试为原创 CC0-1.0；完整许可与说明随包包含在 assets 中。共享SDK及Host字体保留各自许可。

满屏与触点集成测试：`common/pocket-studio/tests/fullscreen.py` 接受签名展开包、公共IMU模拟器、公钥和本地产物目录，验证两款应用六种屏幕比例的实际Surface尺寸、触屏、三键、语言及退出。
