# 遗迹疾奔 · Relic Run

PXA 第三人称 3D 无限跑酷。探险者穿越丛林石桥、落日神庙和幽蓝古墓，躲避倒木、石块、低门与断桥，并按路口提示转弯。每 400 米切换环境；速度随距离逐渐增加。连续收集金币可将倍率提升至 x2、x3、x4；收集和漂亮躲避积累能量，充满后进入 7 秒遗迹觉醒，自动吸金并抵御障碍，路口仍需转弯。轮换挑战提供额外得分，每局失败后可使用一次免费救援。护盾抵挡一次碰撞，磁铁限时吸取金币。最佳得分、累计金币、画质与声音设置保存在应用数据中。

触屏：左右滑动变道，上滑或轻触跳跃，下滑滑铲。路口提示出现后靠近路口，再向指定方向滑动。右上角暂停，暂停菜单可开关声音或返回主菜单。标题页可打开操作指南和切换精美／流畅画质。

手柄：方向键变道，↑／A 跳跃，↓／B 滑铲，START 暂停／继续。标题页 A 开始、B 操作指南、X 切换画质；暂停页 A／START 继续、X 开关声音、B 返回主菜单。失败后 A 重来、B 救援；已经救援过时 B 返回主菜单。触屏结算页左侧为救援／返回，右侧为重来。

在固件工作区根目录运行：

```sh
tools/dev.sh sim temple-runner --source-root local/pxa-apps
```

构建模拟器和 ESP32-S3 包：

```sh
tools/app.sh build temple-runner --target simulator,esp32s3 \
  --source-root local/pxa-apps \
  --output "local/artifacts/temple-runner/$(date +%Y%m%d-%H%M%S)"
```

游戏以 60 Hz 固定步长模拟，目标呈现周期 33 ms。使用 PXA GameRender 批量绘制、近裁剪、可见面剔除、有限绘制距离与预计算的模型截面；无逐帧堆分配。场景使用画家排序；主角与障碍物单独使用 Host 的 16 位深度缓冲，避免路面遮掉双脚或肢体相互遮挡错误。240×427 视口的深度缓冲约 200 KiB，创建失败时回退到无深度模式。竖屏镜头更靠近人物，渲染尺寸按屏幕使用整数倍缩放，流畅画质在大屏幕额外将3D渲染尺寸限制到约屏幕的四分之一，并减少植被、装饰和金币远景数量；文字仍保持原生分辨率。标题、帮助和暂停菜单仅在交互或资源加载时重绘。探险者使用封闭截面、膝肘连接和固定长度的两段关节计算，包含脚掌支撑／摆动、反向摆臂、起跳收腿、落地缓冲、抬趾低撑的非对称滑铲及空中下落接滑铲、转弯前的侧身准备与出弯回正，以及圆角背包、帽檐、卷袖、皮靴和飘动围巾；流畅画质降低角色截面数，远处路面使用简化几何。文字和菜单通过原生分辨率的透明 UI 层单独绘制，espp4-a 的 480×854 屏幕小字至少使用 20 物理像素；降低 3D 分辨率不会降低文字分辨率。奔跑时原生文字层只覆盖顶部 HUD 区域，按需更新，最高约每 125 ms 更新一次；3D 仍按 33 ms 周期绘制。实际真机帧率仍需在所用固件、设备和 LCD 上测量。

逻辑与生成关卡检查：

```sh
local/pxa-apps/temple-runner/tests/check.sh
```

安装支持 C++26 的 Clang 后，`tests/check_render.sh <公共 SDK 根目录>` 使用该 SDK 的实际绘制编码器，检查多视口、画质和种子下的面数及绘制包预算。`tests/check_visibility.sh <公共 SDK 根目录>` 对比整组景物剔除开启与关闭时的绘制包，覆盖左右转弯、动作、画质、深度回退和横竖视口；保守剔除须保持编码逐字节一致。

弯前30米内左右操作仍可变道，同时准备对应方向的转弯；正确转弯准备好后，反向换道不会取消它。动作奖励、方向与护盾／觉醒状态在顶部 HUD 内显示，不覆盖道路中央。

`tests/touch.json`、`tests/polish.json` 和 `tests/controller.json` 供 PXA `verify --scenario` 使用。验证输出请指定工作区的 `local/artifacts/`；商城截图须使用 `--store-screenshots` 并检查原图。

美术为代码生成的原创几何模型，音乐由 `tools/build_music.py` 合成，不包含第三方游戏模型、音频或品牌资源。`tools/build_font.py` 使用系统安装的 Noto CJK 生成字形，许可与版权见 `licenses/`。设备桌面图标缩为128×128并限制在64 KiB内，商城可使用保留的原始图。标题标志与应用图标根据本项目的整体美术设计板生成，原图保留在 `resources/brand/`，`tools/build_icon.py` 仅用 ImageMagick 转为设备尺寸；标题通过原生 UI 图像资源显示。竖屏标题页使用单张 180×320 RGB565 预渲染封面（约 113 KiB）；进入跑酷后使用实时 3D，不加载逐帧角色图片。玉石卡片使用同一张 128×128 纹理的九宫格切片，金色主按钮采用保留完整端部装饰的横向三段切片；原生 Canvas 裁剪共享图像，无需保存九份纹理，文字仍为原生分辨率绘制。石板、徽纹、藤蔓、守卫雕像与遗迹黑豹保持原创代码模型和索引纹理，材质图集为256×128的8种石板、苔藓、木纹和雕纹，铺装变化绑定道路世界位置，移动时不会跳换。近景加入蕨叶、水波、石壁浮雕与转角路面，远景合并路面几何；精美／流畅档位控制几何开销。角色共享顶点的变换和光照每帧只计算一次，画家排序只移动16位索引，深度测试的角色面片无需再次排序；固定山脊、拱门和太阳使用预计算坐标。树木、雕像、火盆和障碍在生成网格之前做保守包围盒剔除，视锥包含转弯时的镜头朝向和倾斜；可见性测试对比开关剔除前后的实际编码结果，防止误删可见景物。

字体生成后会同步更新随包的 `assets/THIRD_PARTY_LICENSES.txt`，包含应用、共享 SDK 及 Noto 字体的完整声明。仅更新声明时可运行 `python3 tools/build_notices.py`；`licenses/` 中的原始声明也随源码保留。
