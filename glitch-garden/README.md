# 露芽守卫

面向 PXA 的五路花园塔防。七种原创植物、四种小怪、十二段 75～120 秒关卡，支持触摸与手柄、暂停、重开和关卡解锁保存。应用 ID 保留为 `pxa-glitch-garden`。启动默认通过 Window 0.5 请求横屏，按 Host 返回的实际尺寸布局；不支持旋转的设备保留原生方向。

美术、UI 和字体均采用本项目生成的原创图像：11 张角色原始序列图及 11 张生成的中间姿态参考图；运行素材为同一角色纹理连续变形得到的 45 组、540 帧动画；另有草坪、16 项 UI 素材、20 组中文固定字样和 25 个数字/符号字模。游戏不调用系统字体或通用字体，不使用原版《植物大战僵尸》及 Glitch 的素材，也无需 Unity 或其他游戏的数据包。字样集合专用于本游戏，不代表完整中文字体。

## 玩法

顶部选择种子，再点草地放置。新增霜铃花（35 露珠，命中后减速 3 秒）、焰籽荚（50 露珠，攻击邻近三行范围）、愈露草（30 露珠，每 4 秒为周围植物恢复 14 生命）。新增岩甲蜗耐打但缓慢，疾叶蛾生命少、行进快；后期关卡混合敌人并增加突袭波。帮助页底部箭头可翻阅新植物与怪物图鉴。战场在完整草地画面上按实际 5×9 格叠加轻微明暗，绘制、脚底锚点和点击共用同一套格子坐标；命中判断使用最终像素边界，避免非整数缩放时出现偏移。铃露花每约 8 秒产出 10 露珠；绯芽花发射金色种子；卷叶盾阻挡敌人；风车花投掷叶刃。铜壳虫可以跃过卷叶盾。底部铲子用于移除植物。守满各关规定时间通关；敌人越过左侧则失败。

种子卡保持统一尺寸。全部种子卡放得下时不显示箭头；空间不足时，托盘两侧显示左右箭头，用于移动卡片列表。翻页键使用保留木纹边框比例的圆木按钮和高对比方向标，触控宽度为 26 个逻辑单位；到达列表首尾时，对应箭头变暗。右下进度条按原图宽高比显示，标记移动范围随轨道对应调整。手柄切换种子时会自动移动列表，让选中的卡片保持可见。

手柄方向键选择格子，A 放置，X 或 R 换种子，L 反向切换，B 或 Start 暂停；菜单中方向键选择、A 确认、B 返回。声音可在暂停页切换。后台自动暂停，返回后手动继续。攻击动作在约 0.6 秒内播放完，再等待攻击冷却；每组动作由固定纹理连续弯曲、伸缩生成 12 帧，避免逐帧重画造成的描边和纹理跳动；待机一秒一轮（约每秒 12 张姿态），行走约每秒 15 张姿态，0.6 秒的攻击动作约每秒 20 张姿态，怪物、阴影和弹丸在最终屏幕坐标上保留水平亚像素位置，对同一姿态的缓存做空间覆盖采样，避免整像素移动的小跳动。

## 构建与运行

在本工作区根目录，使用已安装的 `pxa` 或 DevKit 的 `bin/pxa`：

```sh
pxa build local/pxa-apps/glitch-garden --offline --target simulator
pxa run local/pxa-apps/glitch-garden --profile pai-touch
pxa build local/pxa-apps/glitch-garden --offline --target esp32s3,esp32s31,esp32p4
```

保留 `pxa.lock`、应用 ID、签名身份及 release_sequence。模拟器验证不代表设备性能和实体按键已验证。

## 素材与再生成

`art/generated/` 保存原始参考图、22 张透明序列图、UI、背景和专用字样/字模；完整提示词在 `art/prompts.json` 与 `art/refinement-prompts.json`、`art/expansion-prompts.json`、`art/inbetween-prompts.json`。`art/store-cover-prompts.json` 保存商城原创封面插画的提示词及来源；商城截图仍来自真实运行的模拟器。`asset-sources.json` 保存实际输入摘要。图像再生成使用提示词及参考图；以下工具负责角色连续变形、缩放、透明通道校验、调色板和图集打包。原始生成序列作为设计参考保留；当前播放帧来自固定纹理的运动绑定，生成来源与程序派生过程分别记录。

```sh
python3 local/pxa-apps/glitch-garden/tools/build_original_art.py \
  --export local/artifacts/garden-redesign/YYYYMMDD-HHMMSS/animation-export
```

需要 Pillow。每张角色图固定 6 列；`*-inbetween.png` 对应相邻原帧之间的姿态。运行动画由 `tools/coherent_motion.py` 将每个角色的首张待机姿态绑定到连续的网格变形：植物根部固定，头部与身体弯曲，攻击回弹、受击伸缩、跳跃和有限时长的退场分别处理。小怪和铜壳虫的双足交替摆动和抬起，蜗牛腹足以波纹爬行，飞蛾翼扇独立开合。所有动作共享同一张纹理，避免替换姿态时发生局部材质和描边闪变；不混合前后帧。离线以四倍尺寸、预乘透明度生成，再一次缩小。每段 12 帧共用裁剪范围，独立半透明阴影保留；跳跃包含落地帧，退场最终透明且不会逐帧放大。工具导出逐帧 PNG 和 GIF 预览。编译资源保留共享调色板与 8 位覆盖度，源数据按每行的可见区间存储，跳过透明空白，并隐式表示最长的全不透明区间，保留其余全部八位覆盖度，不把半透明边缘截成二值透明。素材使用构建时 带 16 位后向引用的无损压缩并嵌入程序，启动无需逐块读取素材服务；常见尺寸的地图与实机首屏/暂停 UI 提前过滤，声音在首帧后初始化。地图、固定 HUD 和卡片状态分别更新：切换卡片、翻页或露珠跨过价格门槛时，从不含卡片的 HUD 底图恢复顶栏并重新合成卡片，不解压地图或重画固定按钮；数字和进度仅恢复各自的小块区域。保留频繁切换的卡片底板、翻页按钮和铲子纹理，其余静态 UI 过滤纹理退出单位缓存，避免挤掉行走与攻击姿态；缓存优先复用空隙，仅在必要时整理。原生 RGB565 Surface 使用预乘透明度双线性采样，避免透明区黑边；完整花园背景按视口显示全部画面，保留四角与边缘；草地纹理跨格连续，以平滑的修剪明暗区分格子，战场外沿自然淡出，不覆盖重复草皮小贴图；背景只在布局变化时过滤一次，动态图片缓存最多 1.5 MiB，并按实际帧缓冲大小自动缩减；缓存按行分别保存可见像素的 RGB565 与覆盖度，每像素三字节；二路索引减少查找开销，全不透明连续段批量复制，跳过透明区并复用过滤结果；移动物体的全不透明像素直接写入，保留八位覆盖度；繁忙场景把移动采样复用到四分之一屏幕像素的相位缓存，保留原生分辨率和完整动作，低负载使用完整亚像素相位；所有过滤像素放在单块固定缓存中，淘汰后在缓存内部整理，避免动画与大面板交替时产生堆碎片。箭头采用四点覆盖采样。物理安全边距与系统手势边距按 Surface 像素处理，不再重复乘屏幕密度。底部操作控件避开系统底部手势区域。6 MiB 固定线性内存同时容纳颜色/覆盖度数据、双帧缓冲、背景和过滤缓存。每个映射缓冲区分别记录上一帧的动态绘制范围，复用时只恢复这块背景；布局、HUD 或底图变化后两块缓冲区各自完整刷新，保证移除单位、关闭提示及暂停后不会残留旧画面。植物的地面阴影随放置和移除更新到背景，怪物阴影仍随移动绘制；碰撞按行建立稳定索引，减少无关行扫描。游戏字体完全来自图像字样和字模，没有字体栅格化依赖。UI 与场景使用同一缩放系数，在原生屏幕分辨率提交；暂停面板、横向按钮和标题牌保持各自宽高比。

## 验证

`tests/sprite_quality_test.py` 从实际调色板/覆盖度导出的帧检查亮度、脚底边缘和质心连续性；`tests/temporal_coherence_test.py` 另检查局部轮廓与材质的时间二阶变化，可传入旧版导出帧对比，防止整体对齐后仍有细节闪变。`tests/locomotion_test.py` 检查双足独立移动、腹足爬行及翼扇开合，避免用静态角色平移代替行走。`tests/animation_test.cpp` 检查 12 帧播放覆盖、稳定尺寸及屏幕像素移动；`tests/codec_test.py` 验证 Python 打包器与 C++ 解包器在重复、随机、重叠和窗口边界数据上的一致性。`tests/lawn_test.cpp` 检查草地原画细节保留、外沿自然淡出和格子明暗位置；`tests/layout_test.cpp` 检查缩放后所有像素与实际草皮格的对应关系及边界；`tests/filter_test.cpp` 检查双线性采样、预乘透明度合成与缓存上限；`tests/model_test.cpp` 覆盖资源、放置、碰撞、跨越阻挡、失败与十二关完整通关，可使用 ASan/UBSan 原生运行。`tests/touch.json`、`tests/win.json` 和 `tests/controller.json` 供 PXA 验证工具运行真实输入；必须查看原始截图及运行日志。报告、截图、导出帧和构建日志均放在工作区忽略的 `local/artifacts/`。

## 压力测试

`--define GARDEN_BENCHMARK=1` 是专用测试构建：开始游戏后每 30 秒切换 189 个元素（45 株植物、48 个怪物、96 枚弹丸）和 56 个元素（20、12、24）的固定场景，记录更新、背景、复制、绘制、提交与帧间隔；不写入关卡进度。正式包须去掉该定义。`tests/render_load.cpp` 使用同一战场绘制代码作原生对照，不能把电脑运行时间当成设备帧率；`tests/source_art_test.cpp` 可对照资源存储变更前后的全部解码像素，`tests/model_trace.cpp` 可对照确定性战斗状态；`tests/hud_refresh_test.cpp` 对照不同视口的卡片选择、禁用、翻页、铲子及数值更新与完整重画的结果；`tests/motion_cache_test.cpp` 检查相位缓存、淘汰及整理，`tests/frame_restore_test.cpp` 将不同缓冲区轮换、裁剪、提示消失、面板关闭与底图变化后的每一像素和整屏恢复结果对照。所有输出保存到工作区的 `local/artifacts/`。
