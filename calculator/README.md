# 多功能计算器

独立 PXA SDK 2.1 应用 `pxa-calculator`，版本1.0.0。默认中文，支持触屏、手柄及Gen4上/下/确认三键。采用系统字体、原生绘图与满屏响应布局，不需要网络、音频权限或额外运行库。

## 计算功能

- 基础：四则运算、括号、乘方、阶乘、百分号、当前操作数正负切换、删除和清空。
- 科学：sin/cos/tan、反三角函数、角度DEG/弧度RAD、平方根、平方、倒数、自然对数、常用对数、指数、绝对值及floor/ceil/round。提供π、e和上次结果Ans。
- 记忆：MS存入、MR读出、M+累加、MC清除，当前是否有记忆值以M标记显示。
- 历史：保存最近8条成功计算及其角度模式，按项取回结果继续计算；清空历史先进入确认页，默认保留。
- 换算：长度、质量、温度、面积、体积、速度、时间、数据，共8类。美加仑采用美国液量加仑，市斤为500g；数据单位kB/MB/GB采用1000进制，KiB/MiB/GiB采用1024进制。
- 日常计算：A的B%、A打B折（B为0至10）、从A到B的变化幅度（以原值绝对值为基数）及A由B人/份平均分摊（B须为正整数）。

科学键有两页，点击「更多」切换，「123」返回数字键。按等号时会补齐缺少的末尾右括号；不会补全缺少的运算数。除零、非法定义域和过大的数值会明确报错，并保留输入供修改。

表达式使用数学优先级，乘方右结合，例如`2^3^2=512`、`-2^2=-4`。百分号始终表示除以100，因此`200+10%=200.1`；增加10%可输入`200*(1+10%)`，比例、折扣等常用任务也有独立工具页。负数阶乘、非整数阶乘、`0^0`和负数的非整数次幂不在支持范围内。

内部使用有界的IEEE754双精度浮点计算，结果绝对值上限为1e300。显示最多12位有效数字；窄屏读数空间不足时减少显示位数，内部结果不随显示精度截断。结果继续计算与历史取回使用17位往返格式。它不是任意精度十进制或财务账务系统。算式长度上限96个ASCII字符，括号/函数深度上限24；运算步骤与递归都有界。

## 操作与布局

首次打开不显示焦点框；实际按键或手柄操作后才显示金色焦点，触屏操作会再次隐藏。输入方式同样适用于右上菜单；仅连接手柄或收到空闲报告不会启用焦点。上/下循环选择，确认执行；确认长按只执行一次。触屏在同一按钮内松开才执行，拖出或取消不会输入。完整手柄还可用B删除/返回、X清空输入、Y工具、L科学键、R历史、START菜单。

界面读取实际显示区、安全区和圆角，背景铺满屏幕，内容按比例排布。竖屏将读数放在大按键上方，横屏将键盘放在右侧；方屏、长竖屏与整数缩放的大屏均沿用同一绘制/触点坐标。数值工具选中A/B后，新输入会替换该字段；DEL逐位修改，AC清空字段。顶部返回按钮和右上菜单都可三键到达。

菜单提供继续计算、清空输入、保存退出和语言切换。清空输入保留历史、记忆和偏好。应用只在输入、页面切换或提示消失时重绘，不播放声音。

## 存储与测试

存档键`pxa-calculator.save.v1`，固定1008字节，包含`CALC`版本1、设置/状态、Ans与记忆值、当前输入、最多8条表达式/结果和FNV-1a32校验。数值显式编码为小端IEEE754，字符串、范围、保留位及完整性验证通过后整体替换。语言由共享运行时单独保存。换算和日常计算的临时输入不跨进程保存。

工作区根目录示例：

```sh
calculator_artifacts="$PWD/local/artifacts/calculator/$(date +%Y%m%d-%H%M%S)"
sh local/pxa-apps/calculator/tests/run-native.sh "$calculator_artifacts/native"
tools/app.sh build calculator --source-root local/pxa-apps \
  --target simulator,esp32s3,esp32s31 --aot-only --output "$calculator_artifacts/packages"
python3 local/pxa-apps/calculator/tests/simulator.py \
  --simulator build/simulator/doit-gamekit-1/pxsys_product_simulator \
  --packages "$calculator_artifacts/packages" \
  --publisher-key deps/pxa-system/apps/pxa/.dev-signing/publisher-public.der \
  --output "$calculator_artifacts/simulator"
```

原生测试覆盖优先级、已知函数值、非法输入、有界随机算式、单位往返、存档损坏，以及实际UI在多种比例和两种语言下的文字边界/重叠与三键操作。模拟器测试运行真实签名包，验证触屏取消、长按、计算、工具、历史确认、满屏尺寸和退出重启，不注入保存值。所有生成的日志、截图、数据和可执行文件均进入调用者指定的本地产物目录。

代码、图标和测试为原创CC0-1.0。图标保留可编辑的`assets/icon.svg`。共享SDK、宿主字体和工具保留各自许可。
