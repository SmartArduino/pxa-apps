# 秘宝冒险镇

《秘宝冒险镇》是运行于 PXA 的单人像素经营游戏。玩家从风石谷的驿站起步，经营临街铺面，组队搜寻回声矿洞的六件秘宝，把驿站发展成五星城镇。

## 开始游戏

在 PXA DevKit 环境下，从应用仓库根目录执行：

```sh
pxa run windstone-town --profile doit-gamekit-2
```

- **触摸**：拖动游览地图。点建筑查看详情。先在「建造」选设施，再点地块并确认施工。
- 「建造」在宽横屏显示为侧边卡片面板，在竖屏居中排列。卡片显示设施图、价格和解锁条件。选好地块后，确认栏会提示余款，整地时也会显示地块的高度变化。
- **手柄**：方向键移动焦点，A 确认，B 返回。城镇里按 Y 切到地图标记，方向键按地块移动。选定施工项目后，方向键选地块，A 开工。Start 切换速度。
- 双轴斜俯视地图大小为 20 × 23，共有四级地形。旅人从桥过河，沿石阶在相邻的高度之间走动。点顶栏地图按钮可在谷地、山脊和南岭林道之间切换。南岭沿路可建铺面或民居，东侧台地随镇级开放。
- **整地**：在「建造」切到「地形与道路」，可以找到「抬高地块」「降低地块」和「石阶」。空地可以逐层抬高或降低。石阶需要紧邻一条已通行、恰好相差一级高度的道路。店铺需要紧邻与地块同高的通行道路。镇级越高，可建设的山坡越多。
- 「旅人」名册显示当前活动。点地图上的旅人也能查看详情，选「定位」可跟随镜头。旅人在家或进入矿洞时，镜头指向对应地点。拖动地图或点「停止」可结束跟随。
- 旅人会自行消费和休息。在「旅人」详情可馈赠装备或安排公会训练。训练花费 26 金和 28 体力，每位旅人每天一次，随镇级提升可获得更多经验。
- 点旅店、铁匠铺、药房或集市的「经营账本」，可查看今日和昨日的付费到访次数及收入。惠民经营降低到访价并提高满意度，优质服务提高到访价及恢复效果，铁匠铺的优质服务会提高强化上限。旅人会比较钱包、距离和自身需求，到店时按当前价格支付。货架商品单独定价。
- 「成长」显示升级获得的成长点。每次升级获得一点，最高 25 级。武艺提高攻击，坚韧减轻反击伤害，行装降低远征体力消耗。各项最多投入八点。
- 旅人 2 级后可在「成长」打开「公会专精」。首次修习每项花 32 金，已修习的可免费切换。突击提高攻击，护卫提高防护并优先承受反击，探路减少远征消耗。训练和胜利提升当前专精的熟练度，精通后永久保留对应属性 +1。
- 铁匠铺、集市、药房和祭坛的货架提供装备或道具，新的货品随镇级和铺面等级开放。高阶饰物同时消耗遗物。远征会掉落物品，货架购入和远征战利品都进入共享仓库。
- 铁匠铺和祭坛的「炼成工坊」开放六种装备配方。配方消耗仓库中的原装备、金币和遗物。镇级及铺面等级达标后才可炼成，成品直接入库。
- 在旅人详情打开「装备与道具」，可换装、卸下、使用道具或出售库存。武器、护甲、饰物分别占一栏，更换时旧装备回仓。战力汇总攻击、防护和减耗。装备与道具的分配在旅人回到镇内后操作。
- 已装备的剑、弓、锤和杖会随战斗帧握在旅人手中，行走时也能看到携带的武器。护甲和饰物会出现在旅人的立绘、城镇行走和远征场景中。
- 每层首次常规通关后开放对应险境。点东岸的「回声矿洞」可组队挑战常规路线，点高处带宝石标记的「山脊裂隙」可组队挑战险境。「寻宝」里也能切换路线、查看进度和赏金。组队页显示守卫的生命、护甲、重击间隔和战利品。
- 重访同一条路线时会预选上次阵容，并替换尚在休整的旅人。初次挑战险境时，系统优先推荐有护卫的队伍。点旅人头像可调整阵容。
- 远征结束后的「战报」可查看最近一趟远征的轮数、入账金币、声望、遗物、每位旅人的经验和仓库掉落。
- 从一星起即可建造灯窗民居。点选空屋并「分配住户」，或从旅人详情选择民居。首次入住需要 45 满意度，已定居的旅人也可搬到另一间空屋。每间新分配的民居住一位旅人，扩建提高恢复量和房租。居民会在傍晚或受伤、疲劳时沿路回家。
- 野怪在谷地、东岸和南岭的道路旁分时刷新。城镇评级提升后开放更多刷怪点。状态良好的旅人会优先前往较近的遭遇点。傍晚，未被旅人追踪的野怪会退回林地。
- 镇级达到二星后，岭角王会出现在南岭林道。点地图上的首领，或从「寻宝 → 南岭讨伐」召集一至三人。队员沿路到达南岭后开战，首领每三回合发动一次重击。首次获胜掉落溪石坠，三日后首领再次出现。
- 队伍到达洞口后会继续沿矿道前进，遇见巡游怪、途中宝箱和最后的守卫。深层与险境中会遇见第二批巡游怪。每层的常规与险境宝箱各能开启一次，途中撤回也能带走已经取得的补给。
- 队伍在远征画面到达岔路时会停下等待选择。主路通往守卫大厅，侧洞让每位存活队员额外消耗 8 点体力，多打一场并有机会找到额外宝箱。常规和险境的侧洞宝箱各能开启一次。在小镇处理事务时，队伍会沿主路继续，如果存档时正在等待选路，继续游戏会回到岔路画面。
- 寻宝前挑选一到三名旅人，查看预计首击伤害。均衡维持常规消耗，强袭以更多体力和较重的反击伤害换取攻击，戒备降低双方伤害。守卫和骑士优先承受反击，并减轻受到的伤害。
- 矿洞首通奖励秘宝，重访可赚赏金和炼成所需的遗物。在「镇务 → 发展指引」查看下一星的声望、旅人和秘宝进度，也可直接前往相关界面。「镇务」还可举办灯会、制作护符和查阅秘宝图鉴。灯会期间，空闲旅人会前往广场停留，受伤或疲惫的居民优先回家。
- 在「镇务 → 镇上活动」可以举办广场灯会、公会集训或二星解锁的备战宴。同一时间广场只能举办一项活动。集训与备战宴由空闲旅人白天自行赴约，收益在到场时发放。集训提供经验与专精熟练度，赴宴恢复体力并留下整备效果，下次出征最多减耗 8 点体力。活动详情可以查看到场的旅人。
- 点公会、告示牌，或在「寻宝」打开「公会委托」。同时接取一项，可跨日完成，每天结算一次。矿洞委托每日都有，经营委托在付费到访、建设和野外悬赏间轮换。接取悬赏后，旅人自行击退的野怪会计入进度。
- 交战时可花 24 金补给，每趟一次，为仍在战斗的队员各恢复最多 28 点生命。路线走不通时可撤回，让队员回镇休整。
- 进度在建设、整地、队伍状态变化和每日结算后自动保存。早期版本的城镇和旅人会迁移到新地图。

## 美术与构建

项目使用 ImageGen 内置工具生成原创像素素材，整理为 `art/*.pxi` 后随组件嵌入。

| 素材 | 生成内容 |
| --- | --- |
| 封面和店铺 | 山间梯田与公会的微缩景观，八种斜俯视木石建筑 |
| 地形和植被 | 草地、土路、水面、崖壁分层和石阶纹理，树木、花草、木桥、栏杆和山顶地标 |
| 帧动画 | 八位旅人的前后朝向四帧步态与四帧战斗动作，六种守卫的五帧动作，河面水光、瀑布、旗帜、炊烟与火把的四帧循环 |
| 矿洞和秘宝 | 六层洞室战斗背景，六件可收藏的秘宝 |
| UI | 云杉绿与羊皮纸界面、按钮、施工描边和工具栏图标 |

地景、建筑、角色和界面使用同一张主视觉提取的基础色板。构建时 `tools/palette.py` 分别调整草地、石材、水面与界面的色阶，并保留图块的像素与透明边缘。渲染时逐层绘制岩壁并为相邻台地绘制石阶，按固定锚点播放生成的序列帧，用九宫格方式拼接 UI 皮肤。字形由 Noto Sans CJK SC Medium 栅格化，遵循 [SIL Open Font License](assets/OFL-NotoSansCJK.txt)。

常规构建使用已转换的图集。`python3 tools/make_art.py --help` 列出各图集的源图导入参数，脚本仅在开发阶段运行。
地景的 `--materials` 源图为四列三行的平铺纹理。`--flora` 和 `--landmarks` 使用透明精灵表，分别更新植被及村镇地标。
旅人的原尺寸 PNG 图集在 `assets/adventurers/`。通过 `--native-adventurers assets/adventurers` 导入时保留像素坐标和二值透明边缘。
守卫、水光和瀑布的原尺寸图集在 `assets/scenes/`，用 `--native-scenes assets/scenes` 导入。
装备和道具图标在 `assets/items.png`，用 `--native-items assets` 导入 18 × 18 像素的原尺寸图集。
战斗躯体、持握武器和穿戴贴图在 `assets/outfits/`，用 `--native-outfits assets/outfits` 导入。各动作的手位和握点在 `world_view.hpp` 中按原尺寸像素记录。

## 像素对齐

建筑、角色帧、图标、封面和战斗背景在导入阶段按游戏画布生成固定像素尺寸。地面、两侧岩壁、
石阶和施工标记的斜视投影也预先写入图集。运行时把图块按整数坐标贴到画布上，弹窗边缘使用原大
角块和重复边缘像素，封面及战斗场景根据可见范围裁取。PXA 根据屏幕可用面积在 1×、2×、4×
之间选用整数倍率。
