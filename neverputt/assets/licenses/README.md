Neverputt PXA uses GPL-2.0-or-later upstream game code, selected under GPL-3.0-or-later when combined with the shared guest bridge. Runtime assets are the upstream free courses, textures, sound/music, basic ball and DejaVu Sans Bold. Optional Octocat, HMD SDKs, PhysicsFS, SDL_ttf, libjpeg and system libvorbis are not included.

SDL2 and SDL2_mixer are guest-only zlib dependencies. Image/font rasterisation and Vorbis decoding use stb (MIT/public domain). PortableGL is MIT; see PortableGL.txt and vendor/portablegl/UPSTREAM.json for the RGB565 blend correction.
