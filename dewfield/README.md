# 晴露农场 Dewfield

PXA 上的原创俯视像素种田游戏。开垦土地、种下四种作物、每天浇水，睡觉后等待生长；收成放入出货箱，次日收到货款。池塘可以钓鱼，村民提供三段委托，清理树木和石头得到的材料可以制作洒水器。支持触摸、方向键和手柄，中英文界面。系统返回在弹窗中关闭当前页面，在农场中打开暂停，再次返回继续游戏；保存并退出通过暂停菜单选择。

点地块会自动走到附近并使用当前工具。成熟作物可以用任意工具收获；树木使用斧头，石头使用镐，杂草使用锄头或手。背包中的农场手册可以导航到小屋、种子铺、出货箱、水井、池塘和村民。再次点击已选中的物品栏格子会取消选择，可以空手行动。点击种子名称或 SELECT 切换播种工具使用的种类；直接装备种子堆时使用该种子。背包有 28 格，首排 7 格就是底部物品栏，拖动物品可交换位置，也可拖至空格；物品栏本身同样支持拖动。拖出格子或取消手势不会丢弃物品。拿着种子、收获物和材料时，角色会将物品举在头上。摇杆、操作按钮和工具栏避开系统返回与主页手势区，依据 Window 快照中的导航边距调整；不支持快照的 Host 使用保守内边距。右上角背包、农场手册和暂停使用独立图标入口；手柄操作时收起触摸摇杆和使用按钮，重新触屏后按保存的设置恢复。暂停菜单的「设置」可以分别开关虚拟摇杆、悬浮操作按钮及背景音乐，并切换语言。背包可用左右选择手册或洒水器制作按钮，手册支持方向键按两列导航。

| 操作 | 手柄 | 模拟器键盘 |
|---|---|---|
| 行走 | 方向键 | 方向键 |
| 使用工具、收竿、确认 | A / B | Z / X |
| 背包 | X | A |
| 农场手册 | Y | S |
| 切换工具 | L / R | Q / W |
| 切换种子 | SELECT | Tab |
| 暂停、保存、退出 | START | Enter |

萝卜、土豆、番茄、南瓜分别需要 2、3、4、5 个浇过水的夜晚。番茄收获后每两个浇水日再结果；缺水暂停生长。雨天自动浇水。每季七天，四季改变环境颜色，当前版本作物全年可种。一天从 06:00 到 22:00，每半秒推进一分钟；背包和对话暂停时间，22:00 自动休息。睡觉恢复体力和水量。

出货箱出售背包里的全部作物和鱼，次日结算；第三段村民委托需要三条未出货的鱼。洒水器消耗 8 木材和 6 石头，站在田地内从背包制作，之后每天早晨浇湿自身与上下左右四格。种子铺可以花 180 金币将水壶容量从 30 升到 60。

地图包含橡树、白桦、松树和果树，以及不同岩石、杂草与花丛。树木依次经历幼苗、小树和成树，经过 2 夜成为小树、累计 5 夜长成；成树砍倒后留下树桩，2 夜后重新萌芽，已开垦土地及人物所在格不会重新长树。不同树种、岩石有不同耐久，背包选中斧头或镐可以升级：铜质消耗 80 金币、8 木材、6 石头；铁质消耗 220 金币、16 木材、12 石头。以普通橡树为例，基础、铜、铁工具分别需要 5、3、2 次，升级也缩短动作并减少体力消耗。长按操作按钮可连续作业。

进度保存在应用私有 Storage，v3 为 768 字节（兼容旧版 512 字节），带版本、范围检查和完整校验和。v2 存档追加工具等级、受损物件、背包排列、树龄及设置；v3 继续保存所在地图、主线章节、访问与结识记录、四位村民的好感、每日聊天送礼及个人故事记录；兼容读取 v1/v2 存档。操作合并保存，暂停和退出立即提交；读取异常时保护原存档，避免用默认农场覆盖。升级应用时保留应用数据。

## 地图与村民

农场、晴露镇、林间小径、镜光湖畔和农舍通过固定出口相连。走到木牌标记，或在手册的「地图」选择目的地，都会沿现有道路前往；不会直接传送。手动行走或点地块可取消自动导航。农舍内点击床可以睡觉；无论在哪个区域过夜，清晨回到农舍。农场里的作物、树木、天气、出货结算在离开农场后仍然正常推进。

手册的「村民」显示四位朋友的当前位置与好感，点击名字会沿路追踪本人。小禾照料种子铺；阿岚午后去林间工作；澄在修桥前留在树林，修桥后去湖畔；林婆婆在镇广场活动。雨天改变户外安排，主线完成后大家傍晚在广场聚会。村民有四向外观和短距离行走，日程使用固定站点和安全步行片段，不在每帧执行全图寻路。

每位村民好感上限四心，每天第一次聊天增加 2 点（10 点一心）。拿起背包中的物品，再在对话里选择「送礼物」，每人每天可收一份。小禾和林婆婆偏爱蔬菜，阿岚偏爱木石，澄偏爱鱼；偏爱礼物加 6 点，其他礼物加 3 点。达到一心后会触发各自的个人故事。天气、时间、关系和聚会状态也影响日常对话。

「剧情」记录主线目标，完成条件后找相应村民选择「聊近况」：

1. 结识四位村民，向林婆婆报到。
2. 累计收获 3 份作物，向小禾报喜，获得补种种子。
3. 带 12 木材、9 石头找阿岚，消耗材料修好旧桥，开放湖区。
4. 实际到访湖区，带 3 条鱼交给澄。
5. 四位村民各达到一心，带 4 份蔬菜找林婆婆准备聚会。
6. 傍晚到镇广场，听取每位朋友的聚会对话。

每章有一次性金币奖励。材料不足不会扣除，重复聊天不会重复领奖。林间及湖畔有可拾取的少量资源，次日刷新。旧版农场设施与委托继续保留，老进度无需重开。

## 架构与性能

`core.hpp` / `core.cpp` 是与平台无关的规则、碰撞、寻路和存档编码；`world.hpp` / `world.cpp` 管理区域出口、日程、关系、采集与剧情条件。`main.cpp` 管理输入、自动行走、界面与分层绘制；`runtime.cpp` / `surface.inc` 封装 PXA Surface、事件和 Storage 生命周期。`terrain.hpp` 管理八邻域拼接、内外圆角、材质过渡和连接田垄；`scene.hpp` 管理固定容量的可见物件队列、按精确落地点排序与逆序点击判定；`art.hpp` 管理精灵合成；`ui_layout.hpp` 统一绘制与命中区域，`ui_icons.hpp` 保存原生像素图标；`sprites.hpp` 是离线编译的 RGB565 连续像素段，`title_art.hpp` 为编译好的启动插画。

所有区域复用同一份地表和地形材质缓存，只在切换区域、季节变化或世界事件时重建；离屏区域不参与逐帧合成。地表、栈桥与耕地绘制到 RGB565 缓存，移动时按行复制可见范围。80 字节的耕地外观标记检查开垦、湿度与有无作物的变化；变化时只修复农田区域，重新绘制碎土纹理和种植土窝。单纯行走或叶片生长不重算耕地，也不增加独立农田像素缓冲。房屋、水井、宝箱、围栏、边缘树木、作物、角色及其他前景物件使用同一个排序队列，按精确落地点从后到前合成；同深度使用稳定次序。阴影在所有实体之前绘制，避免压暗前景人物。图像绘制、裁剪和点击共用精灵的物理落地点；树根、石块、草、台阶、箱底与站立鞋底的最下方实像素统一位于落地点上一行；行走时分别计算双脚在地面上的投影。构建工具从底部轮廓生成去重的 RGB565 阴影混合段，树干、石块和箱体沿真实底边贴地，告示牌分成两根支柱，人物只在当前着地的鞋底下加强接触阴影，抬脚不携带深色阴影。接触阴影使用浅色窄边与低饱和暗色，无宽厚椭圆；围栏支柱、作物根部与鸡脚也分别对齐地面。运行时不扫描精灵透明度或临时生成阴影贴图。草地、道路与泥土共享相邻地块轮廓，地形拐角使用手工阶梯切角，水岸使用两像素台阶和浅水带；单格、凸角、凹角与对角邻域分别处理。草地使用成簇草纹，泥土使用带明暗的土粒，压实道路使用短擦痕与双色碎石；纹理由世界坐标生成，不在每个 16px 地块重置。不同土色以整色像素簇交错过渡，相邻耕地共享外轮廓，浅沟与土块以世界坐标分布，不重复描画格线或贯穿的等距横条；干湿土在交界用整色像素错落衔接，凹角继承相邻土壤的湿度。地形纹理与草丛描边在地表缓存构建时生成，移动过程中不重新计算；动态作物、水波、人物和遮挡物随后绘制，离屏树木不进入绘制器。寻路只在走完一格后执行，最多访问 768 格；运行中不动态分配地图或路径。主循环上限约 30 次每秒，环境动画约六次每秒，弹窗与标题静止时不连续绘图。480×480 屏幕进入农场后使用 240×240 的双缓冲 RGB565 Guest-mapped Surface，直接在已取得的映射缓冲上绘制；Host 使用已有整数 2 倍最近邻显示路径。标题保留原始输出分辨率，保持等比裁剪。Surface 重建时保持帧编号递增，兼容保留提交编号的 Host。无法省略的重采样优先使用已有 GameRender RGB565 批量操作，不支持时回退到应用软件缩放。细小 UI 笔画仍在 Guest 绘制，避免大量短命令的调用成本。帧率限制按绘制开始时刻计算，不在绘制结束后额外等待一帧。Guest 线性内存上限为 3 MiB。

UI 文字直接使用 ZLabs Pixel 12px 原始 KBitX 点阵，以横向笔画段绘制；在 Surface 上以整数倍画字，场景缩小显示路径由 Host 将字体和像素画一并整数放大。字库是独立命名的 Dewfield UI 12 子集。原字体、固定上游提交、SHA-256、OFL 和构建工具的 MIT 声明保存在 `art/`；发行包保留对应声明。启动插画使用内置 imagegen 生成，原图、提示词和来源保存在 `art/title-source.*`；树木、房屋、四向人物及 16 类工具和场景物件也使用内置 imagegen 制作原创素材，原图与精确提示词在 `art/world-v2/`；运行前由 `tools/build_sprites.py` 采样成整数像素精灵，不在游戏中解码 PNG。人物采用 GBA 俯视种田游戏的紧凑比例，站立约 28 像素高，头顶、肩部和鞋面体现俯视角。四向站姿使用相同等比缩放与 32 色共享调色板，按头部中心和脚底基线对齐。构建时将站姿绑定为躯干、双臂、双腿，像素段引用原始色值，无额外运行时贴图或透明度扫描。`gait.hpp` 用一个八阶段周期驱动四肢，同侧手臂和腿的前后摆幅相反，左右腿相隔半个周期，转向保持同一解剖侧的步态相位；支撑、经过、抬脚和落脚连续衔接。侧面远侧肢体先画并略压暗，近侧肢体后画；鞋和手保持原始像素高度，腿部与肩部关节保持连接。接触阴影跟随当前落脚点并合并重叠像素，抬脚不携带深色接触阴影。步态每移动 4 个逻辑像素推进一帧，连续跨地块不插入站立帧，停下后恢复站姿。行走中触发工具动作时，腿部继续按同一周期交替，工具上身姿势不会把双脚重置为站立。`tool_animation.hpp` 为锄头、种子袋、水壶、采收、斧头、镐和钓竿分别定义准备、发力与收回动作，持续 360–680ms，铜铁工具进一步缩短。工具实际握点与手腕共用坐标，离线生成旋转后的像素段，不在运行时旋转图像；双手工具连接两侧手臂。北向工具经过人物后方，播种撒种、采收伸手、浇水产生水流、钓竿甩线；拿物行走保留原有换腿周期。树冠遮挡角色时变透明，树干保留不透明；点击树冠、箱体或人物轮廓会定位到对应交互格。作物各阶段由原生像素绘制器生成，与背包中的收获物图案分别绘制。`soil.hpp` 统一每格的种植落点、干湿土色与预计算碎土纹理；土窝在地表缓存中绘制，植株、贴地阴影和遮挡排序共用该落点。萝卜只露出根部肩面，土豆显示有花的叶丛，番茄果实连接藤枝和落地支架，南瓜沿藤蔓贴地生长；根茎下缘使用土壤反光色，浇水后同步改变根部土色。

场景与 UI 共用首页的木棕、蜂蜜金、奶油色与橄榄绿，水与金属保留蓝绿点缀；精灵按同一暖光基准校色；精灵在构建时统一调色与压缩色板，不增加运行时调色开销。首页使用与插画木屋一致的暖色像素木牌、麻绳与叶饰，标题与入口保留整数倍字体。背景按原图宽高比在输出 Surface 上等比铺满并居中裁剪，横屏、方屏和竖屏共用同一缩放比例，不进行横纵独立拉伸。状态区使用分离的小卡片，工具栏保持底部居中；通知会绕开人物区域。背包、商店等弹窗显示独立遮罩，收起场景 HUD；圆角、边框和阴影使用同一组整数像素曲线，装饰不越过外轮廓。悬浮使用按钮、背包、手册和暂停采用像素图标，购买、睡觉等明确动作保留文字。弹窗命中范围严格对应实际按钮，点击空隙或弹窗外不会触发购买、制作等操作。

音乐由远程机器已有 ACE-Step 1.5 模型生成原创田园器乐，原始音频与完整生成参数保存在 `art/audio/`。构建音频采用单声道 22050Hz Ogg Vorbis，17.5 秒循环约 82KB，首尾等功率交叉淡化。`sound.inc` 通过已有 Audio 服务异步播放与循环，解码留在 Host；暂停、后台和关闭音乐会暂停或停止播放，权限或服务不可用时不影响游戏。

## 构建与检查

在 PXA workspace 根目录执行：

```sh
tools/app.sh build dewfield --source-root local/pxa-apps --target simulator,esp32s3,esp32s31
```

生成 `local/app-output/pai-touch/pxa-dewfield.pxa`，包含三种架构。桌面运行：

```sh
tools/simulator.sh product --profile pai-touch \
  --package local/app-output/pai-touch/pxa-dewfield \
  --publisher-key deps/pxa-system/apps/pxa/.dev-signing/publisher-public.der
```

esp-mosaico 构建与安装（先保存游戏，更新时保留应用存档；使用 `pxadb.py devices` 确认端口并设置 `dewfield_port`）：

```sh
tools/app.sh build dewfield --source-root local/pxa-apps \
  --board esp-mosaico --target simulator,esp32s31
dewfield_port=/dev/ttyACM0  # 按实际枚举结果修改
python3 tools/pxadb/pxadb.py package stop pxa-dewfield --port "$dewfield_port"
python3 tools/pxadb/pxadb.py package install \
  local/app-output/esp-mosaico/pxa-dewfield.pxa --yes --port "$dewfield_port"
python3 tools/pxadb/pxadb.py package run pxa-dewfield --port "$dewfield_port"
```
