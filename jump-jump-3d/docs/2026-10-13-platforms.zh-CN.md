# 0.1.3 平台扩充与验证

以 [weapp-jump 的固定版本](https://github.com/yaoshanliang/weapp-jump/blob/8102017c5357ae18a0df2eece2e09771e8648b66/game.js) 为参照，在原有六类平台上新增十四类，总计二十类。不改变上一轮修正的重力、蓄力、解析飞行和 320 ms 翻转。

## 平台

| 发光方块 | 占据时标记亮起，离开后恢复；蓄力时保持亮起 |

[全部新增造型](platforms/catalog.png)、[实际 AOT 游玩画面](platforms/aot-gameplay.png)。采用现有调色板和程序生成的低多边形几何，未引入原版的大尺寸贴图；保留辨识度，不逐像素复刻品牌图案。咖啡杯、药瓶的圆形顶面均可站立，装饰上的洞不作为可掉落孔洞。

普通生成有 60% 概率选择装饰平台，避免连续重复同一种装饰。开局两个平台和第一个预生成目标保持熟悉的外观。奖励平台仍按原有间隔优先生成，音乐盒 +30、商店 +15、魔方 +10、井盖 +5；新造型不额外发奖。

碰撞和阴影共享圆形分类。调整尺寸时同时调整中心位置，保持生成的边缘间隔；药瓶、纸巾卷更小，果岭更宽。所有标记随蓄力压缩和入场下落移动；不把闪灯和发光状态存入额外动画对象。

## 绘制与音频

恒定光照的装饰、顶部标记、粒子矩形和不透明圆环改用已有纯色四边形命令；保持绘制顺序，缺少该能力的 Host 回退到原有三角形路径。没有增加纹理、命令队列或深度缓冲。

连续游玩发现音乐盒长音效与后续蓄力音效的缓存冲突。现在加载长音效前释放闲置准备资源，离开后释放长音效句柄，先停止旧 Host 声道再请求新资源。混音器排空期间的临时配额不足允许三次有限重试，不再第一次失败就永久禁用音效。缓存仍为八个准备槽位和一个加载协程，没有提高 Host 缓存上限。共享 `AudioBank` 的失败日志增加资源路径和错误码，便于排查其他游戏。

上述三次重试是 0.1.3 的历史行为；0.1.4 已改为临时失败持续退避，并处理取消后到达的加载结果，见[音频恢复报告](2026-10-13-audio-recovery.zh-CN.md)。

## 得分页与系统时间

得分页原先每个时钟事件都重绘整屏半透明遮罩，Korvo 上光栅耗时约 58 ms，超过自适应画质的 40 ms 降档阈值。因此不是静止画面的零 FPS 被误判，而是重复绘制昂贵遮罩触发了降档。现在提交成功后保留得分页最后一帧，显示环境变化和恢复前台仍可重绘；提交失败会重试。得分页不参与画质采样，重新开始时重设采样基线，继续推进时钟、音频和存档。

Korvo 真机在得分页停留 60 秒，提交/光栅/显示计数均不变，没有重建渲染器或降低分辨率；切换前后台后画面正确，重新开始恢复绘制，随后成功跳跃得分。见 [保留帧测试](platforms/result-retention.json)、[前台恢复截图](platforms/result-foreground.jpg) 和 [重新开始截图](platforms/result-restarted.jpg)。顶部开发 FPS 浮层的零值表示没有提交新帧，不表示游戏性能下降。

原 Clock 0.1 只有单调时间接口。新增 Clock 0.2 的 `wall_time()` 和 `time_zone()`，Host 返回固定 24 B 快照，SDK 使用 `std::chrono` 值类型；不分配动态字符串、不增加默认缓存或嵌套 Task。POSIX 实现由固件和模拟器共享，读取 Host 实际生效的时区，不在 Guest 写死东八区。Korvo 本次返回 `offset_s=28800`，钟表显示系统本地时间，见 [模拟器本地钟表](platforms/clock-local.png)。

时区快照包含当前有效 UTC 偏移和夏令时状态，不包含 IANA 名称或历史/未来规则，也不声称系统已完成网络校时。模拟器继承宿主时区，可用 `TZ` 验证；当前固件启动配置为 `CST-8`。清单声明 Clock 最低版本 0.2，因此本次只更新了 Korvo 的应用固件分区和游戏包，保留其他应用、存档与设备设置。

补充音频排查：Korvo 在 800×480 连续蓄力十秒，连续窗口均为每 2000 ms 写入 100 帧、消费 100 个非零 DMA 块，写入错误和音乐解码欠载均为零。用户拔插 USB 后杂音消失，尚不能区分供电/接触波动与编解码器、功放断电复位的作用；没有声学录音或电源波形，不宣称根因已证实。本次排查未更换素材或烧录音频诊断固件。见 [排查记录](platforms/audio-noise-check.json)。

## 验证

- 原生十项检查通过。四组种子、800 次中心跳覆盖所有二十类平台，核对圆形边界、落地高度、奖励和生成间隔。
- 480 个特效场景与 7,168 个可到达的混合平台组合通过真实 Host 校验和光栅器；混合组合使用 800×480、十位分数和全部反馈，最大命令 **15,732 / 16,384 B**。
- 72 帧共享/独立临时缓冲的资源、命令和像素一致。纯色四边形与回退路径的内部颜色一致；二十类平台合计 201 个边界像素有一像素以内的覆盖差异。
- ASan/UBSan 五项相关检查通过；音频资源释放检查确认仍在活动的蓄力音效不会被释放。
- 六种实际 SDK 模拟器屏幕配置通过：296×240/160 DPI 圆角、480×480/305 DPI 圆角、176×176 圆屏、320×480/240 DPI、800×480、480×800/320 DPI。
- 独立诊断 AOT 包连续重放十八次跳跃；参数、平台类型、落地回调及截图由 `tools/reference/simulator_platforms.py` 记录。诊断包不用于真机 FPS 对比。
- 完整 C++ SDK 原生检查、Clock POSIX Host 检查和 Core 导入约束检查通过。时区覆盖 UTC、东八区、负偏移、半小时/45 分钟偏移、跨年、负 Unix 时间和夏令时切换；SDK 覆盖错误、取消、长度/保留位及加法溢出，并检查查询不额外占用协程池槽位。

详细检查输出、屏幕矩阵和游玩记录位于 [platforms](platforms)。此前已有的 Pixel Dungeon C/新 SDK 逐像素参照失败不在本轮范围内；其当前核心与光栅检查通过。

## 内存与性能

游戏状态 324 B、渲染状态 9520 B、共享绘制/上传内存 32788 B、完整应用状态 43560 B 均保持不变。钟表分钟/秒和音频重试字段使用已有对齐空间；原生 `AudioBank` 大小仍为 552 B。Guest 初始线性内存 131072 B、上限 1048576 B；三帧缓冲 2304000 B、命令队列 49152 B、深度缓冲 0 B 均不变。

代码映射会随新增模型和逻辑增长，不能宣称总 PSRAM 占用不变。实际 AOT 体积、真机稳定占用和开机累计峰值以随报告保存的测量为准；整机累计峰值包括包安装、启动、截图和此前运行，不能当作单次游戏峰值。

相同 READY 画面的原生 Host 光栅对照：五轮中位数由 281 µs 到 264 µs，像素差异为零。两组耗时范围重叠，支持该路径没有显著回退，不作为真机 FPS 收益的证据。新增平台与旧普通平台是不同工作负载。

Korvo（800×480、216 DPI、相同开局 READY/最高分 120）排除启动窗口后的三个 5 秒窗口均值如下。前后为独立启动；新版固件另外增加 Clock 0.2，光栅和显示配置相同。原始计数、包与固件哈希见 [对照数据](platforms/device-comparison.json) 和 [构建哈希](platforms/package-hashes.json)。

| 指标 | 0.1.2 | 0.1.3 |
|---|---:|---:|
| 实际显示 FPS | 37.81 | 37.33 |
| 应用提交 FPS | 48.13 | 46.52 |
| Host 光栅 / 帧 | 15.60 ms | 15.91 ms |
| 排队 / 帧 | 5.56 ms | 5.78 ms |
| 显示 / 帧 | 21.26 ms | 21.60 ms |
| READY 命令 | 6116 B | 5936 B |
| READY SRAM 空闲 | 59195 B | 59035 B |
| READY PSRAM 空闲 | 10434636 B | 10385692 B |
| 游戏预算内部 / 外部稳定占用 | 44924 / 196938 B | 44924 / 196938 B |

实际显示帧率约 37 FPS，本次样本没有证实 FPS 提升，新版低约 1.3%；不能把更少的命令字节或提交 FPS 当作显示性能收益。阶段时间来自各自计数，不应直接相加推导 FPS。新增模型也不与旧普通模型混作同一性能场景。

固定数据和 Host 游戏资源预算保持不变；整机稳定空闲 SRAM 少 160 B、PSRAM 少 48944 B，不能宣称整机占用下降。S31 AOT 从 465836 增至 587756 B（+121920 B），S3 +102468 B、桌面 +80840 B，包含新增模型与系统时间逻辑。音频缓存从开局 138304 B 到操作后 210064 B，前后相同。截图前已记录新版初始化占用；[内存原始采样](platforms/device-memory.json) 中所有最低空闲/预算峰值均为开机累计值，前版还包含历史会话，**未取得可公平比较的单次真实峰值**，不以这些累计值推断峰值改善。

## 复现

从 workspace 根目录运行：

```sh
PXA_CPP_GAME_TEST_BUILD="$PWD/local/jump-platform-tests" \
  bash local/pxa-apps/common/cpp/tests/run.sh \
  -DCMAKE_C_COMPILER=clang -DCMAKE_CXX_COMPILER=clang++

bash tools/app.sh build jump-jump-3d --target simulator,esp32s3,esp32s31 \
  --aot-only --source-root local/pxa-apps --output local/jump-platform-release

# 原生造型预览，kind 7..20；隐藏角色以检查平台细节。
local/jump-platform-tests/jump_preview --kind 7 --special-age 0 \
  --skip 0x10 --width 296 --height 240 --out /tmp/jump-clock

# Korvo 上已安装测试包时重放；会停止并重新启动该游戏，保留存储。
python3 local/pxa-apps/jump-jump-3d/tools/reference/device_measure.py \
  local/jump-platform-device

# 自动进入得分页，停留 60 秒，再检查前后台、重新开始和一次跳跃。
python3 local/pxa-apps/jump-jump-3d/tools/reference/device_result_retention.py \
  local/jump-result-retention

# Clock Host 边界与完整 SDK 检查。
ctest --test-dir build/simulator/pai-touch -R '^pxa_posix_clock_test$' --output-on-failure
bash deps/pxa-system/tools/package/test_guest_cpp.sh
```

构建保持 C++26 / O3。模拟器诊断额外启用 `J3_TRACE_TIMING=1`，生产包关闭该宏。
