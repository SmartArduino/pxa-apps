# 弹珠迷宫

独立 PXA 游戏，包 ID `pxa-marble-maze`。有自己的首页、选关、设置、图标与存档。

- 12关分为嫩叶小径、林间寻星和星光探险，迷宫随进度扩大，并使用不同配色。收齐三颗星后到达金色出口，解锁下一关；记录每关最好用时。
- 每次启动后首次进入体感玩法时拿稳约一秒完成校准；同次运行的过关、重试、选关、暂停与后台恢复沿用有效校准，不用反复拿稳。需要改变握持基准时，暂停页可手动“重新校准体感”。之后轻倾设备控制弹珠。传感器读数超过400毫秒未更新时冻结弹珠和计时；首次授权失败仍可使用按键或触屏。
- 确认暂停，暂停页提供继续、重新校准、切换控制方式、路线提示、重玩本关及首页。三按键的按键玩法自动前进，↑↓转向，确认暂停；长按方向键可连续转向。触屏可按住棋盘并拖动，右上角暂停。
- 设置提供体感、按键、触屏三种控制方式、三档灵敏度、每次90度方向旋转与左右镜像。选关页跳过未解锁按钮，支持三按键和触摸。
- 返回首页、暂停、退出后台、收集星星时保存当前位置；游玩中每15秒补存。重启可继续原来的一关，包含已收星星、用时和弹珠位置。换屏幕比例导致棋盘尺寸变化时重新开始该关，保留解锁与最好成绩。
- 后台自动暂停、释放传感器；静止画面保留，只有位置、计时或动画变化时重绘。横屏、普通竖屏、长竖屏使用适合比例的棋盘。全程离线，不需要SD卡。

在 `pxa-projects` 构建：

```sh
tools/app.sh build marble-maze --board doit-gamekit-1 --target esp32s3 --aot-only \
  --source-root "$PWD/local/pxa-apps" --output "$PWD/local/app-output/marble-maze"
```

模拟器使用 `--target simulator`。资源生成与测试见 [共用支持代码](../common/motion-games/README.md)。体感只请求加速度读取权限，音效另外请求可选的声音播放权限；倾斜控制使用重力方向，避免积分角速度的累计漂移。代码、原创图标与 PXA SDK 使用 MIT；字形的 SIL OFL 声明完整保存在 `assets/NOTICE.txt`。

文字使用设备系统字体。拾星、碰壁和过关采用简短的原创合成音效；设置及暂停页右上角可开关音效，偏好单独保存，后台停止声音。
