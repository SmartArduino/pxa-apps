# 烬港斗魂 / Ash Harbor

原创的雨港武侠 1 对 1 格斗原型。主角在港城的港灯夜擂上交手，以掌劲、
步法和近身连段争夺码头的守护权。包含三幕开幕剧情、四名可选拳师、四处擂台、局域网双人对战、
依次挑战其余三人的街机巡回，以及不计时、自动补充气槽的训练模式。每战三局两胜。

每台设备控制一名拳师；本机双手柄与独立剧情关卡尚未提供。

## 角色

| 角色 | 设定 | 当前手感 |
| --- | --- | --- |
| 陆炎 / YAN | 戴朱红长巾的港口信使，以烬火掌劲破开防线 | 移动较快，拳脚启动较短，飞行道具较快 |
| 霁岚 / LAN | 银发、玉青护腕的港务守擂人，以潮息拳法控场 | 重脚更远、伤害略高，启动较慢；掌劲较慢、伤害较高 |
| 韩震 / ZHEN | 铜护腕、赭色短褂的码头工头，替工友讨回公道 | 步法较慢、抗推能力强；重拳、投技和绝招伤害较高 |
| 唐绫 / LING | 紫衣黑发的疾电拳师，追查失踪师姐留下的雷痕 | 步法快、跳跃高；快脚、空中踢击和突进更灵活 |

角色、场景、动作、特效、标题和 UI 素材由内置 ImageGen 生成。正文使用真正的
Fusion Pixel（缝合像素）12px 像素字体，中英文字形共用原生基线；保留 OFL
许可和上游声明，不使用系统默认字体。每名角色使用 44 个动作图像；原四帧行走
由八帧双腿交替步态替换，并保留低扫、抓取、闪避、倒地扩展动作。
基础动作按独立人物轮廓提取，保留越过原格线的围巾与伸腿，再按原始坐标绘制；
图集帧之间留透明间隔，避免把相邻动作带入镜像采样。

## 启动

在 PXA 工作区根目录执行：

~~~sh
tools/dev.sh sim ash-harbor --source-root local/pxa-apps --profile doit-gamekit-2
~~~

首次打开播放「港灯邀擂／各有所求／今夜开擂」三幕剧情；按确认或点画面继续，
B／返回或「跳过」直接进入首页。看完或跳过后保存已看状态；首页「剧情」随时重看。
首页选择「街机」或「训练」，「招式」查看当前拳师招式表。Select 快速轮换角色，
X 或点姓名打开四人选人界面，方向键选择，A 确认、B 返回；也支持直接点头像后「选定」。
所选角色单独保存。街机获胜后「下一战」继续，击败另外三人后显示「夜擂通关」。
进入街机和训练均先显示四人对手选择，可点头像或用方向键选择，再确认开战／开始训练。
街机的「三战巡回」从选定拳师开始，后两战依次挑战其余拳师；点模式按钮或按
Select 可切换「自由对战」，只进行所选对手的一场三局两胜。选择我方同一拳师时
自动进入镜像对战。结算页「换个对手」可重新选择；训练设置中也可随时换陪练。
暂停菜单支持继续、招式表、重开和回到首页。
后台切换会暂停并清除按住的输入。

首页左侧可切换「入门／标准／高手」，手柄 L／R 也可切换；难度随选择保存。
街机后三战逐步提高反应与防守强度，仍按角色距离和有限反应间隔决策。
韩震偏好近身投技，霁岚和唐绫偏好腿法；满气时对手会主动使用超必杀。

训练时点顶部「训练」打开设置；手柄可暂停后按 X。陪练可选站立、全防御、
受击后防、自由对练，可独立选择四名陪练拳师，并开关最近五次输入记录。
方向记录显示实际屏幕方向的八向箭头，中立用小圆点表示；P／K／E／S 分别为拳、脚、闪避和简化必杀。
HUD 显示当前连击、实际伤害及本次训练最高伤害。只有对手尚在受击硬直内的
命中才累加连击，恢复行动后再次受击另起一组；防御不会连接连击。
修改陪练方式或拳师后返回会重置训练；「重置位置」同时清空训练统计和输入。
暂停后重开及 L+R 也可重置，设置页可用方向键／A 操作，B 返回练习。

## 局域网双人对战

两端安装相同版本，连接同一 Wi-Fi／局域网。首页「联机」中先选择拳师；
房主选择擂台后「创建房间」，另一方「搜索房间」，根据房主拳师、IP 和擂台选房即可加入；已开战的房间从搜索中移除。
也可用「输入地址」填写房主界面显示的 IPv4 地址。手柄用方向键切换选项，
A／Start 确认，B 返回；地址键盘同样支持手柄。战斗 HUD 的 1P／2P 标明本机玩家；连击、招式提示、回合胜负、结算语音均按本机玩家呈现。

由房主按 60Hz 计算双方战斗，另一端接收权威状态；双方都完成资源加载后才开局。
方向变化和攻击边沿带序号与确认重传，避免重复包制造额外攻击或丢掉短按。
任一方暂停，整场暂停；发起方继续后恢复。三局两胜后双方选择「再来一局」再战。
「退出房间」、切到后台或断线均会退出当前会话，不改动离线进度。短暂收不到数据时
双方暂停战斗，长时间中断提示重新加入，不在失联期间继续计算伤害。
即使握手仍能到达，只要战斗状态无法传递，仍按失联处理；恢复数据后自动解除网络等待。
两端须使用同一版本，旧版协议不与当前版本混用。

联机需要 Host 支持 UDP/IPv4；自动搜索还需要局域网服务发现授权。
搜索受路由器隔离影响时可尝试直接输入地址。当前支持此能力的 ESP、Linux／macOS
原生 Host；网页及尚无 UDP 能力的 Host 会给出提示，离线模式仍可使用。
此模式不包含互联网中继、跨公网匹配或 NAT 穿透。

## 电脑对手

电脑使用有延迟的动作、位置与命中反馈判断，不读取玩家按键或搓招缓存。
入门、标准、高手分别保留 22、14、9 个模拟帧的基础观察延迟；街机后两战仅小幅缩短
标准和高手的反应时间，最低 7 帧，不增加伤害、速度或无敌时间。入门难度会在收招后
停顿并减少压制，高手难度更积极地抓打空、对空和命中确认。

陆炎偏向近身拳脚接必杀，霁岚以长脚和掌劲控制距离，韩震主动贴身寻找投技，
唐绫更多使用突进和跳入。电脑按实际攻击距离与收招时间选择反击，观察飞行道具的
方向决定防御或跳跃，命中后按剩余硬直选择取消；被防住时不盲目接超必杀。满气时也会少量尝试有正常起手和收招的近身压制，可被防守反击。
突进也经过方向输入和正常招式判定。训练的站立、防御、受击后防保持固定行为，
自由对练才使用完整 AI。联机模式始终由两位玩家控制，AI 不参与。

## 操作与招式

| 动作 | 手柄 | 桌面键盘 |
| --- | --- | --- |
| 移动、蹲下、跳跃 | 方向键 | 方向键 |
| 拳 P | A | Z |
| 脚 K | B | X |
| 闪避 | X | A |
| 简化必杀 S | Y | S |
| 暂停 / 确认 | Start / A | Enter / Z |
| 招式表；首页换人 | Select | Tab |
| 训练重置 | L + R | Q + W |

后拉防御，斜后下防下段。空中脚需要站立防御；普通投不能防御。
近身 P+K 抓取，蹲下 K 低扫；P 命中或被防后可接 K，
普通拳脚再取消为必杀，必杀命中或被防后可取消为超必杀。

普通投抓住后保留 12 个模拟帧的挣脱窗口，被抓方新按「拳＋脚」可拆投；
一直按住不会自动挣脱。成功拆投会将双方分开，不扣血、不增加连击，并显示「投技挣脱」。
双方同时输入普通投也会相互挣脱。普通投不能抓空中的对手，落地后短暂防投；
受击／防御恢复和拆投后也有防连投保护，仅防投，不免疫拳脚。投技说明同时显示在招式表。
AI 只在看到自己被抓后进行一次有延迟、可能失败的拆投尝试；入门不会即时拆投。
停帧期间的按键缓冲同时保存当时的方向，因此松开方向不会把升龙、低扫、后闪或超必杀变成别的招式。

招式表使用方向箭头和中文拳脚标签，不需要记小键盘数字。下表以面向右侧为例，
按箭头顺序连贯输入，再按拳或脚；面向左侧时将所有左右方向互换。
近身同时按拳和脚可投技，超必杀行单独标注满气条件。

| 指令 | 陆炎 | 霁岚 | 韩震 | 唐绫 |
| --- | --- | --- | --- | --- |
| ↓ ↘ → + 拳 | 烬流掌 | 潮刃掌 | 震潮掌 | 惊雷掌 |
| → ↓ ↘ + 拳 | 破空拳 | 鹤升拳 | 撼山拳 | 掠云拳 |
| ↓ ↙ ← + 脚 | 踏潮进 | 断浪步 | 铁肩撞 | 逐电步 |
| ↓ ↘ → ↓ ↘ → + 拳（满气） | 燎原潮 | 月满潮 | 崩港震 | 紫电破 |

默认隐藏虚拟按键；触摸后显示，使用手柄或键盘后隐藏，并取消先前触点。
按住方向时可用其他手指同时按拳、脚、闪避或技能；抬起或取消单指只释放该指，
同一按键被两指按住时会保持到最后一指释放。硬件支持的触点数取决于板型。
虚拟按键会避让设备实际声明的底部导航栏和手势检测区，额外保留 6 个逻辑像素；
绘制与触摸判定使用相同偏移。隐藏系统栏之前记录其输入保留区域。

超必杀消耗 100 点气。攻击命中和防御积累气槽。触屏可同时按住左侧方向区与
右侧按钮；S 直接发掌，上+S 对空，下+S 在满气时发动超必杀。普通投和完整
搓招在手柄上更容易操作。上+S 接受跳跃初始 6 帧内补按，避免方向先触发跳跃。

## 声音

包含 22 类生成音效、标题与对战循环配乐、胜负短曲，四人的独立角色语音库共 60 条、每人 15 条，
覆盖开场、喊招、攻击、受伤、闪避、投技、倒地及胜负。素材使用已有的远程 ComfyUI
Stable Audio 3 Small SFX、ACE-Step 1.5 模型制作；角色声线由 Qwen3-TTS VoiceDesign
原创设计，选定陆炎 B、霁岚 A、韩震 A、唐绫 B 后，用 Qwen3-TTS Base 参考音频续写台词，
保持每位拳师的音色。模型不随应用分发。Base 延续参考音的声线与表达，不支持逐句情绪指令；
配置中的 performance 是表演设计记录。完整短喝与痛呼只裁首尾静音，保留 16 位精度，
超长片段需重新生成，不从波形峰值截断。生成工具校验选定参考音的 SHA-256。
语音播放时自动压低音乐；暂停和后台切换停音。首页、战斗 HUD 和暂停菜单的
「声／静」按钮切换总静音并保存；在首页或暂停菜单也可按手柄 Y。
短音效和语音按需加载，和角色图集共同遵守资源缓存预算；音乐由 Host 流式播放。
角色语音库为可选内容；尚未导入某位拳师的语音时，其战斗音效和配乐仍正常播放，
不会套用另一位拳师的声音。
可复现的提示词、生成与转换工具位于 tools/audio-prompts.json、tools/voice-prompts.json
及对应的 generate_/prepare_ 脚本。

## 战斗参数与动画

逻辑固定为 60 Hz，与绘制频率分离。普通搓招窗口 26 帧，双 236 窗口 44 帧；
方向序列不能夹入相反方向。攻击按键缓冲 8 帧，命中停顿期间不消耗按键缓冲。
同帧有效攻击可相互命中；闪避和对空技有独立无敌帧。连段逐击衰减伤害，
气槽、硬直、推开距离和判定范围均由代码控制，动画不决定命中结果。
跳跃中可按左右逐渐改变横向速度；松开方向保留惯性，空中攻击继续横向移动。
斜上与拳脚同一帧输入可直接跳攻。近身 P+K 发动投技，韩震拥有更远的抓取距离；
闪避的前进／后退方向在起手时锁定，松开方向不会使动作中途折返。

陆炎的基础参数如下，单位为逻辑帧：

| 动作 | 启动 / 有效 / 收招 | 基础伤害 |
| --- | --- | --- |
| 拳 | 5 / 3 / 11 | 7 |
| 脚 | 9 / 4 / 17 | 12 |
| 低扫 | 7 / 4 / 15 | 9 |
| 发掌 | 12 / 3 / 22 | 12 |
| 对空拳 | 5 / 12 / 29 | 18 |
| 突进 | 10 / 6 / 21 | 16 |
| 超必杀 | 18 / 8 / 32 | 31 |

霁岚的重脚加 6 像素距离、1 点伤害和 2 帧启动；
掌劲、对空加 2 点伤害和 2 帧启动，突进加 8 像素距离和 3 帧收招。

机制研究参考 [SNK《拳皇 XV》战斗系统](https://www.snk-corp.co.jp/webmanual/kofxv/cn/howtoplay2.php)
与 [官方出招表](https://www.snk-corp.co.jp/official/kof-xv/command/commandlist.pdf)。
这里只参考方向指令、防御与取消等通用设计，数值、角色、招式和素材为本项目设计。

## 美术资源与像素密度

原始生成图位于 art/source，提示词位于 tools/art-prompts.json、tools/ui-prompts.json、tools/walk-prompt.json 与 tools/walk-finish-prompts.json。
四人扩展、剧情、独立步态和扩展场景的提示词位于 tools/expansion-prompts.json。
tools/build_art.py 负责动作取帧、最近邻缩放、共享索引色和图集打包。
按钮、血条、能量条、计时牌、图标、数字和 KO 等提示使用拼接图块。可变宽按钮
与面板用九宫格保持边角；计时牌等独立图形保持比例，选择括号分为左右两块。
菜单、角色名、招式和说明默认中文；普通英文大小写与小号数字由同一套 Fusion Pixel
字体生成。原始字体位于 tools/fonts，授权声明随应用分发。文字按 12px 的整数倍
绘制，保持原生点阵和基线，不拉伸单个字形。
框内文字按实际像素宽度排版；训练统计与输入记录各有独立列，底部空间不足时收起
训练设置中重复的最高成绩。按钮的横向装饰边角独立保留，避免九宫格把角花重复进正文。
剧情图保留源图比例，用等比覆盖填满实际视口并裁剪超出的边缘；四比三画面的第二幕
微调横向取景，字幕和按钮使用独立安全边距，不把整幅插画拉成屏幕比例。

界面参考画面是 320×240。人物基础帧以 96×128、扩展帧以 128×128 为参考坐标，
独立轮廓取帧后保留原有偏移。大屏优先整数缩放，小于参考尺寸的屏幕整体等比缩小，
全部使用最近邻采样，不分别拉伸横轴和纵轴。界面与触摸坐标共用同一变换。
镜头按两人的完整动作轮廓计算取景，必要时等比缩远并跟随跳跃，保留头顶和脚底；
待机、呼吸和行走使用每名拳师固定的中立姿势边界，呼吸帧变化不会移动背景。
场景和人物共用镜头变换。四处擂台均为 512×304，落脚参考线在第 256 行，
按实际视野裁剪，人物不会因镜头移动而站进港水里。超过场景宽度的超宽屏保留两侧留边。
飞行掌劲在出掌帧从各角色登记的掌心像素生成；发射点和人物裁剪、左右镜像及镜头
使用相同坐标。首帧停留在掌心，随后按逻辑帧飞行并独立播放四帧动画，命中火花
使用实际接触位置。掌心高度的掌劲可被蹲伏避过；上下错开的飞行道具不会相消。
八帧行走由实际地面位移驱动；后退时反向播放，撞墙和命中停顿不会原地踏步。
行走播放八幅完整重绘的全身帧图，腰部、裤褶和膝部保持连续。近腿与远腿的
分件只用于生成姿势参考；运行资源直接取完整帧图，不拼接人物上下半身。
一个完整周期对应 80px 地面位移。

场景、字形和特效常驻；UI 图块紧凑打包且不缩放。角色图集以无损 RLE 数据随程序
分发，进入对战时只解码当前两人的动作；切换人物后释放不再使用的解码页。这样换动作
不再反复读取 SD 卡，也不会挤占默认 512 KiB Assets 缓存中的音效和语音资源。
头像单独打包，不为选人同时加载四套动作。支持 48 槽的渲染器会预上传两人的全部
动作；旧渲染器保留 16 槽兼容路径，以最多 448 KiB 的动态图集复用纹理槽。
不用左右朝向的重复图片，左向通过 UV 镜像绘制。缺少纹理时维持上一张完整画面；
预热期间暂停对战计时，避免开场动画被加载时间跳过。重新生成美术时会同步重建压缩
数据，tests/frame_cache_test.py 校验每页像素与原始图集完全一致，并检查双人缓存上限。

重新打包资源并构建：

~~~sh
python3 local/pxa-apps/ash-harbor/tools/build_art.py
tools/app.sh build ash-harbor --target all --source-root local/pxa-apps
~~~

没有 SD 卡的 P4 设备可先用 `tools/prepare_device_source.py --output <暂存源根>/ash-harbor`
准备安装源，再以该暂存源根构建 `--target esp32p4 --aot-only` 包，并沿用原发布者签名。
该流程仅移除已经内嵌在程序中的动态图集副本，保留静态 UI、全部音频和字体许可证；
运行时代码及像素数据保持一致。小容量 LittleFS 可安装构建输出的签名包目录，利用固件的
目录接管流程避免再次复制文件。目录和流式容器均保留正常签名、兼容性及空间检查。

## 开发验证

combat.hpp 可脱离 SDK 运行，tests/combat_test.cpp 检查指令、防御、取消、
投技、回合切换和确定性压力运行。tests/runtime.py 在真实 PXA 产品模拟器中
注入控制器与多点触摸，并检查渲染、训练、必杀、暂停和返回行为。

运行结果、构建输出、截图和日志均放到工作区被忽略的
local/artifacts/ash-harbor/<YYYYMMDD-HHMMSS>/。截图不是生成图；商城图片应另走
verify --store-screenshots 流程并逐张检查原图。

首页的「场景」和选对手页面的「场景」可切换雨港夜渡、竹影晨院、雪关古门、
灯河石桥；手柄在选对手时按 X 打开场景选择。街机三战从所选场景依次轮换，
训练和自由对战使用所选场景，场景选择随设置保存。只预热当前场景与双方角色，避免把四处擂台一起常驻。
每个场景配有一首 ACE-Step 1.5 生成的纯器乐曲，按 64 拍裁切并交叉衔接循环，
角色发声时自动压低音乐。生成与处理记录见 tools/scene-music-prompts.json。

悬浮方向盘使用八支细箭头和小中心钮，四个斜向均可按住、拖入或与攻击指同时使用。
中心有静止区，松手或取消触点即释放方向；八扇区按触点与中心的夹角判断。
新增画面及其提示词保存在 art/source 与 tools/stage-control-prompts.json。
开幕三幕为「港灯邀擂」「各有所求」「今夜开擂」，以本地夜擂与四人的个人动机展开；
港口船只统一为中式木质帆船，没有外来舰队或停战设定。
