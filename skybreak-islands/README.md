# 云峡巡航

第三人称 PXA 像素飞行游戏。驾驶战机穿过群岛和立体云层，迎击三波敌机。每次出击都有一架青色标记的同型僚机跟队，它会自行攻击进入射程的敌机，也可能被击落。加速时能看到尾焰和速度线，导弹和爆炸会留下烟迹。贴海掠飞会在水面激起两道浪花。

标题页可循环选择 F-01 双发巡航机、F-02 单发三角翼快机和 F-03 宽翼低空机。机型分别有不同的巡航速度、加速上限和姿态响应。

岛上有高地湖泊、弯曲的河谷和入海河口。低洼的湖岸长着芦苇，高地之间有草甸、林地和裸露岩坡。湖水有独立的水位，射击水面或贴水掠过湖泊和河流也会激起水花。在空中按 R 或点右上角可切到俯视视角，查看整段河道。

机翼和机身中弹后会留下焦痕，严重受损时会冒烟起火，翼尖也可能脱落并引起偏滚。机体被击毁或撞地时会自动弹射，也可以提前离机。弹射时机盖飞脱，残骸随地表扬起水花或尘土。开伞后可转向。高度足够时，与你所选机型相同的救援机会飞到下方，打开机盖接人。低空跳伞仍支持着陆和水上救援。

选择「海峡护航」可以护送运输船。拦截飞向船只的敌机，直到船开过航道出口的两座浮标。雷达上的浅绿色菱形标示船的位置，左上角显示航程和船体状态。消耗导弹或机体受损后，可在离海面 18–79 米时掠过船附近补给。每次护航可补给一次，最多恢复两枚导弹和一格机体。

「舰队突袭」的目标是保护友方航母，并击毁敌方航母、炮艇和岸炮。敌方航母会派出舰载战机，炮艇会视距离攻击飞机或友舰，岸炮会对接近的飞机开火。把机头转向红色目标，导弹会优先锁定进入瞄准范围的水面或地面目标。机炮也能打坏舰船和岸炮。耗弹或受损后，在海面上方约 25–96 米掠过友舰附近，可补满导弹并恢复一格机体，每局一次。

友方航母采用长约 260 米、最宽约 80 米的甲板，停机位上的飞机和玩家战机使用相同的模型尺寸。进入友舰舰尾方向的进场区时，「着舰」亮起，点击或按 SELECT 可沿跑道自动对正、放起落架并着舰制动。停稳后按「起飞」、SELECT 或 A 可从甲板加速起飞。首次着舰可以用掉本局的一次补给机会。

| 操作 | 触屏 | 手柄 |
| --- | --- | --- |
| 转向和升降 | 拖动左侧摇杆 | 方向键 |

| 从标题出发突袭 | 点「舰队突袭」 | SELECT |
| 着舰和甲板起飞 | 点「着舰」或「起飞」 | SELECT |
| 机炮 | 点击或按住「机炮」 | A |
| 发射导弹 | 锁定敌机或向地表俯冲时点「导弹」 | B |
| 加速 | 按住「加速」，松开恢复能量 | X |
| 弹射 | 点「弹射」 | Y |

手柄在菜单里用 A 开始或确认，B 打开或关闭操作说明，Y 从暂停或结算返回标题。模拟器键位为方向键、Z 对应 A、X 对应 B、A 对应 X、S 对应 Y、Q 对应 L、W 对应 R、Enter 对应 START。

开启 ROLL 后，左右控制滚转速度，上下仍控制俯仰。松开左右会停止滚转并保留当前倾斜。再按 ROLL 会恢复协调转弯和自动回正。

拉升会消耗速度，俯冲会积累速度。高速转弯需要更大空间，持续大坡度转弯会增加阻力并损失高度。副翼、升降舵和方向舵会随操纵偏转。

机内视角的窗外景色会随俯仰和横滚变化。仪表显示速度（km/h）、离地高度（m）、航向（°）以及人工地平仪。操纵时，浅绿色小圈标示实际飞行方向，可以用来判断拉升或俯冲是否已经改变航迹。弹射后镜头跟随飞行员。

穿入云层时，窗外能见度随云密度下降。巡航喷口后的背景会轻微扭曲，加力时出现明亮尾焰。侧倾或急拉升时可看到逐渐消散的翼尖凝结。

## 构建和验证

使用锁定的 PXA DevKit 0.11.2，在此目录运行以下命令。

```sh
pxa run . --profile espp4-a
pxa build . --target simulator,esp32s3,esp32s31,esp32p4,wasm
c++ -std=c++20 -O2 tests/game_test.cpp world.cpp fleet.cpp -o /tmp/skybreak-game-test
/tmp/skybreak-game-test
```

`tests/journey.json` 可交给 PXA verifier 的 `--scenario`。它在 ESPP4-A 矩形截图模式下验证触控，并在 GameKit 2 模拟器上注入手柄操作。飞行使用固定时间步。场景按渲染耗时调整分辨率，HUD 使用完整 RGB565 Surface 分辨率。高度图用于透视地形和接地判定，启动时分帧随机生成三维云密度场。追尾视角沿视线累积云密度，俯视视角使用预计算的垂直密度。两种视角共用由不同方向移动的两组波纹、随浅滩水深向岸推进的碎浪和随风移动的云影。水深渐变预先计算，树木按距离和屏幕预算绘制，并带受光面与地面投影。飞行员有弹射、拉伞和接应入舱动作。

界面使用随包的 ZLabs Pixel 12px CN 位图子集。源文件摘要见 `glyphs.inc`，授权及版权声明见 `assets/ZLabs-Pixel-OFL.txt`。战机模型、地形、云和图标均为本应用制作。
