# 2048

将 Maurits van der Schee 的 [2048.c](https://github.com/mevdschee/2048.c) 移植到 PXA。固定上游提交为 [`90343eb209e84fa9687d596f5d5eecfdf7d4df51`](https://github.com/mevdschee/2048.c/tree/90343eb209e84fa9687d596f5d5eecfdf7d4df51)，版本标记 1.0.3，原作者使用 MIT 许可证。

## 操作

- 方向键或在棋盘内滑动：向对应方向移动，同值方块每步仅合并一次。
- B 或点击「B 撤销 / B UNDO」：撤销一步。撤销后保留历史最高分。
- X 或点击「X 新局 / X NEW」：新局，保留最高分。
- START 或右上角菜单：暂停、继续、重新开始和退出。

界面默认中文，可在公共暂停菜单切换中文或 English；标题数字、方块数值及控制器按键名称保持通用写法。操作提示、计分标签、结束提示和按钮随语言即时切换；语言偏好由公共运行时保存，原有 64 字节棋局存档保持兼容。中文采用共享 10×10 字形，英文采用 5×7 字形。

有效移动后按原版规则生成 2 或 4（概率分别为 90% 和 10%）；无效方向不生成方块。达到 2048 后可继续，满盘且没有相邻同值方块时结束。退出或暂停后自动保存整盘、分数、最高分、步数及一步撤销；再次启动自动续局。存档是带版本与校验和的 64 字节结构。

## 来源与适配

`upstream/2048.c`、`upstream/LICENSE`、`upstream/README.md`、西班牙语说明及原说明截图均原样保留。应用编译 `core.c`，其中直接提取原文件第 97–321 行的查找目标、单行合并、旋转、四向移动、空格统计、终局判断、随机生成及初始棋盘函数，保留原函数结构。

适配层用宏将原版 `rand()` 接到公共运行时随机源，禁用原终端版的时间播种；原来的取余选格与 90/10 分布保持不变。唯一规则源码修正是将计分中的有符号左移换成带边界判断的 `uint32_t` 左移，避免极高方块触发 C 未定义行为。棋盘继续以二次幂指数存储；大于 65536 的数字显示为 `2^指数`，保证小屏可读。

`main.cpp` 实现 288×224 RGB565 界面、触屏、手柄、撤销及存档。窗口、事件、暂停与异步存储使用[公共运行时](../common/pocket-game/README.md)，其中也提供隔离缓存的构建命令与模拟器、实机集成测试方法。不编译上游终端输入、ANSI 绘图或命令行入口。96×96 图标由适配代码自行绘制，没有第三方素材。

原项目许可证见 `upstream/LICENSE`；新增适配、测试和图标也使用 MIT，见本目录 `LICENSE`。两个 MIT 完整声明同时放在 `assets/LICENSE-2048.txt` 与 `assets/LICENSE-PXA.txt`，随签名安装包分发。

## 构建与测试

在固件工作区根目录运行：

```sh
bash local/pxa-apps/game-2048/tests/run.sh
tools/app.sh build game-2048 --source-root local/pxa-apps \
  --target esp32s31,simulator,esp32s3 --aot-only \
  --output local/artifacts/mini-games/$(date +%Y%m%d-%H%M%S)/game-2048-package
```

主机测试包含原版 13 项测试、4096 组行移动性质检查、四向移动和终局判断、随机生成、保存恢复、损坏存档拒绝、撤销及触屏输入。双语绘制测试覆盖普通、达到 2048、两种结束提示和最大分数界面，检查文字边界、文字重叠及语言切换前后的存档一致性。测试还核验原始文件哈希与核心提取一致性，并以 SDK wire codec 驱动实际共享运行时，检查音频权限、PCM 打开和 graph 提交的异步应答、兼容回退、拒绝及失败、WOULD_BLOCK 原帧重试、暂停/后台/退出/撤权清音、静置 PCM 全零与全部操作提示音。SDK 头文件默认取 deps/pxa-system/sdk/guest-c/include，可通过 PXA_SDK_HEADERS 指定；所有二进制和日志写入忽略的本地产物目录。需要 PXA SDK 2.1，最大线性内存 1 MiB、栈 64 KiB；申请可选 audio.playback 权限，不申请网络权限。

## 音效

版本 1.1.2 / release_sequence 4 取消背景音乐，保留移动、合并、首次达到 2048、撤销、新局和受阻音效。音效由共享运行时以 16 kHz 单声道 PCM 实时合成，不含外部录音或素材；没有操作或玩法事件时保持安静。暂停、进入后台和退出时立即清空音符并 flush Host 队列。

audio.playback 权限为可选；拒绝权限、设备不可用、异步音频打开失败或写入受阻均不会阻止玩法和存档。公共菜单保持四行顺序，所有原有棋局与语言偏好字节布局保持不变。主机测试验证静置无声、操作反馈和静置 tick 前后的存档一致性。
