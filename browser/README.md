# PXA 浏览器

[English](README.en.md)

面向 PXA 小屏设备的轻量阅读浏览器，使用 C++26 SDK 和流式 HTTP 接口。
应用名称为「PXA 浏览器」（英文系统显示「PXA Browser」），使用蓝底白色地球图标。
应用 ID 仍为 `pxa-browser`，更名后沿用已有书签和设置。图标源文件为 `assets/icon.svg`，打包使用同尺寸的 `assets/icon.png`。
直接输入网址或搜索关键词，轻点链接跳转，拖动页面滚动。
编辑网址时可点击「完成」左侧的清空图标更换网址；取消编辑会保留原页面与阅读位置。
底部图标依次为返回、前进、首页、刷新/停止、更多；长按可查看名称。

- HTTP/HTTPS、流式 gzip / deflate 正文与脚本、相对链接、重定向、页内锚点、返回/前进和滚动位置恢复。地址栏、表单和脚本跳转前保存阅读位置；恢复历史时优先使用保存的位置，不重新跳到网址中的锚点。同一份完整页面内的锚点历史直接恢复，避免重复请求。
- 默认使用必应的 RSS 搜索结果，可在「更多」切换 DuckDuckGo Lite。
- 简洁主页提供搜索、已验证的轻量网站导航和自己添加的网站。最多保存 8 个自定义网站，重启后保留，长按移除。
- 右侧滚动条支持拖动和点击轨道定位；滚动时显示，停止操作约 0.9 秒后自动隐藏。
- 「更多」可开启音量键翻页：音量 + 向上、音量 − 向下，长按连续翻页；默认关闭，重启后保留选择。输入文字或退到后台时恢复系统音量键。
- UTF-8 / GB2312 / GBK / GB18030 中文、标题、段落、列表、代码、PNG/JPEG/GIF 图片和基础 GET/POST 表单。支持单选按钮组；忽略禁用字段，保留复选框明确声明的空值，并可使用字段的 `aria-label`。
- RSS 2.0 与 Atom 订阅可直接作为文章列表阅读，支持文章链接、摘要、CDATA 和带属性的标题；Atom 优先使用文章的 alternate 链接。单条订阅内容最多 8 KiB，超出后跳过该条并继续读取后面的文章。
- 「更多 → 浏览历史」可选择本次运行的页面并恢复滚动位置，也可清空历史。
- 「更多 → 页内查找」可定位当前已排版正文中的中文或英文，英文忽略大小写，并高亮当前匹配所在的行片段。底栏切换上一处/下一处并循环查找，地址栏显示当前序号/总数；轻点地址栏或「修改」可更换关键词。「关闭」或系统返回退出查找，保留当前阅读位置。关键词最多 128 个 UTF-8 字节，不写入存档，不搜索表单字段、密码或图片替代文字；查找不会重新下载页面。
- 密码输入和有界的会话 Cookie，适用网站可以搜索和登录；「清除登录会话」清空内存中的 Cookie，不将会话写入存档。
- 图片与 GIF 的加载开关分别保存。GIF 只在可见时推进，菜单和输入时暂停，切到后台释放动画状态。
- 支持 HTTP 超限诊断的 Host 上，已确认正文过大时直接停止请求，避免因响应头回退再发一次 GET。响应头过大仍可回退为静态阅读，脚本保持关闭；旧 Host 保留原有安全回退，POST 不自动重放。下载与响应头预算不变。
- 图片预览、1–8 倍缩放和双向拖动；退出预览保留原网页阅读位置。
- GIF 后续帧失败时，普通预览也显示失败原因并支持轻点重试；带链接图片的预览重试不会打开链接。从后台回到 GIF 预览时会重新加载动画，保留缩放与拖动位置；不重新请求网页。
- 「更多 → 漫画阅读」按屏幕宽度阅读当前网页的图片，支持上一张/下一张、适宽/适屏与拖动；点击顶部可在 1/2/4/8 倍间切换。网页声明了 `rel=next/prev` 时，首尾按钮可切换章节并继续进入阅读视图。返回恢复原网页位置。
- 图片失败会保留原因；漫画中已确认不支持、超限、拒绝访问或关闭 GIF 的图片，翻回或重新打开阅读视图时不再自动请求。可轻点失败画面或切换画质主动重试；临时网络失败或取消的下载仍可在进入阅读时恢复。网页脚本重新排列同一图片时也保留失败原因。
- 漫画默认沿用省存解码，可手动点「清晰」重新下载并解码当前图片，最多 262144 像素；缓存同时只保留一张清晰图片。切换图片先清除旧画面引用，返回网页或退到后台会关闭清晰图片句柄，内存紧张时切回省存。清晰度仍受原图、512 KiB 编码体积及 Host 解码预算限制，GIF 动画保留原有较小预算；不支持 WebP、加密切图或完整现代浏览器脚本环境。章节标题可加载不代表正文图片都符合预算；切回省存也不会降低服务器原图的编码体积。
- 系统输入法、8 个书签、12–24 dp 字号，设置存放于应用私有目录。
- 按 DPI、字体比例、安全边距、圆角/圆屏及系统手势区计算布局；地址栏和工具栏保持居中，正文按左右各自的安全边距避让，不把单侧手势区重复预留到另一侧，充分利用屏幕中段。
- 状态提示优先使用工具栏下方的安全空白；空间不足时短暂浮在正文底部，不再固定占一行。加载期间保持显示，普通提示约 4 秒后隐藏，加载失败提示保留约 8 秒；菜单和文字编辑时隐藏。
- Canvas 直接绘制；只有页面变化或交互时重绘，不额外分配网页帧缓冲。静态页面不创建 JS VM；脚本页按需创建有界 DOM 与运行时。
- 「更多 → 网页脚本」可开启/关闭轻量 JavaScript；拖动、菜单和编辑期间暂停脚本调度，DOM 更新合并绘制。
- 「更多 → 脚本内存」可选择自动或 256 KiB～4 MiB，保存后对下次页面加载生效。自动档按需使用、最高 1 MiB，并非根据设备空闲内存自动计算；较大内存设备可手动提高上限。

网站导航提供《小辣椒与萝卜头》中文首章、xkcd 英文漫画，以及古诗文、IT之家资讯订阅、博客园技术文章订阅、维基文库经典原文及 NPR 英文文字新闻。原有 TXT 图书、万本 TXT 小说网、努努书坊、手机新浪网、手机漫画网目录、hao123、2345 和微信读书实验入口继续保留。外部内容和可用性会变化；手机漫画网的重脚本章节仍未完整适配。
浏览器保留网站原始 HTML、脚本和链接，不再自动替换微信读书登录、书架或漫画章节。当前漫画网站所需的 jQuery/DOM 仍未完整支持。微信读书原始登录脚本已通过模拟器协议回归，但真实账号登录、书架与阅读仍未验收，不能视为已能阅读。通用大图解码与原始页面验证见 [本轮报告](docs/original-pages-images-20261016.zh-CN.md)。

在主页点「+ 添加网站」输入地址，也可在网页的「更多」菜单中收藏当前页面。
「更多 → 退出浏览器」会先完成网站与设置的保存，再正常关闭应用。

这是一款阅读浏览器。Guest 内集成 QuickJS，支持经典脚本、基本 DOM、事件、定时器及同源异步 XHR/fetch；不支持完整 CSS、模块脚本、Canvas/WebGL、视频、验证码和现代框架的完整浏览器环境。

HTML 的 title/textarea 按文本容器解析，保留内部标签文字并解码实体；textarea 忽略初始换行，基础编辑与提交见下文表单支持。xmp 与 plaintext 保留实体字面量，plaintext 直到输入结束；iframe/noembed/noframes 的后备文字不生成脚本、图片、链接或表单。iframe 不自动加载，可手动打开合法 src（srcdoc 仍不支持）。这些模式同样用于脚本捕获、DOM 构建和 innerHTML 上下文；DOM 构建在实体解码前规范化源换行。重绘将可见原始文字块映射为转义的 pre，并保护动态 style 的结束标签，避免把文字重新解析为资源。标题仍限 256 字节，正文、DOM、脚本及图片等原有上限不变。

动态 `innerHTML` 的标记片段先在独立节点中完成有界解析，成功后再替换子节点。可捕获的片段字节、节点、属性或样式超限会保留旧节点身份、父子关系、事件与单选状态，并回滚失败片段的样式额度；随后仍可尝试有效更新。解析属性直接初始化新节点，避免无效的重绘通知；重复 HTML 属性保留首次值。既有 8 KiB/96 token 片段上限、属性和样式预算不变，实际内存耗尽和脚本超时仍停止执行；这不提供完整 HTML 树构建或对任意 DOM 操作的事务保证。

支持有界 `classList`：`add/remove/toggle/replace/contains`、`value`、实时索引/长度与迭代（含 `forEach`）。同一元素返回同一列表；`className`、属性写入和删除同步更新列表与 CSS 匹配。类名按 ASCII 空白拆分、去重并保留顺序；无效参数和属性额度失败不会提交部分变更。缓存仅在使用时创建，类名未变时复用；无变化操作不请求重绘。沿用每节点 24 个属性、属性值 4096 字符的原有限制。提供 `DOMException` 的名称、消息、旧式错误码及常量；无效/不支持的选择器抛出名称为 `SyntaxError` 的 DOMException，资源超限仍为 RangeError。这些接口不代表完整浏览器 DOM 支持。

`element.dataset` 提供按需创建的同一 `DOMStringMap` 视图，支持 `data-*` 与驼峰键名转换、字符串读写、删除、枚举及与属性 API 的即时同步，可用于 `img.src = img.dataset.src` 这类懒加载脚本。沿用 ASCII 属性名子集（字母、数字、下划线、冒号、点和连字符）、64 字符属性名、每节点 24 个属性及 4096 字符值限制；未变化的写入不请求重绘。不支持访问器或显式不可配置的字符串属性描述符，拒绝时保留原值；符号属性作为普通对象属性处理。

事件处理器和监听器直接以目标作为 `this` 调用，保持监听器顺序，支持同一目标上的嵌套分发和异常后的继续使用，不依赖函数对象的可覆盖 `call` 成员。

节点通过原型读取只读 `tagName`，样式状态在首次使用时创建，避免每个节点重复保存标签名和空样式字段。

快照仅在当前批次复用不超过 64 字符的原始标签名，控件绘制为链接时不会覆盖复用值。交互命中表随快照维护计数，避免逐节点枚举整张表；常见短闭合标签在扫描栈前只转换一次名称。沿用原有遍历、交互与片段额度。

`innerHTML` / `outerHTML` 读取直接推进有界快照；转义逐个消费匹配结果，避免回调层和完整匹配列表。保留 `&`、尖括号、双引号及空字符的原有转义规则。较长标签名仍按原路径转换，不增加标签长度限制。

脚本 DOM 解析对属性名均为不超过 64 字节 ASCII 的节点，在原生侧统一属性名大小写，并复用运行时的属性名字符串；无属性节点使用空标记传递，避免为每个节点分配空数组。非 ASCII 或较长名称保留原有脚本处理路径，属性值、首次重复值和额度检查保持不变。原生解析桥与预编译运行库须一起构建、校验；不能混用不同版本的内部参数约定。




脚本的 `querySelector` / `querySelectorAll`、`matches` / `closest` 支持标签、通配符、ID、类及其组合，属性存在/比较（`=`、`~=`、`|=`、`^=`、`$=`、`*=` 与 ASCII `i` / `s` 标志）、后代/子元素关系、逗号列表与 `:scope`。查询按 DOM 树顺序返回，元素查询只返回后代；祖先匹配可越过查询根，`:scope` 可显式限定根。集合是带 `item()` 的静态数组，包含 `getElementsByTagName` 与新增的 `getElementsByClassName`，不实现动态 NodeList/HTMLCollection。每个选择器最多 512 个 UTF-16 代码单元、8 组、32 步、64 项条件，每次查询最多访问 512 个节点并执行 8192 次元素与选择器步骤的匹配尝试；仅缓存最近一条解析结果，不缓存匹配节点。属性值默认按原文比较；input/button 的 type、form 的 method/enctype 及 dir 使用默认 ASCII 大小写折叠，显式 i/s 标志优先。暂不支持 CSS 转义、兄弟关系和其他伪类/伪元素，遇到不支持或非法语法抛出 `SyntaxError`，超预算抛出 `RangeError`。这些是脚本查询能力，不扩展下面的样式表绘制子集。

0.1.9 增加有界文字 CSS：正文之前的页内 `<style>` 与行内样式支持简单标签、类、ID 及其组合选择器，按优先级和 `!important` 合并颜色、字号、`display`、`white-space` 与左右/居中对齐。样式继承和嵌套恢复也用于脚本重绘。CSS 总前缀最多 8 KiB、规则最多 64 条、嵌套状态最多 32 层；后续规则按预算忽略，保留可读内容。字号随阅读字号缩放并限制在 0.5–2 倍，`pre` 按可换行方式阅读，浅色文字自动压暗以适应固定阅读背景。暂不请求外部样式表，不支持复杂选择器、媒体查询、完整盒模型或已输出内容的追溯重排。

0.1.10 为重复样式保留最多 16 项匹配缓存，单个键最多 256 字节，较长属性直接解析。缓存只保留声明结果，字号百分比与颜色继承仍逐元素解析；后续样式块会使缓存失效。无注释的 CSS 直接从有界输入解析，纯文本和无样式页面不分配匹配缓存。

脚本可通过 `element.style` 的属性、`cssText`、`setProperty`、`getPropertyValue`、`getPropertyPriority` 和 `removeProperty` 修改行内样式，也可读取 `length` / `item`。替换或移除 `style` 属性会清除旧声明，已有的 `style` 引用保持有效；单独修改样式会触发页面更新，重复写入相同值保持空闲。声明按需分配，每个元素最多 32 项、序列化后最多 4096 个 UTF-16 代码单元，值中的括号最多嵌套 16 层；超限保留原值。解析保留引号和括号内的分号并识别 `!important`，序列化结果复用到后续重绘。该接口仍为有界子集，绘制只应用上述文字 CSS，不实现完整 CSSOM、简写展开或 CSS 变量求值。

已经完成绘制的脚本页只在内容、样式或点击目标变化后启动 DOM 快照；空回调、相同文字/样式赋值和重复监听注册不单独生成快照。动态 `onclick`、`addEventListener` / `removeEventListener` 会同步点击区域，XHR 回调中新绑定的处理器也能生效；移除最后一个处理器会恢复普通内容。`onclick=null` 或 `undefined` 可停用行内处理器，重新设置同一份 `onclick` 属性可重新启用。每类事件仍最多 16 个监听器，重复注册已有函数不占用额外名额；不提供完整 DOM 事件模型。

基础表单按 DOM 树顺序收集 input、textarea 与被激活的提交按钮，保留同名字段顺序、按钮值、复选框/单选状态及 UTF-8 表单编码；禁用控件不触发点击，普通按钮和 reset 按钮不再误提交。静态 `<button>` 将可见子文字（含实体、内嵌格式和图片替代文字）合并为不超过 128 字节的 UTF-8 标题，隐藏内容不参与；标题和提交的 `value` 分别保留，省略 `value` 时提交空值。原生表单控件各占一个完整点击区域，长标题在单行内截短。基础 textarea 支持初始文字、中文和实体、只读/禁用状态，以及按需打开的多行原生编辑器；输入法回车插入换行，地址栏「完成」保存修改。每个值仍限 512 个 UTF-8 字节。脚本的 value / defaultValue 分别保留当前值与默认子文字，编辑完成后派发 input / change；内部值按 LF 读取，表单名称和值在编码时将换行统一为 CRLF。隐藏控件仍参与成功字段收集，禁用控件不参与。GET 替换 action 的旧查询参数并保留锚点，POST 保留 action 的查询与锚点。脚本可设置 action / method / enctype，使用 `form.submit()` 直接提交，或用有界的 `form.requestSubmit([button])` 触发可取消的 submit 事件并读取 `event.submitter`；后者不实现完整约束验证。静态表单仍限 24 个字段和 2 KiB 编码正文，脚本表单仍受原有 DOM 与 8 KiB 正文限制，GET URL 上限仍为 1024 字节。重置默认值、外部 form 关联、提交按钮覆盖属性、文件上传、select、textarea 的 hard 换行与选择区 API，以及 multipart/text/plain POST 尚未实现；reset 可由网页脚本自行处理。

采用混合组件：界面、滚动、网络和图片走 `main.aot`；QuickJS 与 DOM 放在按需启动的 `script.wasm` 中解释执行，通过有界 IPC 批量交换更新。纯静态页面不加载脚本组件。只有禁用 input/button/textarea 点击处理器的页面仍按静态页处理；加载、提交事件、启用目标的点击处理器和实际脚本继续触发自动检测。关闭脚本页会释放 VM，但已加载的模块和增长的线性内存不会因此自动缩小。解释执行会降低脚本速度，不能将包体积减少视为脚本提速。

解析器按传输块跳过脚本、样式和注释，校验 UTF-8 后批量追加普通正文；实体、跨块字符和容量边界保留逐字符处理。它保留可读内容及有限的链接/表单信息。同一页的 DOM 更新复用容量；新导航和回到主页释放旧文字、链接、表单及排版缓冲，
不为所有应用添加缓存。排版只在内容、字号或屏幕变化时重新计算；绘制时不创建临时容器。
普通英文单词优先整体换行，长网址和代码仍可逐字换行；文字宽度采用保守估算，
还没有完整字体塑形和 CSS 排版。

「更多」提供轻量/手机兼容页面模式，下一次加载生效。默认使用真实的轻量浏览器 UA；
手机兼容模式仅尝试触发网站的移动版本。两者都发送 `Save-Data: on`，
网站可以忽略这些偏好；它们不能替代 JavaScript 或 CSS 支持。
0.1.11 支持常见的 `data-src`、`data-original`、`data-lazy-src`、`data-url` 懒加载地址和 `data-srcset` / `data-lazy-srcset`；无效或已知不可解码的备用地址不会阻止后续回退。`srcset` 校验候选描述，并按原始顺序选择首个可用地址，兼容 URL 中的逗号；单组最多 4 KiB、32 个候选，不保留候选列表。`picture` 可跳过明确声明的 WebP/AVIF 源，选择 PNG/JPEG/GIF 的备用源。仅处理无 media 或简单 all/screen，不实现尺寸媒体查询、sizes 计算和 DPR 自动切换；没有可用候选时保留 img 的原始回退。脚本修改 srcset、sizes、media、loading 属性可触发页面同步。显式 `lazy`/`lazyload` 图片优先使用懒加载地址，其余图片优先使用有效 srcset，再回退到 src。漫画视图忽略小图标和已知不支持的图片格式；页面含 `comicpage` 图片标记时，仅连读同一图片目录的内容，避免混入站点的视频缩略图。原网页保持原来的内容与导航。
PNG 保留透明度，普通 JPEG 使用原生缩小解码。图片保持原始宽高比，按屏幕、字号和
正文宽度排版；离屏图片可被淘汰，返回时重新下载。无法加载的图片保留替代文字，轻点可重试。
图片解码完成后保留 HTML 指定的宽度上限，只有高度时按原图比例推算宽度；小图标按显示宽度限制解码输出，避免恢复成原图尺寸挤占正文。没有指定尺寸的图片仍使用原图比例。
直接打开 PNG/JPEG/GIF 地址也能显示，不会把二进制内容当作 HTML。
GIF 下载完成后开始动画，最低帧延迟按 30 ms 调度，不补发错过的帧；8192 像素上限会降低
大 GIF 的细节，透明孔洞和处置语义保留。
支持脚本更新 `img.src`，以及严格 Base64 PNG data URL（单个 4096 字节、每文档合计 8192 字节），通过临时私有文件复用 Host 原生解码。其他 data URL、渐进式 JPEG、WebP、SVG 和 CSS 背景图暂不支持。
ESP32-S3 的 ROM 后端暂不支持灰度 JPEG；桌面后端支持，具体限制见报告。

## 压缩页面与兼容范围

0.1.5 支持 gzip（含校验和及最多 16 个成员）和标准 zlib 包装的 HTTP deflate，不整页解压到第二份缓存。正文读取每 4 次调用或约 16 KiB 让出执行机会，方便滚动和取消。解码扫描预算允许读取较大的 CSS/脚本前缀，但不会扩大可读文字、DOM、JS 堆或图片预算。达到容量后仍保留可读静态内容；截断、校验失败和未知压缩格式报告错误，不启动未完成页面的脚本。

还可直接阅读 UTF-8 的 `application/json`、`text/json` 和 `text/markdown` 响应，以纯文本显示，不解释为 HTML。压缩图片、Brotli、原始裸 DEFLATE、完整 CSS/现代前端框架仍不在本版支持范围内。

解压使用应用私有的 zlib 1.4 inflate 子集（Zlib 许可证），来源和逐文件摘要在 `vendor/zlib/SOURCE.json`，许可随 `assets/zlib-license.txt` 打包；不向系统引入新依赖。Guest 线性内存增长后仍不能自动缩回，释放页面缓冲使后续页面能够复用空闲区，不等于立即将同等字节还给 Host。
