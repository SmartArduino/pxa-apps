# PXA 浏览器

[English](README.en.md)

面向 PXA 小屏设备的轻量阅读浏览器，使用 C++26 SDK 和流式 HTTP 接口。
应用名称为「PXA 浏览器」（英文系统显示「PXA Browser」），使用蓝底白色地球图标。
应用 ID 仍为 `pxa-browser`，更名后沿用已有书签和设置。图标源文件为 `assets/icon.svg`，打包使用同尺寸的 `assets/icon.png`。
直接输入网址或搜索关键词，轻点链接跳转，拖动页面滚动。
底部图标依次为返回、前进、首页、刷新/停止、更多；长按可查看名称。

- HTTP/HTTPS、相对链接、重定向、页内锚点、返回/前进和滚动位置恢复。
- 默认使用必应的 RSS 搜索结果，可在「更多」切换 DuckDuckGo Lite。
- 简洁主页提供搜索、已验证的轻量网站导航和自己添加的网站。最多保存 8 个自定义网站，重启后保留，长按移除。
- 右侧滚动条支持拖动和点击轨道定位；滚动时显示，停止操作约 0.9 秒后自动隐藏。
- 「更多」可开启音量键翻页：音量 + 向上、音量 − 向下，长按连续翻页；默认关闭，重启后保留选择。输入文字或退到后台时恢复系统音量键。
- UTF-8 / GB2312 / GBK / GB18030 中文、标题、段落、列表、代码、PNG/JPEG/GIF 图片和基础 GET/POST 表单。
- 「更多 → 浏览历史」可选择本次运行的页面并恢复滚动位置，也可清空历史。
- 密码输入和有界的会话 Cookie，适用网站可以搜索和登录；「清除登录会话」清空内存中的 Cookie，不将会话写入存档。
- 图片与 GIF 的加载开关分别保存。GIF 只在可见时推进，菜单和输入时暂停，切到后台释放动画状态。
- 图片预览、1–8 倍缩放和双向拖动；退出预览保留原网页阅读位置。
- 系统输入法、8 个书签、12–24 dp 字号，设置存放于应用私有目录。
- 按 DPI、字体比例、安全边距、圆角/圆屏及系统手势区计算布局；地址栏、正文和工具栏分别避让圆角，每一行保持左右居中，充分利用屏幕中段。
- 状态提示优先使用工具栏下方的安全空白；空间不足时短暂浮在正文底部，不再固定占一行。加载期间保持显示，普通提示约 4 秒后隐藏，加载失败提示保留约 8 秒；菜单和文字编辑时隐藏。
- Canvas 直接绘制；只有页面变化或交互时重绘，不额外分配网页帧缓冲。静态页面不创建 JS VM；脚本页按需创建有界 DOM 与运行时。
- 「更多 → 网页脚本」可开启/关闭轻量 JavaScript；拖动、菜单和编辑期间暂停脚本调度，DOM 更新合并绘制。
- 「更多 → 脚本内存」可选择自动或 256 KiB～4 MiB，保存后对下次页面加载生效。自动档按需使用、最高 1 MiB，并非根据设备空闲内存自动计算；较大内存设备可手动提高上限。

网站导航包括 TXT 图书、万本 TXT 小说网、努努书坊、手机新浪网、手机漫画网目录、hao123、2345 和微信读书扫码入口。
浏览器保留网站原始 HTML、脚本和链接，不再自动替换微信读书登录、书架或漫画章节。当前漫画网站所需的 jQuery/DOM，以及微信读书原始脚本的栈需求仍未完整支持，不能视为已能阅读。通用大图解码与原始页面验证见 [本轮报告](docs/original-pages-images-20261016.zh-CN.md)。

在主页点「+ 添加网站」输入地址，也可在网页的「更多」菜单中收藏当前页面。
「更多 → 退出浏览器」会先完成网站与设置的保存，再正常关闭应用。

这是一款阅读浏览器。Guest 内集成 QuickJS，支持经典脚本、基本 DOM、事件、定时器及同源异步 XHR/fetch；不支持完整 CSS、模块脚本、Canvas/WebGL、视频、验证码和现代框架的完整浏览器环境。

采用混合组件：界面、滚动、网络和图片走 `main.aot`；QuickJS 与 DOM 放在按需启动的 `script.wasm` 中解释执行，通过有界 IPC 批量交换更新。纯静态页面不加载脚本组件。关闭脚本页会释放 VM，但已加载的模块和增长的线性内存不会因此自动缩小。解释执行会降低脚本速度，不能将包体积减少视为脚本提速。
已检查更小的引擎候选；JerryScript 的 Guest 异常适配和 MicroQuickJS 的兼容性取舍见 [引擎验证与混合组件方案](docs/engine-selection-20261016.zh-CN.md)。
组件设计、实测取舍和复现命令见 [AOT + Wasm 混合组件报告](docs/aot-wasm-20261016.zh-CN.md)。
pai-touch 最终静态/脚本页拖动约 29.0 / 30.3 FPS；静态 PSRAM 明显减少，脚本页稳定 PSRAM 比单 AOT 增加约 0.50 MiB，解释执行也更慢。mosaico 日志中的脚本栈溢出已按同样的 16 KiB 解释器栈复现并修复，详见 [栈与事件验证](docs/mosaico-script-stack-20261016.zh-CN.md)；mosaico 实机复测仍待进行。
运行时、DOM 和网络都有容量限制；超过预算会保留静态内容并提示。Web Storage 分来源隔离，目前仅在浏览器本次运行内保留，不写磁盘。详见 [JS 接入与验证](docs/javascript-20261015.zh-CN.md)。
基础 WML 页面可阅读和使用简单 GET 跳转，不支持 WMLScript 或计时器。
旧中文编码按 HTTP 声明或页面前 1024 字节中的 meta 转换；编码表只在读取旧编码页时加载，完成后释放。
暂不支持旧编码页面的表单提交、Big5 等其他编码、服务器强制压缩和不支持的文件类型，会显示提示。
DuckDuckGo 有时会返回图片验证，此时可切回必应；程序不会绕过验证码。

书签不接受含查询参数的网址，避免持久化常见的搜索和表单内容。历史记录仅保留在本次运行中，
POST 正文不会被历史重放；没有完整的隐私浏览或网站认证功能。HTTPS 验证由 Host 执行。

未带链接的图片加载完成后，轻点打开预览；带链接的图片轻点跳转、长按预览。
预览底部依次为返回网页、缩小、适合屏幕、放大，长按图标可查看名称。
缩放倍数相对于「适合屏幕」，复用现有解码像素，不重新下载或增加图片缓存。
放大可以方便查看局部，但不会恢复已被缩小的原图细节。

## 构建与运行

需要包含 **Net 0.4 / Core 2.0、UI dynamic-text / sized-text / text-input-control** 的最新 SDK
与 FS 原子替换接口和 UI password-input 的最新 Host，以及 **Assets 2.3 / image-decode / image-frames、Window 0.3**。
旧版 DevKit 和设备固件需要先更新；仅更新应用包不足以提供流式网络和原生图片解码。

在 pxa-workspace 根目录：

```sh
tools/dev.sh sim browser --source-root local/pxa-apps
tools/app.sh build browser --target esp32s3
```

或者使用更新后的独立 DevKit：

```sh
pxa run pxa-apps/browser
```

首次联网时授权网络权限。地址栏支持 `https://example.com/`、`example.com`、
`ESP32 开发`；以 `?` 开头可强制作为搜索词。含端口的本地 HTTP 服务请明确写出 `http://`。

| 原图限制 | 有界 MCU/扫描线 JPEG 单边最多 4096；PNG、GIF、LVGL 整图后端仍最多 1048576 像素。旧 Host 仍有旧的 JPEG 限制 |

解析器逐块消费网络正文，保留可读内容及有限的链接/表单信息。容器按需分配并复用容量，
不为所有应用添加缓存。排版只在内容、字号或屏幕变化时重新计算；绘制时不创建临时容器。
普通英文单词优先整体换行，长网址和代码仍可逐字换行；文字宽度采用保守估算，
还没有完整字体塑形和 CSS 排版。

「更多」提供轻量/手机兼容页面模式，下一次加载生效。默认使用真实的轻量浏览器 UA；
手机兼容模式仅尝试触发网站的移动版本。两者都发送 `Save-Data: on`，
网站可以忽略这些偏好；它们不能替代 JavaScript 或 CSS 支持。
PNG 保留透明度，普通 JPEG 使用原生缩小解码。图片保持原始宽高比，按屏幕、字号和
正文宽度排版；离屏图片可被淘汰，返回时重新下载。无法加载的图片保留替代文字，轻点可重试。
直接打开 PNG/JPEG/GIF 地址也能显示，不会把二进制内容当作 HTML。
GIF 下载完成后开始动画，最低帧延迟按 30 ms 调度，不补发错过的帧；8192 像素上限会降低
大 GIF 的细节，透明孔洞和处置语义保留。
支持脚本更新 `img.src`，以及严格 Base64 PNG data URL（单个 4096 字节、每文档合计 8192 字节），通过临时私有文件复用 Host 原生解码。其他 data URL、渐进式 JPEG、WebP、SVG 和 CSS 背景图暂不支持。
ESP32-S3 的 ROM 后端暂不支持灰度 JPEG；桌面后端支持，具体限制见报告。
画质、内存和验证见 [图片验证报告](docs/images-20261015.zh-CN.md)。

## 验证

```sh
bash local/pxa-apps/browser/tests/test.sh
bash local/pxa-apps/browser/tests/test_script_transport.sh
python3 local/pxa-apps/browser/tests/fixture.py --bind 0.0.0.0
```

原生测试启用 ASan/UBSan，覆盖任意分块的 HTML/RSS、UTF-8、URL、表单、容量边界和随机输入，
以及不对称圆角、圆屏留边、DPI 与完全占用的安全区。独立仓库测试可通过
`PXA_CPP_SDK_INCLUDE` 指定 DevKit 的 C++ 头文件目录。
`tests/simulator_smoke.py` 对真实 Wasm/AOT 包操作链接、前进后退、系统输入法、POST、
重定向、停止、容量边界、404、纯文本与压缩提示；`tests/display_matrix.py` 保存不同屏幕的截图。
测试包设置 `PXA_BROWSER_TRACE=1`，测试从日志读取实际布局，避免按钮坐标随屏幕适配失效。
均可用 `--help` 查看参数。`tests/ui_smoke.py` 额外验证手动添加网站、去重、长按移除、
重启恢复、滚动条拖动/隐藏、音量键开关/长按/释放/输入时暂停及菜单退出；模拟器的 `TEXT` 诊断命令通过正常的 LVGL
文本变更事件编辑已聚焦的输入框。单独运行模拟器时须传入已受信任的系统输入法包。
`tests/image_smoke.py` 使用按测试路由构建的包，覆盖透明 PNG、JPEG、长图、取消、异常格式、
缓存淘汰及高 DPI/圆屏；传入 `--help` 查看路由和参数。
`tests/gif_smoke.py` 验证实际动画画面、透明处置、可见性暂停、伪装格式过滤、静态 GIF、截断和取消；
`--shell` 使用桌面系统模拟器额外覆盖 Home 手势与前后台恢复。
安装以测试服务器 `/gif` 启动的 TRACE 测试包后，`tests/device_gif_smoke.py` 可在 pai-touch
核对实际帧颜色、透明孔洞、LCD 完成速率、启动与稳定播放的独立内存窗口、前后台释放及重复启动。
使用 `--fixture-url` 指定设备可访问的服务器；`--restore-package` 可在结束后恢复正式主页包。
脚本不刷写固件或修改设备设置，并在正常停止后逐字节核对原有偏好。依赖 pxadb、Pillow 和 tesseract。
`tests/device_gif_benchmark.py` 用关闭 TRACE 的同场景包和前者测得的布局，分别记录启动、不透明和
透明动画的真实堆峰值，再做 LCD 完成计数及三轮启动/停止；截图不进入内存窗口。
测试期间保持屏幕解锁，图片/GIF 开启；其 `--package` 和 `--restore-package` 分别指向测试包和正式主页包。
`tests/session_smoke.py` 使用测试账号验证密码遮罩、POST、重复 Cookie、登录后页面和清除会话；
不要向测试脚本或截图传入真实凭据。
网站逐项检查及真实登录/搜索验证见 [历史、会话与网站报告](docs/history-sessions-sites-20261015.zh-CN.md)，
动画集成及真机验证见 [GIF 报告](docs/gif-native-20261015.zh-CN.md)。

基准页面包通过环境变量 `PXA_BROWSER_START_URL=http://电脑局域网地址:31878/` 构建，
生产包不设置此变量。诊断可临时启用 `PXA_BROWSER_TRACE=1`，不要用带逐触摸日志的包测量延迟。
应用 UI/SDK 构建保持 O3；QuickJS 单独使用 Oz，采用 full LTO 以降低设备 AOT 装载与初始线性内存开销。冷启动和稳定内存均通过真机核对。
`PXA_BROWSER_PROFILE=1` 只在加载结束和手势结束汇总排版、编码和提交耗时；正式包不启用。
滚动使用 Canvas 局部重绘，保留完整绘图命令以支持窗口重新显示，不添加网页位图缓存。
模拟器截图检查依赖 Python Pillow；包括局部/完整重绘逐像素一致性和低 DPI 图标可见性。
