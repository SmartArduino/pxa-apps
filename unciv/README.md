# Unciv（PXA）

从零编写的 C++ PXA 单人回合制 4X 游戏，参考 Unciv 的探索、城市、科研与战斗玩法。
应用逻辑、AI、界面和存档均为新实现；没有移植或翻译 Kotlin/Java 代码。
美术及音效来自固定版本的 Unciv，署名与许可见 [assets/NOTICE.md](assets/NOTICE.md)。

## 玩法与范围

- 可选 20×14、28×18、36×20 三档平顶六角地图，支持缩放、小地图定位、拖动、视野及战争迷雾。
- 玩家控制中华，与罗马、印度两名 AI 对局；AI 会探索、评估城址、改良、研究、生产和作战。
  军事单位会移动后攻击，弓箭手优先选择远离近战威胁的射击位置；受伤时撤退休整，城防受威胁时回援、优先研究弓术并转产军队，保留原项目进度。
  和平时限制军队规模，避免无限征兵；宣战前需要已发现对方城市，并评估己方与可见敌军战力。
- 6 类单位：开拓者、勇士、侦察兵、工人、弓箭手、剑士。战斗获得经验，可选择地形战力、医疗或即时恢复晋升。
- 勇士研究铁器后可在己方领土支付52金币升级为剑士，需完整行动力；保留生命、经验和晋升，升级用完本回合行动力。
- 兵营训练的军事单位初始经验15；待命和休整至满血支持自动恢复行动。完整驻防每回合积累20%防御，最多40%。
- 高耗地形允许用最后一点行动力进入；从同一敌军或城市的相邻格移动到另一个相邻格，会因控制区耗尽剩余行动力。
- 军事单位可掠夺敌方或中立改良，获得金币并回复生命；改良受损后失去产出加成，工人可修复。
- 城市可选择均衡、粮食、生产、金币重心，自动分配独占工作地块；积累粮食增长人口，缺粮会降低人口；可生产单位与纪念碑、粮仓、图书馆、兵营，
  或使用金币完成当前生产。各项目独立保留进度，支持当前项目加9项待办的生产队列、排序、移除和单位连续生产。
- 12 项有前置关系的科技，3 类文化政策，宣战及十回合和平条约；和平时不能进入他国领土，议和后迁出越界单位。
- 攻击前预览双方剩余生命，伤势影响战力；近战反击、远程射击与视线遮挡、驻防恢复、城市自动防御；单位与城市远程攻击均考虑视线遮挡，城市优先打击军事单位，远程单位不能占城。
- 征服全部初始首都、研究全部科技，或第 150 回合后按得分决胜。
- 触屏和手柄、中英文切换、独立开关的原版音效和背景音乐、异步自动存档和覆盖确认。

这是独立的精简规则版本，尚未覆盖原版 Unciv 的全部内容：没有联网、模组、宗教、贸易、
完整时代和文明特性、海空军或原版存档兼容。城市工作地块按重心自动选择，
外交采用固定期限和平条约，规则及平衡与原版不同。

## 操作

在「开始新游戏」中选择地图大小，再开始。选中开拓者，点击底部「建城」。
再次点城市或点底部「城市」进入管理；「单位 / 建筑」切换生产分类。
每人口每回合消耗2粮食；人口增长门槛为 `15 + 8×(人口−1) + floor((人口−1)^1.5)`。
均衡重心会尽量避免饥荒，手动锁定地块仍优先保留。
开拓者需要城市人口至少2；训练时暂停正向粮食积累，粮食盈余转为产能，负盈余仍会导致饥荒。
选择生产项目后先查看效果、前置科技、已有进度和预计回合，再点击「开始生产」确认。
切换项目会保留原项目进度，切回来可继续。点击「加入生产队列」，当前项目完成后自动接续；
城市管理右上「队列」可调整顺序、移除项目、翻页。单位允许多次排队，建筑不能重复排队。
队列为空时，完成项目后停止生产；「下一回合」会先定位到需要选择生产的城市。
队列为空时可手动开启当前单位的连续生产；加入后续项目或更换当前项目会关闭连续生产。
正常生产的剩余产能结转到下一项目，最多结转该项目成本或当前回合产能两者中的较大值；金币购买只完成当前项目，不额外产生结转产能。
返回详情不会改变当前生产或产能。
选单位后，白色半透明圆圈表示本回合可到达的地块，金色边框标记选中单位。
按住可达格可预览实际路线与行动点消耗，松手移动；开始拖动或取消触摸会取消路线预览。
不可达格不会取消单位选择。宣战后，红色圆圈与准星表示可攻击目标。
点击目标先查看战斗预览，再确认攻击；返回不会消耗行动力。
选中单位后点击「详情」，或在概览的单位页选择单位后按 X / 点「详情」，可驻防、待命、休整、晋升和升级。
近战攻击/受击获得5/4经验，远程攻击/受击获得2/2经验，攻击城市获得3经验；击打平民不获得经验。
经验阈值10/30/60/100对应最多4次晋升，经验封顶127。开阔/崎岖地形战力每级+15%、各最多3级；
弓箭手的地形加成只用于攻击。医疗使自身休整额外恢复8生命；即时恢复50生命，每单位限一次并耗尽行动力。
先选晋升卡，再确认才消耗机会。升级也需确认，返回不扣金币。
待命只跳过本回合，下一回合恢复手动操作；休整期间「下一单位」会跳过该单位，满血后自动唤醒。
取消休整或唤醒不补回本回合已消耗的行动力。本回合移动、攻击、升级或掠夺后，不会立即获得休整回复；行动状态写入存档。
休整基础回复为己方城市25、己方领土20、其他陆地10，另加医疗晋升的8点。单位详情显示所在地的回复量。
完整驻防每回合增加20%防御，最多两回合40%；移动、攻击、升级、掠夺、唤醒或取消休整会清除积累。攻下最后一座城市后，若该文明没有开拓者，清除其残留单位。
城市管理右上「发展」可切换重心，查看粮食收支和增长回合。
「管理工作地块」显示工作人口，绿色表示正在工作，金色表示已锁定。选地块后「锁定地块」
优先保留该格，切换重心仍保留锁定；「自动分配」清除锁定。人口减少或领土变化后自动调整。
地图以文明颜色显示城市周围领土边界。金币购买先显示花费和余额，确认后扣款。
单位详情中的「掠夺改良」先显示确认页，返回不消耗行动力；确认后消耗1行动力，获得25金币，回复最多25生命。
不能掠夺己方或和平文明的改良；受损地块显示红叉，工人用2回合修复后恢复农田或矿山的加成。
AI 会掠夺经过的敌方改良，并优先修复己方受损地块；撤退时会考虑安全地块的回复能力。
工人可以改良己方城市两格内的土地；
农田需3回合，丘陵矿山和森林清理需4回合；矿山需先研究采矿。
工人开始作业会用完当前行动力，之后自动推进；移动或「停止作业」取消工程。
森林上的农田完成后会清除森林。科技树先选择科技，再点击底部研究按钮。结束回合获得产出。
地图上方「! / 数字」打开本次游戏的回合通知，可定位研究、生产、人口、改良和战败事件；通知历史不写入存档。
地图支持双指捏合缩放，以双指中点为基准，并支持双指平移；右上角「− / +」按钮仍可使用。
捏合会取消移动预览，两指全部松开后恢复单指操作；工具栏和小地图上的触点不参与捏合。
点击小地图定位；再次点击已选单位可取消选择。
主页提供「继续游戏」（有存档时）、「开始新游戏」和「游戏说明」。
右上「概览」提供城市、单位和外交三个分页。城市列表可直接打开城市管理；
单位列表显示生命、行动力和驻防状态，点击可定位并选中单位。
列表支持翻页；「下一单位」显示待行动数量并跳过驻防和正在作业的单位，可从总览选中后唤醒。
外交页管理战争、和平和政策；菜单按钮打开暂停、语言、新游戏及保存退出菜单。
开始新游戏需要再次确认，普通返回及暂停不会覆盖存档。

| 手柄键 | 操作 |
| --- | --- |
| 方向键 / A | 移动地图光标 / 选择地块；菜单中移动焦点 / 确认 |
| B | 返回，或取消地图单位选择 |
| X | 地图操作；概览单位页打开详情；城市中打开队列；生产详情加入队列；队列中移除所选项 |
| Y | 地图中结束回合；城市中查看购买；地块管理中恢复自动分配 |
| L / R | 地图科技 / 概览；城市和总览切换分类；队列中上移 / 下移；新游戏切换地图大小 |
| SELECT / START | 地图下一单位；城市中打开发展，发展中打开地块管理，总览中打开通知 / 暂停菜单 |

## 构建与运行

使用当前工作区 PXA 0.10.0 工具链，`pxa.lock` 固定 SDK 与编译器。
应用仅依赖相邻 `common/` 中现有 CC0 PXA 窗口、输入、字体及存储适配。
需支持 Surface、GameRender 1.0、UI 0.10、Assets 2.0、Window、Clock、Storage 和可选 Audio 0.10 服务。
GameRender RGB565 批处理通过离屏实际操作探测支持情况；不支持时使用 Guest 软件绘制。
图块按地形和前景两层绘制到已获取的 Surface 缓冲，GameRender 回退按层批量提交。
原版森林、丘陵、山脉资源是带透明区域的地貌图层；生成素材时将草地底图合成在其下方。
绘制时保持原始纵横比并以地块底边对齐，按地块纵深排序，避免透明孔洞和山峰被压扁。
常用精灵按当前 Surface 像素尺寸缓存，并记录每行不透明区间，以逐行拷贝完成绘制。
精灵缓存固定上限 256 KiB，超大精灵或缓存不可用时回退 GameRender / 软件绘制。
移动提示使用原版 FantasyHex 圆形遮罩及攻击准星，按地图视口裁切；前景单位保持清晰。
可达格、寻路前驱和攻击目标按游戏状态及选中单位缓存，平移和缩放不重复寻路。
地图对象、领土边界、工作人口、资源产出和小地图底图按状态更新，避免在拖动时重复遍历和排序。
领土索引只遍历城市周围地块，替代逐格扫描所有城市；寻路和 UI 使用同一份领土规则。
地图仅遍历视口附近的行列，保持地形绘制顺序；城市工作地块排序前预计算权重。
文字通过系统字模接口取得 A8 覆盖并缓存在应用内，最多 512 个字形、192 KiB 位图；
未缓存、无法取得的字形以及整数放大的 Surface 保留原生分辨率的 Canvas 文字回退。
UI 接口继续提供输入和窗口环境。
直刷由 Host 决定，使用 GameRender 不保证绕过合成。没有使用 UI 0.11 的 Image 采样属性。
帧缓冲要求固定线性内存，包中配置 `pinned: true`、上限 2 MiB。

在 PXA 工作区根目录，设置已有工具链位置后执行：

```sh
export WASI_SDK_DIR=/path/to/wasi-sdk
export WAMRC=/path/to/wamrc
export PXA_SIMULATOR_DIR=/path/to/simulator-binaries
SDK=/path/to/pxa-system
APP=/path/to/pxa-apps-unciv/unciv
"$SDK/bin/pxa" build "$APP" --target simulator --offline
"$SDK/bin/pxa" run "$APP" --profile pai-touch --offline
```

独立 Wasm 版本使用同一份代码、素材和签名身份构建：

```sh
"$SDK/bin/pxa" build "$APP" --target wasm --offline --output "$APP/dist/wasm/pxa-unciv"
```

`dist/wasm/pxa-unciv/artifacts/main.wasm` 是组件，`dist/wasm/pxa-unciv.pxa`
是包含 Wasm、素材和签名的完整应用包。
Wasm 需要 PXA Host 提供包声明的服务，不能作为不带 Host 的普通网页程序运行。
商城分别上传 Wasm 与三个硬件目标的 AOT 包；各包使用相同版本和 release sequence，
硬件目标通过 `--aot-only` 构建以避免重复携带 Wasm。

`dist/pxa-unciv.pxa` 是签名应用包。真机安装前需构建匹配的 CPU 目标并检查设备兼容性；
模拟器通过不代表已完成硬件验证。存档格式为带版本号与校验和的显式小端编码，
拒绝截断、损坏和越界数据。当前格式 v7 兼容读取 v1～v6，使用9位地块编码，存档为 1257 / 1509 / 1752 字节（按地图大小），分为最多三块，
每块 800 字节以内，适配单值上限 960 字节的固件。两代数据各有带校验和的提交描述，
全部数据块成功后才提交新一代；读取时校验并回退到上一完整代。支持旧版单值存档迁移。
驻防回合数占用单位编码中原有的空闲位，存档大小不变；旧存档中已驻防的军事单位按一回合驻防迁移。
自动保存合并检查点，不逐帧写入。

## 开发与验证

`core.hpp/core.cpp` 不依赖 PXA，可在本机测试。`main.cpp` 实现自适应界面与操作；
`runtime.cpp` 适配分块存档和图块批次，`font_cache.cpp` 管理字形缓存，
`save_store.cpp` 是可独立测试的双代 KV 存档。`audio.cpp` 异步预加载原版音效，使用系统准备音效接口播放；
播放时序由 Host 负责，不依赖游戏更新送入 PCM。
背景音乐使用原版默认下载曲目《Thatched Villagers》（Kevin MacLeod，CC BY 4.0），完整曲目循环播放；转为16 kHz单声道Vorbis以控制包大小。
在「游戏说明」中可分别关闭音效与音乐。音乐切到后台暂停，回到前台续播；解码失败时不循环重试，也不影响音效和游戏。界面提示与游戏动作使用两个独立音轨，关闭声音或离开前台会停止播放。
音效加载失败时保持静音，不退回逐帧音频路径。`art.hpp` 和 `assets/audio/*.pcm` 可由 `tools/assets.py` 重建。
源图像与音效保留在 `source-assets/upstream/`，不重复装入设备包；运行时只携带实际使用的编译素材、音频和许可文件。

```sh
# 默认写入工作区忽略的 local/artifacts/unciv/<时间戳>/
./tests/run.sh

python3 "$SDK/ai/skills/pxa-debug/scripts/verify_app.py" "$APP" \
  --pxa "$SDK/bin/pxa" --output /path/to/local/artifacts/unciv/NEW-TIMESTAMP \
  --profiles pai-touch --scenario "$APP/tests/production.json" --headless --store-screenshots
```

原生测试使用 AddressSanitizer / UndefinedBehaviorSanitizer，覆盖规则、48 局对战、
三种地图、存档损坏、写入中断、回退、旧存档迁移、触摸取消、手柄操作与重开确认。模拟器场景验证真实 Guest 输入，仍须检查截图。
所有截图、日志和测量结果留在本地目录，均不属于应用资源。

重新生成素材需 Python 3、Pillow 与 ffmpeg：`python3 tools/assets.py`。
该脚本只取固定提交的已署名图片与音效；不得将其他未审查素材并入相同许可。

性能对比构建可以使用 `--define UNCIV_REFERENCE_BLIT=1 --define UNCIV_CANVAS_TEXT=1
--define UNCIV_LOCAL_BLIT=1` 保留逐像素 / Canvas 基线；正式包不使用这些宏。
只定义 `UNCIV_LOCAL_BLIT=1` 可比较直接 Guest RGB565 绘制与 Host 批处理。
`--define UNCIV_HOST_BLIT=1` 可关闭原生尺寸精灵缓存，比较相同界面下的 GameRender 路径。
拖动结束后日志记录提交帧数、时间和绘制耗时；这些计数不等同于独立测得的 LCD 扫描率。

真机拖动复测：先进入地图并等待字体载入，再运行
`python3 tests/device_pan.py --pxadb /path/to/pxadb.py --port PORT`。
它在同一连接上完成四次往返拖动，保存原始画面和提交帧率，不修改游戏规则状态。
