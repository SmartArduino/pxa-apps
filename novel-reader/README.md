# 书页阅读

![书页阅读图标](assets/icon.png)

图标源文件为 [icon.svg](assets/icon.svg)，包清单引用 128×128 的 `assets/icon.png`，由系统启动器加载。
修改 SVG 后可用 `rsvg-convert -w 128 -h 128 -o assets/icon.png assets/icon.svg` 重新生成。

PXA C++ SDK 小说阅读器。借鉴 [KOReader](https://github.com/koreader/koreader) 的阅读菜单、字号和进度操作，界面与解析器自行实现，没有复制其 AGPL 代码。详见 [第三方说明](THIRD_PARTY.md) 和 [验收报告](docs/ACCEPTANCE-20261010.md)。

## 使用

- **书架**：轻点书籍继续阅读，按住约 0.55 秒立即打开管理页，无需松手；移动或取消触摸会取消长按，移除前需要确认。点击正文左/右侧翻页，中间打开菜单。
- **列表导航**：书架、搜索、书源与目录使用顶部 `‹` / `›` 图标浏览前后内容，底部不再占用一整行“上一组 / 下一组”。圆屏或高 DPI 下标题区过窄时，箭头放到已有的副标题行。远程目录仍按需补齐，不跳过刚取得的章节。
- **发现**：点击输入框使用系统中文输入法，输入书名或作者后搜索；输入法有确认键时也可直接搜索，小屏键盘的收起键保留输入。空关键词不发请求，提供清空输入、最多六条真实搜索历史；切换书源时复用当前关键词。没有固定的书名推荐按钮。
- **阅读菜单**：目录、下载离线/停止下载、离线管理、保存进度、阅读设置、返回书架。
- **正文**：保留书名和正文，底部居中显示“当前页 / 总页数”；页数按当前字号、行距、DPI 和屏幕形状计算。总页数在后台分段统计，缓存未完成时显示“当前页 / 已缓存页数+”，不冒充全书页数。缓存进度在中间轻点唤出的阅读菜单查看，不显示底部翻页按钮。轻点左侧上一页、右侧下一页，滑动或取消触摸不会误翻页。首次尚无正文时显示加载提示，正文出现即清除；错误和读到缓存边界时仍有短暂提示。
- **设置**：字号 12–28 dp、行距、跟随系统（默认）/纸张/护眼/夜间配色、5–30 秒自动翻页；右上角“缓存”管理新书默认阅读模式与当前书籍缓存。切到后台或重启后自动翻页关闭。
- **书源**：启用、移除或添加自定义来源。最多 8 个来源、16 本书；移除书籍只删除本应用的对应缓存。

0.2.2 内置四个阅读网站，直接使用网站的书名 / 作者搜索：

| 书源 | 已验证查询 | 规则 |
| --- | --- | --- |
| [努努书坊](https://www.nunubook.com/) | 长夜难明 | [nunu.json](source-examples/nunu.json) |
| [书斋阁](https://www.shuzhaige.com/) | 三体 | [shuzhaige.json](source-examples/shuzhaige.json) |
| [笔趣阁 · biquche](https://www.biquche.com/) | 庆余年 | [biquche.json](source-examples/biquche.json) |
| [文林社](https://www.wenlinshe.com/) | 儒林外史、三国 | [wenlinshe.json](source-examples/wenlinshe.json) |

目录支持普通 HTML、分页 JSON 和分页 HTML；同一章的多页正文会合并后显示。
不会把几部内置经典当作网络搜索结果。
每次最多展示 32 个结果，泛词查询可细化为完整书名或作者。
升级会移除四个旧默认项（经典直读、GITenberg、古腾堡中文 / 世界文学），
保留自定义书源、书架、阅读进度及已有正文缓存。书源也可以全部移除，不会在重启时自动加回。
已有默认网站的旧安装会一次性补入三个新来源；自定义规则保留，已清空书源的安装不会自动补回。
内置规则放在只读区，不在每个来源和状态文件中重复保存。书源是第三方网站，访问状况和页面结构可能变化；
接入与实测记录见[新增网站与分页验收](docs/2026-10-15-more-website-sources.zh-CN.md)。

本地《林间书屋》为原创 CC0 验收短篇，不需要网络。

## 添加书源

在“添加书源”输入一个 HTTP(S) JSON 配置地址。可以是下面的配置文件，也可以直接指向 `books` 目录。0.2.0 另支持适配静态阅读网站的 HTML 规则，详见[书源规则与示例](docs/source-rules.zh-CN.md)。输入框最多 512 个 UTF-8 字节，使用单行横向滚动；最终请求地址也限制为 512 字节。

```json
{
  "format": "pxa-reader-source-1",
  "name": "我的免费书源",
  "kind": "json",
  "searchUrl": "/catalog.json?q={{key}}"
}
```

`searchUrl` 相对于配置文件地址解析，`{{key}}` 替换为 URL 编码的关键词。没有占位符时，客户端在当前结果页按书名/作者筛选。结果示例：

```json
{
  "books": [
    {"title": "小说一", "author": "作者", "url": "/book.txt"},
    {"title": "分章小说", "author": "作者", "toc": "/toc.json"}
  ],
  "next": "https://example.org/catalog.json?page=2"
}
```

TXT 正文必须为 UTF-8。分章目录格式：

```json
{"chapters": [{"title": "第一章", "url": "/chapter-1.txt"}]}
```

章节可以返回 UTF-8 TXT，也可以返回 `{"text":"正文"}`。每章最多 64 KiB、目录最多 1,024 章；空目录、错误 URL 或超限目录会拒绝整次下载，避免把残缺目录标记成完整小说。每次搜索最多展示 32 项，通过“下一组”翻页。

## 下载与离线

**默认不保存正文。** 新网络作品按需阅读：TXT 使用 8 KiB 内存窗口及 HTTP Range，分章 JSON / HTML 只在内存中保留当前章。书架、搜索历史、设置和少量阅读进度仍会保存；正文不创建 `.part` / `.txt`。翻页进度在停顿约一秒后合并保存，离开页面或进入后台时保存；突然断电可能丢失最后约一秒的进度。

按需 TXT 校验 Content-Range、长度、UTF-8 和同一会话的 ETag / Last-Modified。服务器不支持 Range 时，仅接受已知长度且不超过 32 KiB 的文本，仍只保留当前窗口；这类来源跨窗口可能重复传输全文。窗口内连续前后翻页不重新开文件或发请求。超出最近页历史的反向定位使用稀疏检查点及分段重排，首次从深处回溯可能较慢。按需 TXT 不为统计总页数提前请求整本书，页脚显示“按需阅读”；分章来源显示当前章页数。

需要离线时，在阅读菜单选择“下载离线”，或在偏好的“缓存”页将新书默认模式改为“自动下载全文”。已经存在的完整或部分离线缓存继续使用，不会自动删除。缓存管理可清除当前书籍正文，书架条目保留；分章离线书清除后从首章打开，TXT 保留字节进度。没有后台自动清理其他书籍的行为。

主动下载时，TXT 首段为 8 KiB，之后使用 32 KiB HTTP Range，校验长度及版本，UTF-8 校验跨分段保留状态。服务器不支持 Range 时，仅接收已知长度且不超过 32 KiB 的正文。菜单可停止或重试。

正文写入 `.part`，完整校验并关闭文件后使用 FS 原子替换发布 `.txt`。刷新失败保留已有离线版本。已缓存作品重启后直接从私有文件读取；阅读位置、书源和设置存于 `reader-state.json`。暂停后可立即打开已有缓存，并在菜单继续下载。TXT 已完整收到的章节标题随缓存增量显示；分章书源先显示目录，未缓存的章节标记“待缓存”，暂不允许跳转。TXT 有可信 ETag / Last-Modified 时可续传，恢复时重新验证已有 UTF-8；无校验标识的来源和分章来源重试从头开始。

单书应用上限 8 MiB。pai-touch / esp-mosaico 的应用私有磁盘配额为 8 MiB，但**实际文件系统剩余空间也必须足够**；多本书和更新时的临时副本共享这个空间。配额没有扩大 Flash 分区，也不预留 8 MiB RAM。空间不足时显示错误。

## 显示与输入

界面采用手机阅读 App 的布局：封面书架、作者和进度信息、底部导航、
搜索操作、阅读菜单和带字号预览的设置页。界面使用系统主色、背景和文字色，响应运行中的配色变更；正文默认跟随系统，也可选择纸张、护眼和深夜模式。
双行预览、真实小说排版和边缓存边显示目录见
[排版与增量目录验收](docs/2026-10-10-typography.zh-CN.md)。
正文去除缓存提示与底部按钮的截图和验证见
[阅读页简化验收](docs/2026-10-10-reading-ui.zh-CN.md)。
底部页码、完整及部分缓存页数与内存核对见
[页码验收](docs/2026-10-10-page-numbers.zh-CN.md)。
阅读页紧凑标题、高 DPI 修正及相同章节前后截图见
[空间利用率验收](docs/2026-10-11-reading-space.zh-CN.md)。
调整字号、行距后的正文上下均衡与圆角避让见
[留白均衡验收](docs/2026-10-11-reading-balance.zh-CN.md)。
改版截图、SDK 迁移及验证记录见
[2026-10-10-sdk-mobile-ui.zh-CN.md](docs/2026-10-10-sdk-mobile-ui.zh-CN.md)。

按照 Host 的分辨率、DPI、安全边距和四角半径排版；圆屏逐行计算可用宽度，底部导航避开弧边。小面板会缩小布局以保留操作行。正文使用 Host 中国大陆黑体字形和抗锯齿，不在 Guest 中携带字库。
系统字库补齐繁体字和《西游记》全部用字，未知字形使用可见占位，详见
[缺字修复与验收](docs/2026-10-11-font-coverage.zh-CN.md)。更新需要替换系统字体并重启 Host，只安装阅读器包不会更新系统字体。

正文默认跟随系统，也可单独选择阅读配色；输入框文字始终跟随系统，按 DPI 和可用行高选择 Host 已有的正文、标题或大字档位。中文候选和键盘使用系统主题及系统字号，切换系统深浅色/主色会保留输入内容。阅读器复用 `TextInputRef`，不携带拼音词典或另造输入法。

书页使用 PXA UI 的原生 Canvas 与标准 `TextInput(...).box(...)`。输入框布局、颜色、
文本事件和键盘引用由 C++ SDK 管理，应用无需 `pxa::wire` 或自定义输入控件。
书架、搜索、书源、设置、目录和阅读菜单使用声明式原生 Text / Button / Box；
需要任意字号和圆屏逐行排版的正文与两行字号 / 行距预览复用同一个 Canvas。
详情和前后截图见 [原生控件与截字修复](docs/2026-10-10-native-ui.zh-CN.md)。
没有额外的全屏阅读帧缓冲、深度缓冲或字体图集；只有页面变化才重绘。
系统输入法打开时使用系统已有的 UI 覆盖层。

## 构建与验收

需要当前 Host 与 SDK：UI 0.8 (`sized-text`, `text-input-control`, `dynamic-text`)、FS 0.2、Net 0.3。旧 Host 不能直接运行本应用，需要更新应用固件。C++ / Wasm / AOT 使用 O3，最大线性内存 2 MiB，按需增长。默认线性 C 栈保持 64 KiB，和 WAMR 执行栈、协程池分别核对；QA 在低地址 8 KiB 放置守卫并检查。

从 PXA 工作区根目录执行：

```sh
SANITIZE=1 bash local/pxa-apps/novel-reader/tests/test.sh
bash tools/app.sh build novel-reader --target simulator,esp32s3 --aot-only
```

完整系统验收使用标准 UI 模拟器，独立 `product` 模拟器没有系统键盘。0.2.0 的按需阅读、HTML 规则、五屏验证及翻页前后对比见[本轮报告](docs/2026-10-15-on-demand-and-paging.zh-CN.md)。原生测试之外，可以用 `tests/build_playtest.py` 构建独立 QA 身份，再运行 `tests/session_probe.py`（本地 HTTP 测试站）与 `tests/paging_probe.py`（相同正文翻页基准）。正式包用 `tests/release_probe.py` 对照回放。旧版本真机记录保留在[历史验收报告](docs/ACCEPTANCE-20261010.md)。

`tests/website_probe.py --output <验收目录>` 会实际联网检查默认网站的搜索、完整目录以及首章、中间章、末章；
加 `--package <QA包>` 会通过系统模拟器操作真实搜索、跳章和按需阅读。测试不把外网失败算作通过，也不修改真实书架。

四站联网矩阵用 `tests/source_matrix_probe.py --output <联网目录>`；随后用
`tests/source_ui_probe.py --package <QA包> --native-report <联网目录>/report.json --output <模拟器目录>`
实际操作四站搜索与阅读。`tests/session_probe.py --html-paged` 检查分页目录、完整章节合并及缺页后重试。

`tests/interaction_probe.py --package <QA包> --output <验收目录>` 在四种屏幕配置中验证未松手长按、
松手不穿透、拖动 / 取消、短按阅读，以及多页书架、书源和目录的前后遍历与末页返回。
截图与复现记录见[长按与图标导航验收](docs/2026-10-15-touch-and-navigation.zh-CN.md)。

## 当前边界

支持 TXT、JSON 目录及声明式静态 HTML 规则，不兼容 Legado 的 JavaScript/CSS 规则全集；不支持 EPUB/PDF、图片正文、动态脚本生成的页面、账号登录和付费章节。HTML 规则使用受限选择器，不运行网站 JavaScript。拉丁字母按一字一个 em 保守换行，长英文段落利用率较低；不自动繁简转换。后台暂停网络任务，已下载 TXT 可以继续离线阅读及按条件续传。网络来源的稳定性由服务端决定。

正文索引从本地 TXT 中识别常见“第…章/回/卷”和英文 Chapter 标题，不能保证识别所有书的目录格式。缓存书源和图书字符串有容量上限，界面热路径没有无限增长的容器。

动态输入与替换安装验收：[DYNAMIC_INPUT-20261010.md](docs/DYNAMIC_INPUT-20261010.md)。
