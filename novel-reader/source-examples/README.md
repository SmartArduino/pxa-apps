# 网站书源

0.2.2 内置以下四组独立网站规则，配置格式为 `pxa-reader-source-2`。

| 配置 | 已验证查询 | 目录与正文 |
| --- | --- | --- |
| [努努书坊](nunu.json) | 长夜难明 | 分页 JSON 目录、HTML 正文 |
| [书斋阁](shuzhaige.json) | 三体 | HTML 目录与正文 |
| [笔趣阁 · biquche](biquche.json) | 庆余年 | 分页 HTML 目录、同章多页正文 |
| [文林社](wenlinshe.json) | 儒林外史、三国 | 搜索列表 / 直达书页、HTML 目录与正文 |

默认已添加，无须再次导入。自定义分发时，将单份 JSON 放到设备可访问的 HTTP(S) 地址，
在“书源 → +”输入该 JSON 地址；不是网站首页地址。更新相同搜索地址的自定义规则时，先移除旧来源再添加。
这不是支持批量导入的索引文件。

网站可能改版或暂时不可访问，实测只说明报告时指定书目可以完成搜索、目录和正文链路。
每本最多 1024 章、目录响应最多 96 KiB、合并单章最多 64 KiB，超过限制会明确报错。
默认按需阅读不保存正文，主动下载离线后才创建正文文件。
完整字段见[规则文档](../docs/source-rules.zh-CN.md)，新站点可从 [simple-html.json](simple-html.json) 开始。
