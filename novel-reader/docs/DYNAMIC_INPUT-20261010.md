# 动态输入更新（2026-10-10）

书源地址和搜索框已从旧的 64 字节文本事件改为按实际内容长度传输，
上限 512 个 UTF-8 字节。使用单行横向滚动，保留原有 DPI 字体、主题颜色、
圆角安全区域和输入框高度。无需额外 Guest 字体图集、绘制层或帧缓冲。

需要 UI 0.8 的 `dynamic-text`，与 `sized-text`、`text-input-control` 一并在
组件清单中声明。通用 C++ SDK 支持 `TextInput(...).max_bytes(n).single_line()`，
单条事件上限 4052 字节，旧输入框的默认容量仍为 64。ESP 的短文本保持内联，
长文本按实际字节分配并释放；命令槽、LVGL 节点、默认 SDK 控件尺寸未增长。

原生阅读器分页/JSON/UTF-8/存档检查及 ASan/UBSan 通过。相关 SDK 和 Host
回归、37 项原生检查、15 项模拟器检查通过。pai-touch 和完整系统模拟器的
独立验收应用以真实系统键盘完成 500、2048、4052 字节输入的字符删除及提交，
收到 499、2047、4051 字节完整文本，并验证清空和三次重复启动。

真机发现多行长网址反复折行会触发看门狗，因此加入可选单行能力。Host
也跳过相同文本的状态写回，避免重复分配、排版和重置光标。未声称所有长文本
多行场景已优化，也未将旧版无法接收的长输入当作同等工作负载性能对比。

pai-touch 更新只写应用固件分区。阅读器采用替换安装，未卸载或清空数据；
更新前后私有文件 SHA-256 相同（包括 `reader-state.json` 和已有 `.part` 文件）。
ESP32-S3 AOT 包 589601 字节、解包 774116 字节；线性内存上限仍为 2 MiB。

独立验收应用的 Guest 线性内存保持 128 KiB；长输入仍需要实际文本空间，
并非任意长度都与短输入占用相同。首次键盘/字体/截图初始化产生系统缓存，
本次内存窗口单独记录初始化与编辑峰值，没有新增资源拒绝或分配失败。

可复现的专用应用与脚本在 PXA SDK 的
`sdk/guest-cpp/examples/system-input/tests/`；本次原始结果位于工作区
`local/dynamic-input-20261010/`。此前 [验收报告](ACCEPTANCE-20261010.md)
中的 64 字节限制属于旧版测量，本文件记录当前能力。
